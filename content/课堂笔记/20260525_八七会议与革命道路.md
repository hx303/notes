## 一、八七会议（1927年8月7日）

### 背景
- 1927年大革命失败后，**中共中央在汉口召开紧急会议**
- 陈独秀离开中央领导岗位（其右倾机会主义错误被批判）
- 新领导人接替（瞿秋白）
- 共产国际代表罗明纳兹（苏联）参与指导

### 核心内容
1. **确立武装反抗国民党的总方针**
2. **土地革命**作为基本内容
3. 党的工作重心开始从城市转向农村，走"农村包围城市"道路

### 毛泽东对大革命失败原因的分析
1. **领导权问题**：孙中山去世后，中共未能掌握领导权
2. **军事问题**：以前只搞工农运动，不搞军事运动 → 必须建立自己的军队（"枪杆子里出政权"）

## 二、三大武装起义

### 2.1 南昌起义（1927年8月1日）
- 依托叶挺、贺龙的军队
- 主要领导人：周恩来、叶挺、贺龙、朱德等
- **意义**：打响武装反抗国民党反动派的**第一枪**，创建**人民军队**的起点
- 南昌起义后南下，最终部分部队在朱德率领下上井冈山

### 2.2 秋收起义（1927年9月9日）
- 湘赣边界发动
- 起义受挫后，毛泽东率部在**文家市**决策转向农村
- **三湾改编**（江西永新）：
  - 缩编：将一个师缩编为一个团
  - **支部建在连上**：确立党对军队的绝对领导（"党指挥枪"原则）
  - 设立士兵委员会，实行民主制度
- **井冈山建立根据地**（1927年10月27日）
  - 收编王佐、袁文才的地方武装
  - 意义：中国革命从城市退却与农村进攻的有机结合，中共开始在农村建立自己的政权

### 2.3 广州起义（1927年12月）
- 希望夺取广州为港口，接收苏联武器援助（1.5万支枪、100万发子弹、30门大炮）
- 叶剑英等参与领导
- **结果失败**：敌我力量悬殊，牺牲过大
- 叶剑英后来评价：有革命精神但能力不足以控制广州这样的城市

### 其他起义
- **海陆丰起义**（广东）：彭湃领导，建立了第一个苏维埃政权
- 1927-1928年间，中共在全国各地进行了上百次武装起义
- 标志着进入**第一次国内革命战争时期**（土地革命战争时期）

## 三、农村包围城市道路理论

### 3.1 毛泽东的两篇重要文章

#### 《中国的红色政权为什么能够存在？》（1928年）
**核心论点**：中国是一个**政治经济发展不平衡**的国家
- 部分地区（如川陕革命根据地）由于地理环境限制，革命力量能长期存在
- 红军具备灵活转移的能力

#### 《星星之火，可以燎原》（1930年）
- 回应林彪"红旗到底能打多久"的疑问
- 论述农村革命根据地发展的必然性
- 标志**农村包围城市、武装夺取政权**道路理论的形成

### 3.2 如何在农村坚持？

**三大要素**：
1. **土地革命**：把土地分给农民，农民才会支持革命
2. **武装斗争**：建立和扩大红军
3. **根据地建设**：政权、经济、党的建设同步推进

**战略意义**：抗战胜利后中共在四年内迅速取得全国胜利，根本原因在于吸收了江西时期（1927-1934）的基本经验。

### 3.3 《反对本本主义》（1930年）
- 毛泽东针对"教条主义"（从莫斯科回国的"二十八个半布尔什维克"用苏联革命理论套中国实际）
- 提出 **"没有调查就没有发言权"**
- 强调从客观实际出发，不搞"本本主义"

## 四、三次"左"倾错误

### 第一次：瞿秋白"左"倾盲动错误（1927-1928）
- 主张在城市组织大规模暴动（如广州起义）
- 不切实际地希望夺取大城市
- 斯大林的判断：中共前两任领导人（陈独秀、瞿秋白）都是知识分子，具有动摇性

### 第二次：李立三"左"倾冒险错误（1930年）
- 判断"革命高潮已经到来"，希望苏联配合中国革命爆发
- 攻打南昌、长沙等大城市，均告失败
- 1930年8月被迫去莫斯科检讨

### 第三次：王明"左"倾教条主义错误（1931-1934）
- 王明（陈绍禹）、博古（秦邦宪）等"二十八个半布尔什维克"从莫斯科回国
- 核心错误：
  - **关门主义**：把民族资产阶级当作敌人排斥
  - **城市中心论**：否定农村根据地
  - 土地政策和军事路线的严重偏差
- 毛泽东被排挤出领导岗位（宁都会议后）
- 直接导致第五次反"围剿"失败

### 关键人物
- **顾顺章**：中共特科重要人物，被捕叛变，导致上海地下组织全面破坏
- **钱壮飞**：打入国民党内部的中共情报人员，及时传递消息，挽救周恩来等中央领导人

## 五、反"围剿"斗争

### 四次反"围剿"
- 前三次：毛泽东亲自指挥，取得胜利
- 第四次：1932年，毛泽东已离开前线，周恩来指挥；陈诚率约40万军队 → 后方日军进入华北（长城抗战），国民党军北调

### 战果
约歼敌31.6万，俘虏19.6万，缴获16.5万支枪

### 第五次反"围剿"（1933-1934年）
- 蒋介石吸取教训，采取**"三分军事，七分政治"**策略
- 军事上：堡垒战术（碉堡封锁）、保甲制度
- 中共方面：共产国际军事顾问**李德**错误指挥，与国民党打正规阵地战
- 彭德怀怒斥："崽卖爷田不心疼"（把毛泽东打下的根据地断送了）
- **结果：失败，被迫长征**

## 六、长征（1934年10月—1936年10月）

### 6.1 基本过程
| 时间 | 事件 |
|------|------|
| 1934年10月 | 中央红军从江西、福建出发，约8.6万人 |
| 1934年11月 | 湘江战役，损失惨重（8.6万 → 3万余人） |
| 1935年1月 | **遵义会议** |
| 1935年6月 | 红一、红四方面军在四川懋功会师 |
| 1935年10月 | 中央红军到达陕北（行程约二万五千里） |
| 1936年10月 | 红二、红四方面军到达甘肃会宁，三大主力会师 |

### 6.2 遵义会议（1935年1月）
- **重要意义**：
  - 批判了博古、李德的错误军事路线
  - 确立了毛泽东在红军和中共中央的**实际领导地位**
  - 电台损坏，无法与共产国际联系 → 独立自主解决党内问题
  - 是中共历史上**生死攸关的转折点**

### 6.3 张国焘分裂事件
- 懋功会师时，张国焘率红四方面军约8万余人，中央红军仅1万余人
- 张国焘坚持南下，另立"中央"
- 经过斗争和红四方面军南下受挫后，最终北上会合

### 6.4 雪山草地
- **海拔**：平均3600米以上（拉萨3650米），高原缺氧
- **温差**：昼夜温差极大
- **粮食**：极度缺乏，数万人断粮
- **牺牲**：大量红军战士因饥饿、寒冷、缺氧牺牲

### 6.5 长征意义
- 传播了革命理想：埃德加·斯诺《红星照耀中国》向世界介绍了长征
- **淬炼了革命队伍**：经历长征考验的干部成为党的核心力量
- "长征是宣言书，长征是宣传队，长征是播种机"

## 七、抗日战争全面爆发的背景

### 7.1 九一八事变（1931年9月18日）
- 日本关东军炸毁沈阳柳条湖段南满铁路，嫁祸中国军队
- 张学良奉行"不抵抗"政策（蒋介石"攘外必先安内"）
- 日本迅速占领东北全境
- 东北沦陷后，中共领导的**东北抗日联军**坚持抵抗（杨靖宇、周保中等）

### 7.2 华北事变与一二九运动
- 1933年日军进犯长城（长城抗战），29军宋哲元部在喜峰口以大刀砍杀日军（《大刀进行曲》背景）
- 1935年《何梅协定》《秦土协定》：华北主权严重受损
- **一二九运动**（1935年12月9日）：北平学生大规模抗日救亡运动
  - 口号："停止内战，一致抗日"
  - 配合中共抗日民族统一战线策略，掀起全国抗日救亡新高潮

### 7.3 日本侵华的根本动因
- **经济**：1929年世界经济危机，日本市场狭小，需要中国市场和东北资源
- **军事**：日本军部势力膨胀，军队逐渐脱离政府控制
- **资源**：日本对中国东北进行了详细探测（精密度极高的军用地图）
- **体系**："国强民弱"——国家军国主义化，但老百姓生活困难

### 7.4 蒋介日的战略判断
- 中日必有一战（认识到从1928年"济南惨案"开始）
- **核心战略**：若与日本开战，必须将日军的进攻方向从"自北向南"改为"自东向西"——利用中国西高东低的地形优势
- 为此必须把华东的军队力量展示出来（淞沪会战的战略逻辑）

## 八、西安事变（1936年12月12日）

### 背景
- 张学良的东北军和杨虎城的西北军在陕北与红军作战不利
- 东北军思乡心切（东北沦陷），不愿继续内战
- 中共通过地下党组织与张学良接触，双方在陕北形成抗日联盟
- 张学良屡次劝蒋介石联共抗日被拒
- 蒋介石亲赴西安督战，逼迫张杨"剿共"

### 经过
- 1936年12月12日，张学良、杨虎城扣留蒋介石，实行"兵谏"
- 中共方面：经共产国际指示，派周恩来赴西安和平解决
- 苏联《真理报》不支持扣押蒋介石

### 结果
- 蒋介石口头承诺停止内战、联共抗日（释放后写了《对张杨的训词》）
- 张学良亲自护送蒋回南京，随即被扣押，从此失去自由
- **标志**：十年内战基本结束，**第二次国共合作**开始形成

### 意义
- 促成**抗日民族统一战线**的建立
- 中共获得了合法地位
- 为全民族抗战创造了条件

### 后续
- 1937年初国民党五届三中全会 → 国共开始正式合作谈判
- 但蒋介石内心未放弃"铲共"（日记中认为最多一个月可消灭中共）
- 国共合作中摩擦不断

## 九、核心概念总结

| 概念 | 内容 |
|------|------|
| **八七会议** | 武装反抗、土地革命、农村转向 |
| **三湾改编** | 支部建在连上、党指挥枪 |
| **农村包围城市** | 政治经济不平衡+土地革命+武装斗争+根据地建设 |
| **三大"左"倾** | 瞿秋白盲动→李立三冒险→王明教条 |
| **遵义会议** | 独立自主、毛泽东领导地位确立、生死攸关转折 |
| **长征** | 两年、二万五千里、三大主力会师 |
| **一二九运动** | 抗日救亡、民族觉醒 |
| **西安事变** | 兵谏→和平解决→第二次国共合作 |
