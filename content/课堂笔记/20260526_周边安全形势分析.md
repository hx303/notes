## 一、课程概述

本课程从三个层面系统分析国家周边安全形势：
1. 我国地缘环境的基本情况
2. 周边安全风险的挑战
3. 重点热点问题

**学习目的**：跳出个人生活视角，从国家与民族高度理解国家安全，成为维护国家安全的践行者。

## 二、我国地缘环境的基本情况

### 2.1 核心概念
- **地缘环境**：国家的地理空间位置，以及由此产生的政治、安全格局和邻国构成
- 狭义：与我国陆地领土接壤的邻国构成的亚太地区（"家门口"的安全）
- 广义：涵盖中亚、南亚、东北亚、东南亚、西亚、南太平洋**六大板块**的"大周边"

大周边在我国外交总体布局中处于**首要地位**——能源运输通道（马六甲海峡、太平洋至澳大利亚）、对外贸易通道、海外利益拓展的战略缓冲地带。

### 2.2 中国是典型的海陆复合型大国
- 陆地边界线：**2.2万公里**
- 海岸线：**1.8万公里**
- 双重属性：既是陆地型大国，也是海洋型大国
- 挑战：陆地和海洋双重安全压力，防范范围广、难度大、任务繁重

### 2.3 四大特点

#### 特点一：邻国众多（世界第一）
- **陆上邻国 14 个**（顺口溜记忆）：俄罗斯、蒙古、朝鲜、越南、老挝、缅甸、印度、尼泊尔、不丹、阿富汗、巴基斯坦、吉尔吉斯斯坦、塔吉克斯坦、哈萨克斯坦
- **海上邻国 8 个**：朝鲜、韩国、日本、菲律宾、马来西亚、文莱、印度尼西亚、越南（越南既是陆上也是海上邻国）
- **合计 20 个邻国** → 边界管控、跨境合作、安全防范、纠纷处理任务繁重

#### 特点二：周边人口众多
- 中国及周边邻国总人口占全世界总人口的 **53.1%**（2024年数据）
- 全球人口破亿的16个国家中，周边占9个：中国14.1亿、印度14.3亿、印尼2.8亿、巴基斯坦2.4亿、孟加拉国1.7亿、俄罗斯1.5亿、日本1.2亿、菲律宾1.1亿、越南1亿
- 影响：巨大的人力资源优势与市场潜力，但也面临资源消耗、环境压力、跨界人口流动等风险

#### 特点三：邻国差异巨大
| 维度 | 对比 |
|------|------|
| 国土面积 | 俄罗斯1700万km² vs 文莱5765km²（差3000倍） |
| 人口 | 印度14.3亿 vs 文莱45万（差3000倍） |
| 政治制度 | 社会主义（中、越、朝、老）→ 君主立宪制 → 资本主义 |
| 经济 | 日本人均3.7万美元 vs 阿富汗人均600美元 |
| 宗教 | 东正教、印度教、伊斯兰教、基督教、佛教 |

差异导致：历史遗留问题、资源争夺、民族对立、宗教冲突、地缘博弈激烈。

#### 特点四：位于世界两大地缘战略区交界处
- 受大国关系深刻影响
- 是理解国家安全形势的基本逻辑起点

## 三、新形势下的安全威胁

**总体判断**：传统安全威胁依然严峻，非传统安全威胁日益严重，呈现全方位、多层次、复合型特点。

### 3.1 传统安全威胁

#### （1）台湾问题——祖国统一面临复杂严峻形势

**历史梳理**：
| 时期 | 事件 |
|------|------|
| 三国 | 吴国军队到达台湾，开启中原王朝与台湾的正式交往 |
| 隋朝 | 中央政府派遣军队加强对台湾的管辖 |
| 元朝 | 设立"巡检司"，正式将台湾纳入中央行政管辖 |
| 明末 | 郑成功收复台湾（1662年），恢复国家主权 |
| 1683年 | 清政府统一台湾，设台湾府（隶属福建省） |
| 1885年 | 清政府正式设立台湾省 |
| 1895年 | 《马关条约》割让台湾给日本 |
| 1945年 | 抗战胜利，根据《开罗宣言》《波茨坦公告》，台湾归还中国 |
| 1949年至今 | 两岸处于暂时分离状态 |

**国际法依据**：《开罗宣言》《波茨坦公告》明确台湾应归还中国，获国际社会普遍承认。

**当前风险**：
- **内部**：民进党当局拒不承认"九二共识"，推进"渐进式台独"（篡改历史教材、阻挠两岸交流、勾结外部势力）
- **外部**：美国打"台湾牌"，虚化掏空一个中国原则，以台制华；日本、澳大利亚跟风干涉

**基本立场**：
- 一个中国原则（世界上只有一个中国，台湾是中国的一部分）
- 坚持"和平统一、一国两制"基本方针
- 绝不承诺放弃使用武力
- 台湾问题不容外部干涉

#### （2）海洋权益争端

**海洋国土**：我国拥有300万平方公里的管辖海域。

**主要争议**：

| 海域 | 争议对象 | 核心问题 |
|------|---------|---------|
| 黄海 | 朝鲜、韩国 | 划界原则：大陆架自然延伸 vs 中间线 |
| 东海 | 日本 | 大陆架划界 + **钓鱼岛问题** |
| 南海 | 越南、菲律宾、马来西亚等 | 六国七方主权争议格局 |

**钓鱼岛问题**：
- 钓鱼岛及其附属岛屿（71个岛礁），总面积5.69km²，海域面积17.5万km²
- 中国最早发现、命名、管辖（明清《使琉球录》、海防范围等史料为证）
- 1895年《马关条约》被日本窃取，1945年应归还
- 1951年《旧金山条约》美国托管琉球，1971年将钓鱼岛"施政权"移交日本
- **根源**：美国介入制造的遗留问题
- **现状**：2012年日本"购岛"闹剧后，中国设立东海防空识别区（2013年），海警船常态化巡航（2024年达355天）
- **方针**：主权属我、搁置争议、共同开发

**南海问题**：
- 南海面积350万km²，我国管辖约200万km²（西沙、中沙、南沙、东沙四大群岛）
- "第二波斯湾"：石油储量约占中国总储量的1/3，天然气、可燃冰资源丰富
- 争议由来：1968年联合国报告指出南海有丰富油气资源 → 各国提出主权要求
- 当前格局：**42个岛礁被非法侵占**（越南29个、菲律宾8个、马来西亚5个），形成六国七方争议
- **中方立场**：对南海诸岛拥有无可争辩的主权 → 搁置争议、共同开发 → 通过和平对话解决 → 反对外部干涉

#### （3）中印边境争端

- 边界总长约1700公里
- **西段**：阿克赛钦地区（3.35万km²，中国实际控制）
- **东段**：藏南地区（9万km²，印度实际控制，中国绝不承认）
- **历史根源**：英国殖民遗留——"约翰逊线"（1865年）、"麦克马洪线"（1913年），中国从未承认
- 印度1947年独立后继承英国殖民遗产，坚持对争议地区的占领
- 1962年中印边境自卫反击战
- 谈判持续进行中，但问题远未解决

#### （4）朝鲜半岛问题

- 核心矛盾：朝鲜发展核武器 ↔ 美日韩制裁威慑
- 朝鲜：以核武器求生存，形成核威慑
- 美国：强化美日韩军事同盟，部署萨德系统
- 日本：谋求对敌基地攻击能力
- **中方立场**：坚持半岛无核化、维护半岛和平稳定、通过对话谈判解决、反对加剧紧张局势的行为
- **中方核心利益**：绝不允许朝鲜半岛发生战争或动乱（将导致难民、边境动荡、战略安全受损）

#### （5）阿富汗问题

- "帝国坟墓"：英国（1839/1879/1919三次入侵失败）、苏联（1979-1989）、美国（2001-2021）均失败
- 三股势力活跃：恐怖主义、极端主义、分裂主义
- 毒品、跨国犯罪等问题严重
- **中方立场**：不干涉内政，推动和平重建

#### （6）美国印太战略

- 美国将中国视为主要竞争对手
- 通过军事演习、武器部署、军事同盟强化在亚太存在
- "第一岛链"战略遏制

### 3.2 非传统安全威胁

| 威胁类别 | 具体内容 |
|---------|---------|
| 恐怖主义 | 昆明火车站事件（2014年）、中东和欧洲恐怖活动频繁 |
| 跨国犯罪 | 金三角毒品、缅甸诈骗、洗钱 |
| 大规模杀伤性武器扩散 | 核武器等威胁全球安全稳定 |
| 重大传染性疾病 | 新冠疫情（2020年）、禽流感等 |
| 战略通道与海外利益安全 | 海上护航、海外撤侨、能源运输安全 |

---

## 四、总结

1. 中国是**海陆复合型大国**，地缘环境极其复杂（四大特点）
2. **传统安全威胁**：台湾问题、海洋权益争端、中印边境、朝鲜半岛、阿富汗、美国印太战略
3. **非传统安全威胁**：恐怖主义、跨国犯罪、武器扩散、传染病、海外利益安全
4. 基本方针：**独立自主的和平外交政策**，推动构建**人类命运共同体**
5. 核心原则：坚决维护国家主权和领土完整，反对外部干涉
