# ESP32 飞机大战 v2 — Plane Shooter

> 从 8051 汇编迁移到 ESP32 + ST7789 240×240 TFT，全面升级版

## 🎮 操作

| 按键 | 功能 |
|:--:|------|
| `2` | 上移（长按连续） |
| `8` | 下移（长按连续） |
| `4` / `A` | 左移（长按连续） |
| `6` / `D` | 右移（长按连续） |
| `5` / `#` | 射击（长按连发） |
| `0` | 暂停 / 继续 |
| `*` | 重新开始 (Game Over 时) |

## 🆕 v2 新增功能

### 难度曲线
- 分越高敌越快越密，spawn 间隔 50→12 ticks
- 速度随关卡递增：基础 1.0 + 0.1×level
- 4 种敌人类型：普通 / 高速 / 蛇形 / 坦克

### 关卡系统
- 每 10+(level×4) 击杀升一级
- HUD 显示当前关卡 (LV)
- 升级时音效 + "LEVEL N!" 提示

### 道具掉落（杀敌 15% 概率）
| 图标 | 类型 | 效果 |
|:--:|------|------|
| T | 三向弹 | 9秒三连发 |
| B | 清屏炸弹 | 消灭所有敌人 + 屏幕震动 |
| S | 护盾 | 挡一次伤害 |
| L | 加命 | +1 命（上限 5） |

### 视觉增强
- 像素风飞船（座舱+机翼+引擎尾焰闪烁）
- 4 种敌人配色（橙/紫/青/金）
- 坦克型敌人带装甲条纹
- 多色爆炸粒子
- 受击闪白 + 屏幕震动
- 暂停画面闪烁提示

### 系统
- EEPROM 存储最高分（断电保留）
- `0` 键暂停/继续
- 护盾/三向弹状态 HUD 显示

## 📦 硬件

| 模块 | 型号 | 数量 |
|------|------|:--:|
| 主控 | ESP32 DevKit | 1 |
| 屏幕 | ST7789 240×240 TFT | 1 |
| 键盘 | 4×4 矩阵键盘 | 1 |
| 蜂鸣器 | 无源蜂鸣器 | 1 |

## 🔧 接线

```
TFT → ESP32:  SCL=18  SDA=23  DC=2  RST=4  CS=15  BLK=5
键盘 → ESP32: R1=32 R2=33 R3=25 R4=26  C1=27 C2=14 C3=12 C4=13
蜂鸣器 → ESP32: BUZZ=19
```

## 📚 依赖

TFT_eSPI 库，User_Setup.h 配置：ST7789_DRIVER, 240×240, MOSI=23 SCLK=18 CS=15 DC=2 RST=4, SPI 40MHz
