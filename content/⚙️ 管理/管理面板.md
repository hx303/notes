## ⚙️ Notes 管理面板

管理功能需要运行本地服务器。在项目目录下执行：

```bash
# Windows — 双击运行
admin.bat

# 或命令行
python admin_server.py --port 8765
```

然后打开浏览器访问：

> **[http://localhost:8765](http://localhost:8765)**

---

### 可用功能

| 功能 | 说明 |
|:--|:--|
| 📄 PDF 导入 | 拖入论文 PDF，自动渲染为笔记并提交到 git |
| 🖼️ 图片渲染 | 支持 150/200/300 DPI 分辨率选择 |
| 📋 自动元数据 | 从 PDF 提取标题、作者、DOI、年份 |
| 🚀 一键部署 | 自动 git commit + push，触发网站重建 |
