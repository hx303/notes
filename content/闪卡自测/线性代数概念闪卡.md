# 🧮 线性代数概念闪卡

## 第一章：矩阵基础

<details class="flashcard">
<summary>什么是阶梯形矩阵？ <span class="flashcard-tag easy">入门</span></summary>

矩阵满足：(1) 非零行在零行之上；(2) 每个非零行的首元（第一个非零数）位于上一行首元的右侧。

**简化阶梯形**：首元为 1，且所在列其余元素全为 0。
</details>

<details class="flashcard">
<summary>高斯消元法的基本操作？ <span class="flashcard-tag easy">入门</span></summary>

三种初等行变换：
1. **交换**两行（$R_i \leftrightarrow R_j$）
2. 某行**乘以**非零常数（$R_i \to kR_i$）
3. 一行**加上**另一行的倍数（$R_i \to R_i + kR_j$）
</details>

<details class="flashcard">
<summary>矩阵乘法的条件是什么？ <span class="flashcard-tag easy">入门</span></summary>

$A_{m \times n} \times B_{n \times p} = C_{m \times p}$

**条件**：$A$ 的列数 = $B$ 的行数。

$(AB)_{ij} = \sum_{k=1}^{n} a_{ik} b_{kj}$（第 $i$ 行与第 $j$ 列的内积）
</details>

<details class="flashcard">
<summary>矩阵乘法是否满足交换律？ <span class="flashcard-tag easy">入门</span></summary>

**不满足**。一般 $AB \neq BA$。

但 $A(BC) = (AB)C$（结合律成立）。

$A(B+C) = AB + AC$（分配律成立）。
</details>

<details class="flashcard">
<summary>什么是逆矩阵？ <span class="flashcard-tag easy">入门</span></summary>

若存在 $B$ 使 $AB = BA = I$，则称 $B$ 为 $A$ 的逆矩阵，记作 $A^{-1}$。

$A$ 可逆 ⇔ $\det(A) \neq 0$（非奇异）
</details>

## 第二章：行列式

<details class="flashcard">
<summary>如何计算 2×2 行列式？ <span class="flashcard-tag easy">入门</span></summary>

$$\det\begin{bmatrix} a & b \\ c & d \end{bmatrix} = ad - bc$$
</details>

<details class="flashcard">
<summary>行列式的核心性质？ <span class="flashcard-tag medium">进阶</span></summary>

1. $\det(A^T) = \det(A)$
2. 交换两行 → 变号
3. 某行乘 $k$ → 行列式乘 $k$
4. 某行加到另一行 → 值不变
5. $\det(AB) = \det(A)\det(B)$
6. $\det(A^{-1}) = 1/\det(A)$
</details>

## 第三章：向量空间

<details class="flashcard">
<summary>线性相关的定义？ <span class="flashcard-tag easy">入门</span></summary>

向量组 $\{v_1, v_2, \dots, v_k\}$ **线性相关** ⇔ 存在不全为零的常数 $c_i$ 使 $c_1v_1 + \cdots + c_kv_k = 0$。

**线性无关** ⇔ 只有 $c_1 = c_2 = \cdots = c_k = 0$ 时等式成立。
</details>

<details class="flashcard">
<summary>矩阵的秩是什么？ <span class="flashcard-tag easy">入门</span></summary>

**秩** $r(A)$ = 最高阶非零子式的阶数 = 阶梯形矩阵的非零行数 = 列空间的维数。

$r(A) = r(A^T)$（行秩 = 列秩）。
</details>

<details class="flashcard">
<summary>什么是基和维数？ <span class="flashcard-tag medium">进阶</span></summary>

**基** = 向量空间中极大线性无关组。

**维数** = 基中向量的个数。

$\mathbb{R}^n$ 的标准基：$e_1 = (1,0,\dots,0), e_2 = (0,1,\dots,0), \dots$
</details>

## 第四章：特征值与特征向量

<details class="flashcard">
<summary>特征值和特征向量的定义？ <span class="flashcard-tag medium">进阶</span></summary>

若 $Av = \lambda v$（$v \neq 0$），则 $\lambda$ 为 $A$ 的特征值，$v$ 为对应的特征向量。

特征方程：$\det(A - \lambda I) = 0$（$n$ 次多项式，$n$ 个特征值）
</details>

<details class="flashcard">
<summary>迹和行列式与特征值的关系？ <span class="flashcard-tag medium">进阶</span></summary>

$$\text{tr}(A) = \sum_{i=1}^{n} \lambda_i$$

$$\det(A) = \prod_{i=1}^{n} \lambda_i$$

迹 = 所有特征值之和，行列式 = 所有特征值之积。
</details>

<details class="flashcard">
<summary>什么是矩阵的对角化？ <span class="flashcard-tag medium">进阶</span></summary>

若 $A$ 有 $n$ 个线性无关的特征向量，则 $A$ 可对角化：

$$A = PDP^{-1}$$

$P$ = 特征向量组成的矩阵，$D$ = 对角矩阵（特征值在对角线上）。

**对角化的好处**：$A^n = PD^nP^{-1}$，计算简单。
</details>

<details class="flashcard">
<summary>实对称矩阵的特殊性质？ <span class="flashcard-tag hard">高阶</span></summary>

1. 特征值全为**实数**
2. 不同特征值对应的特征向量**互相正交**
3. 可**正交对角化**：存在正交矩阵 $Q$ 使 $Q^TAQ = D$

这是 PCA、谱分解的理论基础。
</details>
