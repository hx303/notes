## 向量基础

<details class="flashcard">
<summary>向量是什么？零向量有何特性？ <span class="flashcard-tag easy">入门</span></summary>

**向量** = 大小 + 方向。**零向量** $\vec{0}$：模为 0，**方向任意**。

**单位向量**：模为 1，只含方向信息。向量的单位化 = 除以模。
</details>

<details class="flashcard">
<summary>$\vec{a} \parallel \vec{b}$ 的充要条件？（定理 1） <span class="flashcard-tag easy">入门</span></summary>

$\vec{a} \parallel \vec{b}$（含共线） $\iff \exists!\,\lambda: \vec{b} = \lambda\vec{a}$（前提：$\vec{a} \neq \vec{0}$）

坐标条件下：$\frac{a_1}{b_1} = \frac{a_2}{b_2} = \frac{a_3}{b_3}$。分母为 0 时，对应分子也必须为 0。
</details>

<details class="flashcard">
<summary>$\vec{a},\vec{b},\vec{c}$ 共面的判定方法有哪些？ <span class="flashcard-tag medium">进阶</span></summary>

1. **混合积为零**：$[\vec{a}\;\vec{b}\;\vec{c}] = 0$（充要条件）
2. 线性表出：$\vec{c} = \lambda\vec{a} + \mu\vec{b}$（前提 $\vec{a} \nparallel \vec{b}$）
3. 坐标：三阶行列式值为 0

**空间向量基本定理**：任意向量 $\vec{r}$ 都可以由三个不共面的向量**唯一**线性表出 → 这就是坐标系的数学基础。
</details>

<details class="flashcard">
<summary>方向余弦的三个核心结论？ <span class="flashcard-tag easy">入门</span></summary>

$$\cos\alpha = \frac{a_1}{|\vec{a}|},\quad \cos\beta = \frac{a_2}{|\vec{a}|},\quad \cos\gamma = \frac{a_3}{|\vec{a}|}$$

1. **恒等式**：$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$（无条件成立）
2. 单位化 = 方向余弦：$\frac{\vec{a}}{|\vec{a}|} = (\cos\alpha, \cos\beta, \cos\gamma)$
</details>

## 点积、叉积、混合积

<details class="flashcard">
<summary>$\vec{a}\cdot\vec{b} = 0$ 和 $\vec{a}\times\vec{b} = \vec{0}$ 各判定什么？ <span class="flashcard-tag easy">入门</span></summary>

| 条件 | 判定 | 注意事项 |
|------|------|----------|
| $\vec{a}\cdot\vec{b}=0$ | $\vec{a}\perp\vec{b}$ | 结果为**标量 0** |
| $\vec{a}\times\vec{b}=\vec{0}$ | $\vec{a}\parallel\vec{b}$ | 结果为**向量 $\vec{0}$** |

> ⚠️ $0 \neq \vec{0}$！叉积得向量零，不是标量零。
</details>

<details class="flashcard">
<summary>叉积的几何意义是什么？ <span class="flashcard-tag easy">入门</span></summary>

- $|\vec{a} \times \vec{b}|$ = 以 $\vec{a},\vec{b}$ 为邻边的**平行四边形面积**
- $\boxed{S_{\triangle ABC} = \frac12|\overrightarrow{AB} \times \overrightarrow{AC}|}$ — 三角形面积
- 方向由**右手法则**确定：四指从 $\vec{a}$ 弯向 $\vec{b}$，拇指所指即为方向
- **反交换律**：$\vec{a}\times\vec{b} = -\vec{b}\times\vec{a}$
</details>

<details class="flashcard">
<summary>混合积 $[\vec{a}\;\vec{b}\;\vec{c}]$ 的几何意义？ <span class="flashcard-tag easy">入门</span></summary>

- $|[\vec{a}\;\vec{b}\;\vec{c}]|$ = 以 $\vec{a},\vec{b},\vec{c}$ 为棱的**平行六面体体积**
- 四面体体积：$\boxed{V = \frac16|[\vec{a}\;\vec{b}\;\vec{c}]|}$
- 轮换不变：$[\vec{a}\;\vec{b}\;\vec{c}] = [\vec{b}\;\vec{c}\;\vec{a}] = [\vec{c}\;\vec{a}\;\vec{b}]$
- 对调两向量变号
</details>

<details class="flashcard">
<summary>点积不满足消去律是什么意思？ <span class="flashcard-tag medium">进阶</span></summary>

$\vec{a}\cdot\vec{b} = \vec{a}\cdot\vec{c}$ **不能**约去 $\vec{a}$ 推出 $\vec{b} = \vec{c}$。

只能推出：$\vec{a} \cdot (\vec{b} - \vec{c}) = 0$，即 $\vec{a} \perp (\vec{b} - \vec{c})$。

> 向量点积和数的乘法不同，没有消去律。

</details>

## 平面与直线：方程形式

<details class="flashcard">
<summary>何时用平面点法式？一般式的法向量是什么？ <span class="flashcard-tag easy">入门</span></summary>

**点法式**：$A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ — 已知一点 + 法向量

**一般式**：$Ax+By+Cz+D=0$，法向量 $\vec{n} = (A, B, C)$

**截距式**：$\frac{x}{a}+\frac{y}{b}+\frac{z}{c}=1$ — 已知三轴截距

> ⚠️ 截距式**不能表示**过原点、平行坐标轴、平行坐标面的平面。

</details>

<details class="flashcard">
<summary>直线有哪四种方程形式？ <span class="flashcard-tag easy">入门</span></summary>

| 形式 | 何时用 |
|------|--------|
| **点向式** $\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}$ | 已知一点 + 方向 |
| **参数式** $\begin{cases}x=x_0+mt\\y=y_0+nt\\z=z_0+pt\end{cases}$ | 代入运算（求交点） |
| **两点式** | 已知两点 |
| **交面式** $\begin{cases}A_1x+B_1y+C_1z+D_1=0\\A_2x+B_2y+C_2z+D_2=0\end{cases}$ | 直线作为两平面交线 |

> ⚠️ 点向式分母为 0 有意义。如 $\frac{x-1}{0}=\frac{y}{1}=\frac{z}{2}$ 表示 $x\equiv1$ 恒定。

</details>

<details class="flashcard">
<summary>一般式 $Ax+By+Cz+D=0$ 系数与平面位置的关系？ <span class="flashcard-tag easy">入门</span></summary>

| 条件 | 含义 |
|------|------|
| $D=0$ | 平面过原点 |
| $A=0$ | 平面平行于 $x$ 轴 |
| $A=D=0$ | 平面**过** $x$ 轴 |
| $A=B=0$ | 平面平行于 $xOy$ 面（水平面 $z=\text{const}$） |

</details>

<details class="flashcard">
<summary>平面束是什么？何时用？ <span class="flashcard-tag medium">进阶</span></summary>

**平面束**：$(\Pi_1) + \lambda(\Pi_2) = 0$

即 $A_1x+B_1y+C_1z+D_1 + \lambda(A_2x+B_2y+C_2z+D_2) = 0$

用于：已知该平面**过两已知平面的交线**，需要利用另一条件确定 $\lambda$。

</details>

## 距离与夹角

<details class="flashcard">
<summary>距离公式速记方法？ <span class="flashcard-tag easy">入门</span></summary>

| 求什么 | 公式 | 记忆法 |
|--------|------|--------|
| 点到平面 | $d=\frac{\|Ax_0+By_0+Cz_0+D\|}{\sqrt{A^2+B^2+C^2}}$ | 代入 ÷ 法向量模 |
| 点到直线 | $d=\frac{\|\overrightarrow{M_0P}\times\vec{s}\|}{\|\vec{s}\|}$ | **面积÷底=高** |
| 异面直线 | $d=\frac{\|[\vec{s}_1\;\vec{s}_2\;\overrightarrow{M_1M_2}]\|}{\|\vec{s}_1\times\vec{s}_2\|}$ | **体积÷底面积=高** |

</details>

<details class="flashcard">
<summary>直线到平面的距离如何计算？ <span class="flashcard-tag medium">进阶</span></summary>

**先判后算**：

1. 若 $\vec{n}\cdot\vec{v} \neq 0$ → 相交，$d=0$
2. 若 $\vec{n}\cdot\vec{v} = 0$ 且点在面上 → 直线在平面内，$d=0$
3. 若 $\vec{n}\cdot\vec{v} = 0$ 且点**不**在面上 → 平行，$d =$ 直线上任一点到平面的距离

> 为什么平行时任一点都行？因为 $\vec{n}\cdot\vec{v}=0$，沿着直线走不会改变点到平面的距离。
</details>

<details class="flashcard">
<summary>线面夹角为什么用 $\sin$？ <span class="flashcard-tag easy">入门</span></summary>

$$\sin\varphi = \frac{|\vec{s}\cdot\vec{n}|}{|\vec{s}||\vec{n}|}$$

**用 $\sin$ 不是 $\cos$！**

记忆诀窍：法向量和方向越"接近平行" → 直线越"接近垂直"平面 → 角越大。

| 夹角类型 | 用 |
|----------|:--:|
| 两平面间 | $\cos$ |
| 两直线间 | $\cos$ |
| 直线与平面 | $\mathbf{\sin}$ |

</details>

## 曲面识别

<details class="flashcard">
<summary>旋转曲面方程怎么写？ <span class="flashcard-tag easy">入门</span></summary>

$yOz$ 面上曲线 $F(y,z)=0$ 绕 $z$ 轴旋转：

$$\boxed{F(\pm\sqrt{x^2+y^2},\, z) = 0}$$

**口诀**：绕哪根轴，**那个轴的坐标不变**，另一个坐标换为 $\pm\sqrt{\text{其余两坐标平方和}}$。

</details>

<details class="flashcard">
<summary>柱面和锥面怎么判定？ <span class="flashcard-tag easy">入门</span></summary>

**柱面**：方程中**缺少哪个变量**，母线就平行于哪根轴。

> ⚠️ $x^2+y^2=R^2$ 在空间是**圆柱面**，不是圆！圆要加 $z=0$。

**锥面**：方程满足 $F(tx,ty,tz) = t^nF(x,y,z)$（齐次）⇔ 以原点为顶点的锥面。

</details>

<details class="flashcard">
<summary>六种标准二次曲面怎么一眼认出？ <span class="flashcard-tag easy">入门</span></summary>

| 特征 | 曲面 |
|------|------|
| 三项全正（$+ + +$） | 椭球面 |
| 两正一负（$+ + -$） | 单叶双曲面（沙漏/冷却塔） |
| 一正两负（$+ - -$） | 双叶双曲面（两顶对扣的碗） |
| 齐次 $= z^2$ | 椭圆锥面（两个冰淇淋筒尖对尖） |
| $z=$ 二次项，同号 | 椭圆抛物面（碗/卫星锅） |
| $z=$ 二次项，异号 | 双曲抛物面（马鞍） |

> **口诀**：全正椭球、一负单叶、两负双叶、齐次为锥、$z$ 一次同号碗异号马鞍。

</details>

<details class="flashcard">
<summary>$z = xy$ 是什么曲面？为什么？ <span class="flashcard-tag medium">进阶</span></summary>

**马鞍面**（双曲抛物面）。

证明方法：
1. **二次型矩阵**：$A = \begin{pmatrix}0&\frac12&0\\\frac12&0&0\\0&0&0\end{pmatrix}$，特征值 $0, +\frac12, -\frac12$ → 一正一负一零 = 马鞍面
2. **旋转 45°**：坐标变换 $x=\frac{u-v}{\sqrt{2}}, y=\frac{u+v}{\sqrt{2}}$，代入得 $z = \frac{u^2-v^2}{2}$ → 标准马鞍面

</details>

<details class="flashcard">
<summary>曲线投影怎么求？ <span class="flashcard-tag easy">入门</span></summary>

| 投影到 | 操作 | 结果 |
|:---:|------|------|
| $xOy$ | **消 $z$** | $\begin{cases}H(x,y)=0\\z=0\end{cases}$ |
| $zOx$ | **消 $y$** | $\begin{cases}R(x,z)=0\\y=0\end{cases}$ |
| $yOz$ | **消 $x$** | $\begin{cases}S(y,z)=0\\x=0\end{cases}$ |

消元 = 做"阳光投影"——去掉一个坐标，影子就落在对应的坐标面上。

</details>

## 二次型矩阵判别法

<details class="flashcard">
<summary>如何用特征值快速判别曲面类型？ <span class="flashcard-tag medium">进阶</span></summary>

1. 把方程写成 $F(x,y,z)=0$，提取**二次型矩阵 A**：
   - 平方项系数 → 对角线
   - 交叉项系数 ÷ 2 → 对称位置
2. 求 A 的**三个特征值**
3. 查表：特征值正负号组合 + 是否齐次 → 唯一确定曲面

| 特征值 | 曲面 |
|--------|------|
| $+++$ | 椭球面 |
| $++-$ | 单叶双曲面 |
| $+--$ | 双叶双曲面 |
| $++0$ | 椭圆抛物面 |
| $+-0$ | 马鞍面 |

</details>

<details class="flashcard">
<summary>"z = f(x,y)" 型曲面的速判规则？ <span class="flashcard-tag easy">入门</span></summary>

$z$ 没有平方项 ⇒ 第三个特征值必为 **0**。

此时只看前两个非零特征值：
- **同号** → 椭圆抛物面（碗）
- **异号** → 马鞍面

例：$z = x^2+y^2$ → 特征值 $1,1,0$ → 同号 → 椭圆抛物面 ✓
例：$z = xy$ → 特征值 $+\frac12,-\frac12,0$ → 异号 → 马鞍面 ✓

</details>

## 过线且平行于另一线的平面

<details class="flashcard">
<summary>求过 $\ell_1$ 且 $\parallel \ell_2$ 的平面方程，口诀是什么？ <span class="flashcard-tag medium">进阶</span></summary>

**核心**：$\boxed{\mathbf{n} = \mathbf{v}_1 \times \mathbf{v}_2}$（两次叉积）

| 步骤 | 操作 |
|:--:|------|
| ① | 从 $\ell_1$ 点向式读 $P_1$, $\mathbf{v}_1$ |
| ② | 从 $\ell_2$ 交面式求 $\mathbf{v}_2 = \mathbf{n}_1 \times \mathbf{n}_2$ |
| ③ | $\mathbf{n} = \mathbf{v}_1 \times \mathbf{v}_2$ |
| ④ | 点法式：$\mathbf{n}\cdot(\mathbf{r} - P_1) = 0$ |

</details>

<details class="flashcard">
<summary>什么叫法平面？和切平面有什么区别？ <span class="flashcard-tag medium">进阶</span></summary>

**法平面**（对空间曲线）：以曲线**切向量** $\mathbf{r}'(t_0)$ 为法向量的平面。

$$\mathbf{r}'(t_0) \cdot (\mathbf{r} - \mathbf{r}(t_0)) = 0$$

| | 对象 | 平面名 | 法向量 |
|:--|:--|:--|:--|
| 曲线 | 空间曲线 | **法平面** | **切向量** $\mathbf{r}'(t)$ |
| 曲面 | 空间曲面 | **切平面** | **法向量** $(F'_x,F'_y,F'_z)$ |

> 记忆："法"和"切"是反的！

</details>
