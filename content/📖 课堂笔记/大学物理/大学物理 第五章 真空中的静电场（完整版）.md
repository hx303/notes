## 🏔️ 直觉地图

> **电场线 = 水流，通量 = 雨桶接水，电势 = 海拔，电容 = 水库容量。**

这一章的核心图像可以这样理解：

- **电荷**是"泉眼"（正电荷往外冒水）或"地漏"（负电荷往里吸水）。电场线就是从泉眼流向地漏的水流。
- **高斯定理**说的是：用一个封闭的网兜（高斯面）包住泉眼——不管你怎么包，从网兜里流出来的总水量（通量）只取决于里面有多少泉眼，跟外面开多少泉眼无关。外面的水流会穿过网兜，但进来多少就出去多少，净通量为零。
- **电势**是"海拔"：标量，每点一个数，两点的海拔差就是你要爬的高度。**电场**是"坡度"：矢量，告诉你哪边最陡、有多陡。电场总指向电势降低最快的方向。
- **电容**是"水库容量"：同样涨一米水位，水库越大存的水越多。同样升高一伏特电势，电容越大的器件存的电荷越多。

> 📐 **微积分 §7 接轨**：矢量积分的分解法（把 $\vec{E}$ 拆成 $E_x, E_y, E_z$ 分别积分）就是 §7 多重积分思想在物理中的应用——但物理多了一步**对称性分析**，能先判零的分量就别积！

### §1 库仑定律——静电学的基石

#### 为什么学这个？

没有库仑定律，就不可能有电场、电势、高斯定理……整个静电场大厦都建立在"两个电荷之间力的大小怎么算"这个基础问题上。

#### 电荷与库仑定律

- 电荷量子化：$q = ne$，$e = 1.602 \times 10^{-19}\,\text{C}$
- 电荷守恒：孤立系统电荷代数和不变

**库仑定律**（真空中两个静止点电荷）：

$$\boxed{F = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r^2},\quad \varepsilon_0 = 8.85 \times 10^{-12}\,\text{C}^2/(\text{N·m}^2)}$$

方向沿着连线，同性相斥、异性相吸。

> 💡 写成 $1/(4\pi\varepsilon_0)$ 而非 $k$，是为了让后续高斯定理等公式更简洁（分母恰好消掉 $4\pi$）。

**叠加原理**：$\vec{F} = \sum_i \vec{F}_i$——这看似平凡，却是所有后续计算的根本出发点。场的叠加本质上就是力的叠加。

### §2 电场与电场强度——从"力"到"场"

#### 为什么引入"场"的概念？

电荷 A 怎么"知道"远处有电荷 B？通过**场**。A 在自己周围产生电场，B 感受到这个场，受到力——不需要直接接触。

**电场强度定义**：

$$\boxed{\vec{E} = \frac{\vec{F}}{q_0}}$$

单位：N/C（等价于 V/m，后面学电势就能体会这个等价的美妙）。

**点电荷的电场**：

$$\boxed{E = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}}$$

方向：正电荷的 $\vec{E}$ 向外（辐射状），负电荷的 $\vec{E}$ 指向电荷。

#### 场强叠加原理

$$\vec{E} = \sum_i \vec{E}_i$$

> 📐 **微积分 §7 方法论迁移**：单个点电荷场很简单，但连续带电体呢？把带电体切成无穷多份 $dq$，每份当点电荷，然后积分——这就是 **"微元法"** ，和 §7 的积分思想完全一致。

#### 连续带电体的积分方法论

| 分布类型 | 密度 | 微元 |
|:---:|:---:|:---:|
| 体电荷 | $\rho$ | $dq = \rho\,dV$ |
| 面电荷 | $\sigma$ | $dq = \sigma\,dS$ |
| 线电荷 | $\lambda$ | $dq = \lambda\,dl$ |

$$\vec{E} = \int \frac{dq}{4\pi\varepsilon_0 r^2}\,\hat{r}$$

**矢量积分的核心技巧——分解法**：

$\vec{E}$ 是矢量，方向随 $dq$ 位置变化。不能直接标量积分！

正确做法：分解为分量分别积分：
$$E_x = \int dE_x,\quad E_y = \int dE_y,\quad E_z = \int dE_z$$

然后合成为 $\vec{E} = \sqrt{E_x^2 + E_y^2 + E_z^2}$，方向由分量比决定。

> 🔑 **对称性优先**：动手积分前先看对称性——往往能直接判定某些分量为零。比如均匀带电圆环轴线上，$E_x$ 和 $E_y$ 因对称性为零，只剩 $E_z$。这一步省掉的积分工作量不可估量。

#### 极限检验——物理学家自检的看家本领

算出公式后，用极端情况回代验证：

| 极限过渡 | 应回归 | 示例 |
|----------|--------|------|
| $r \gg L$（考察点很远） | 点电荷场 $E = Q/(4\pi\varepsilon_0 r^2)$ | 检验有限长杆、圆盘、圆环公式 |
| $L \to \infty$ | 无限长直线公式 | 有限线 → 无限线 |
| $R \to \infty$ | 无限大平面公式 | 圆盘 → 无限大面 |
| $z \ll R$ | 无限大平面公式 | 靠近圆盘面 |

> "算出一股表达式，让它回到极端情况——能回去，说明你算对了。回不去，检查哪儿出了bug。"

#### 电偶极子

一对等量异号电荷 $\pm q$，间距 $l$（极小），定义电偶极矩：$\vec{p} = q\vec{l}$（方向从负到正）。

| 位置 | 场强 | 方向 |
|------|------|------|
| 轴线延长线 ($r \gg l$) | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{2p}{r^3}$ | 与 $\vec{p}$ 同向 |
| 中垂线 ($r \gg l$) | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{p}{r^3}$ | 与 $\vec{p}$ 反向 |

> 核心特征：$E \propto 1/r^3$，比点电荷衰减更快——因为正负电荷的场在远处几乎抵消。

#### 常见电场强度分布速查表

| 电荷分布 | 场强公式 | 衰减规律 |
|---------|----------|:---:|
| **点电荷** | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r^2}$ | $\propto 1/r^2$ |
| **电偶极子（轴线）** | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{2p}{r^3}$ | $\propto 1/r^3$ |
| **电偶极子（中垂线）** | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{p}{r^3}$ | $\propto 1/r^3$ |
| **无限长均匀带电直线** | $E = \dfrac{\lambda}{2\pi\varepsilon_0 R}$ | $\propto 1/R$ |
| **均匀带电圆环（轴线）** | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{qz}{(z^2+R^2)^{3/2}}$ | 圆心处 $E=0$ |
| **均匀带电圆盘（轴线）** | $E = \dfrac{\sigma}{2\varepsilon_0}\left(1 - \dfrac{x}{\sqrt{x^2+R^2}}\right)$ | $x\ll R$ → 无限大平面 |
| **无限大均匀带电平面** | $E = \dfrac{\sigma}{2\varepsilon_0}$ | **不衰减！**（均匀场） |
| **均匀带电球壳（球外）** | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r^2}$ | 等价于点电荷 |
| **均匀带电球壳（球内）** | $E = 0$ | — |
| **均匀带电球体（球外）** | $E = \dfrac{1}{4\pi\varepsilon_0}\dfrac{Q}{r^2}$ | 等价于点电荷 |
| **均匀带电球体（球内）** | $E = \dfrac{Qr}{4\pi\varepsilon_0 R^3}$ | $\propto r$ |

> 📌 衰减规律递进：点电荷 $1/r^2$ > 无限长直线 $1/r$ > 无限大平面 **不衰减**。维度越低，衰减越慢！

### §3 高斯定理——静电场的"核武器"

#### 直觉类比

> 🌧️ **通量 = 雨桶接水**：桶口正对雨来的方向 → 接到水最多（$\vec{E} \perp$ 面，通量最大）；桶口水平 → 几乎接不到（$\vec{E} \parallel$ 面，通量为零）；桶口倾斜 → 接到 $\cos\theta$ 比例的水。

**电通量**：

$$\Phi_e = \int_S \vec{E} \cdot d\vec{S}$$

$d\vec{S}$ 方向为面的**外法线方向**（闭合曲面向外，开口面可自定）。

#### 高斯定理

$$\boxed{\oint_S \vec{E}\cdot d\vec{S} = \frac{1}{\varepsilon_0}\sum_{\text{内}} q_i}$$

**物理意义**：静电场是**有源场**——正电荷发出电场线，负电荷汇聚电场线。

#### 三个最容易混淆的点（课堂反复强调！）

| 易混淆点 | 正确理解 |
|---------|---------| 
| ① $\vec{E}$ 是**谁的**场？ | $\vec{E}$ 是**空间所有电荷**在该点产生的**总场**（不仅是面内电荷） |
| ② $\sum q_i$ 是哪些电荷？ | 仅包含**高斯面内部**电荷的**代数和** |
| ③ 外部电荷能影响通量吗？ | 不能——外部电荷的电力线穿过高斯面，**进 = 出**，对通量贡献为零 |

> 🥟 **包饺子类比**：高斯面像饺子皮——只算皮里面包的馅儿（内部电荷），不关皮外面的事。但皮上任意一点的面皮"质感"（场强 $E$）是所有馅料（所有电荷）共同决定的。

> 🎯 **期中考试成绩类比**（郭华忠老师金句）：期中考试平均分 69 分——那不是某一个同学的贡献，而是全班共同努力的结果。$E$ 也是一样，是所有电荷场的矢量叠加。

#### 能用高斯定理直接求场强吗？

⚠️ **高斯定理永远成立**（是物理定律），但要用它**直接求出 $E$ 的数值**，有严格条件：

| 条件 | 说明 |
|------|------|
| **对称性** | 球对称 / 柱对称 / 面对称 |
| **高斯面选取** | 面上 $E$ 大小处处相等，且与面法向夹角恒定（0° 或 90°） |
| **$E$ 可提出积分号** | 若面上各处 $E$ 大小不同，无法提出积分号，就不能直接求解 |

> 📝 能用高斯定理直接求解的情况"屈指可数"——三种经典对称性：

#### 三类经典应用

<details>
<summary><b>应用一：均匀带电球面/球体（球对称）</b></summary>

**高斯面**：同心球面。

| 区域 | 球面结果 | 均匀球体结果 |
|------|----------|-------------|
| 球外 ($r > R$) | $E = \dfrac{Q}{4\pi\varepsilon_0 r^2}$ | 同左 |
| 球内 ($r < R$) | $E = 0$ | $E = \dfrac{Qr}{4\pi\varepsilon_0 R^3}$ |
| 球面 ($r = R$) | $E = \dfrac{Q}{8\pi\varepsilon_0 R^2}$（均值） | — |

> 球面结果中最精妙的是 $r=R$ 处不连续——球内 $E=0$，球外 $E=Q/(4\pi\varepsilon_0R^2)$，球面上取两者算术平均。这是有限带电面（面电荷分布）的普适特征。

</details>

<details>
<summary><b>应用二：无限长均匀带电直线/圆柱（柱对称）</b></summary>

**高斯面**：同轴圆柱面（半径 $r$，高 $L$）。

$$\Phi_e = E \cdot 2\pi r L = \frac{\lambda L}{\varepsilon_0} \quad\Rightarrow\quad \boxed{E = \frac{\lambda}{2\pi\varepsilon_0 r}}$$

> 与直接叠加积分的结果一致 ✅
</details>

<details>
<summary><b>应用三：无限大均匀带电平面（面对称）</b></summary>

**高斯面**：扁平圆柱面，底面平行于带电平面。

$$\Phi_e = 2E \cdot \Delta S = \frac{\sigma \cdot \Delta S}{\varepsilon_0} \quad\Rightarrow\quad \boxed{E = \frac{\sigma}{2\varepsilon_0}}$$

> 两侧通量各半 → 场强因子为 $1/2$。这是后面 $\sigma/\varepsilon_0$ 和 $\sigma/2\varepsilon_0$ 辨析的核心。

</details>

#### 高斯定理的微分形式

<details>
<summary><b>从积分形式到微分形式（点击展开推导）</b></summary>

积分形式：$\oint_S \vec{E}\cdot d\vec{S} = \frac{1}{\varepsilon_0}\int_V \rho\,dV$

利用散度定理（数学上的高斯定理）：$\oint_S \vec{E}\cdot d\vec{S} = \int_V \nabla\cdot\vec{E}\,dV$

对任意体积 $V$ 成立，故：

$$\boxed{\nabla\cdot\vec{E} = \frac{\rho}{\varepsilon_0}}$$

</details>

**物理意义**：某点电场散度 = 该点电荷密度的 $1/\varepsilon_0$ 倍。$\rho > 0$ → 电场线从此发出（源）；$\rho < 0$ → 电场线向此汇聚（汇）。

> 🔗 **降维打击**：散度定理将三维体积分降为二维面积分，高斯定理的微分形式则进一步将面积分关系压缩为逐点关系——每一点的 $\nabla\cdot\vec{E}$ 只取决于该点的 $\rho$。

#### ⚡ 概念辨析题（课堂真题，5道判断题）

> 以下判断题来自课堂讨论，核心是检验对"$E$ 是总场 vs 通量只算内部电荷"的理解。

**① "高斯面上各点场强都为零 → 面内必无电荷"**

→ ❌ **错**。$E=0$ 只保证通量为零 → 只保证面内**净电荷**（代数和）为零。面内可以有等量异号电荷。例子：平行板电容器导体板内部 $E=0$，但板内有大量等量正负电荷。

**② "高斯面内无电荷 → 面上各点场强必为零"**

→ ❌ **错**。面内无电荷只保证通量为零（进=出），不保证面上 $E$ 为零。例子：均匀外电场中任意高斯面，面内无电荷，面上 $E \neq 0$ 但通量为零。

**③ "高斯面上各点场强都不为零 → 面内必有电荷"**

→ ✅ **对**（在特定理解下）。若通量不为零（场强全不为零且分布不对称），则面内必有净电荷。更精确的说法：通量不为零 $\Leftrightarrow$ 面内有净电荷。

**④ "高斯面内有电荷 → 面上各点场强完全由面内电荷决定"**

→ ❌ **错**。$E$ 是空间所有电荷的总场！外部电荷同样对面上 $E$ 的分布有贡献。面内电荷决定的是**通量**，不是各点场强。

**⑤ "高斯面上各点场强都相等 → 面内必无电荷"**

→ ❌ **错**。均匀带电球面外的同心球面上 $E$ 处处相等，但面内有电荷。若"场强相等且为零"，则面内净电荷为零。

> 🎯 **核心教训**：逢高斯定理判断题，先想清楚——问的是 $E$（总场）还是 $\Phi_e$（通量）？两者对应的条件完全不同！

### §4 电势——标量的力量

#### 为什么引入电势？

电场是**矢量**，三个分量要分别积分然后合成——麻烦。电势是**标量**，一个数直接代数相加——简单得多！

> ⛰️ **电势 = 海拔（标量），电场 = 坡度（矢量）：**
> - 海拔：每点只有一个数，65m 就是 65m——像电势 5V 就是 5V。
> - 坡度：既有大小又有方向，"这边往下 30° 坡最陡"——像电场，告诉你哪个方向电势降得最快。
> - 两点的海拔差 = 你爬的高度（电势差 = 电压）。
> - 你朝最陡的方向走（沿电场线），电势降得最快（$E = -\nabla V$）。

#### 静电场是保守场

静电场力做功与路径无关 → **保守力场**：

$$\oint_L \vec{E}\cdot d\vec{l} = 0$$

这是静电场的第二个基本性质——**无旋场**（对比：有源（高斯定理）+ 无旋（环路定理））。

> 🏃 类比：绕操场跑一圈回到起点，静电场力做的总功为零。重力也是保守力，绕一圈回原地，重力做功为零。

#### 电势的定义与计算

$$\boxed{V_a = \frac{W_a}{q_0} = \int_a^{\text{零点}} \vec{E}\cdot d\vec{l}}$$

参考点：通常取 $V_\infty = 0$（无穷远处电势为零）。

**点电荷的电势**（取无穷远为零点）：

$$\boxed{V = \frac{1}{4\pi\varepsilon_0}\frac{q}{r}}$$

> ⚠️ 不要和电场强度搞混！$E \propto 1/r^2$，$V \propto 1/r$。一个 $r^2$，一个 $r$。

#### 电势叠加原理——标量叠加的强大

电势是**标量** → **代数相加**（不需要分解分量！）：

$$\boxed{V = \sum_i \frac{q_i}{4\pi\varepsilon_0 r_i}}$$

连续带电体：$V = \int \dfrac{dq}{4\pi\varepsilon_0 r}$

> 🎯 **电势叠加比电场叠加简单得多**——电场要拆三个分量、逐个积分、再矢量合成；电势只需一个标量积分。这也是"先求电势 $V$，再求梯度 $E = -\nabla V$"成为电工学首选策略的原因。

<details>
<summary><b>典型例子：均匀带电圆环轴线电势 vs 电场</b></summary>

**电势**（瞪眼法）：环上各 $dq$ 到轴上 $P$ 点距离相同 = $\sqrt{x^2 + R^2}$

$$V_P = \int \frac{dq}{4\pi\varepsilon_0\sqrt{x^2+R^2}} = \frac{Q}{4\pi\varepsilon_0\sqrt{x^2+R^2}}$$

一步到位！不需要对称性分析，不需要分解分量。

**电场**：要用 $E = -\nabla V$，对 $x$ 求导取负：

$$E_x = -\frac{\partial V}{\partial x} = \frac{Qx}{4\pi\varepsilon_0 (x^2+R^2)^{3/2}}$$

也比直接做矢量积分简单得多！
</details>

#### 电场与电势的梯度关系

$$\boxed{\vec{E} = -\nabla V}$$

三个分量：$E_x = -\dfrac{\partial V}{\partial x},\; E_y = -\dfrac{\partial V}{\partial y},\; E_z = -\dfrac{\partial V}{\partial z}$

**物理图像**：
- $\vec{E}$ 指向电势**降低最快**的方向（负梯度方向）
- $\vec{E}$ 的大小 = 电势在该方向的方向导数
- $\vec{E}$ **始终垂直于**等势面
- 等势面密的地方电场强（电势变化快 → 梯度大）

> 🌿 **草坪小路类比**：草坪上原本没有路，人多了自然踩出最省力的最短路径——那就是电势变化最快的方向 → 就是电场方向。

#### 常见电势分布

| 电荷分布 | 电势公式 |
|---------|----------|
| 点电荷 | $V = \dfrac{q}{4\pi\varepsilon_0 r}$ |
| 均匀带电球面（球外 $r \ge R$） | $V = \dfrac{Q}{4\pi\varepsilon_0 r}$ |
| 均匀带电球面（球内 $r < R$） | $V = \dfrac{Q}{4\pi\varepsilon_0 R}$（**常数！等势体**） |
| 均匀带电球体（球外 $r \ge R$） | $V = \dfrac{Q}{4\pi\varepsilon_0 r}$ |
| 均匀带电球体（球内 $r < R$） | $V = \dfrac{Q(3R^2 - r^2)}{8\pi\varepsilon_0 R^3}$ |
| 电偶极子（远场） | $V = \dfrac{\vec{p}\cdot\hat{r}}{4\pi\varepsilon_0 r^2}$ |
| 无限长直线 | $V = -\dfrac{\lambda}{2\pi\varepsilon_0}\ln r + C$（需设有限参考点） |

> ⚠️ 无限长带电直线的电势不能取无穷远为零点。**原因**：$E \propto 1/r$，积分 $V = -\int E\,dr \propto -\int dr/r = -\ln r$，当 $r 	o \infty$ 时 $\ln r 	o \infty$，积分发散——意味着从无穷远搬运单位电荷到有限距离需要无穷大的功。这不是物理问题，而是无限长直线的**数学模型奇性**（真正的世界没有无限长的线）。处理办法：在有限远处（如 $r_0$）设参考点。

### §5 导体静电平衡——从场到物质

#### 导体 vs 绝缘体

| | 导体 | 电介质（绝缘体） |
|------|------|------|
| 自由电荷 | 大量自由电子 | 几乎没有 |
| 能带结构 | 导带与价带交叠 | 禁带很大（几 eV） |
| 外电场中 | 静电感应 → 内部 $E=0$ | 极化 → 内部 $E \neq 0$（被削弱） |

#### 静电感应与静电平衡

导体放入外电场 $\vec{E}_0$ 中：

1. 自由电子在电场力下移动
2. 正负电荷分离 → 产生反向感应电场 $\vec{E}'$
3. $\vec{E}_{\text{内}} = \vec{E}_0 + \vec{E}' = 0$ → **静电平衡**
4. 弛豫时间极短：$\tau = \varepsilon_0/\sigma_c \approx 1.5 \times 10^{-19}\,\text{s}$（铜）→ 宏观"瞬间"

#### 静电平衡的五大特征

> 🔑 **统一逻辑**：这五条特征**不是独立的**——它们都是同一条物理原理的不同表现：**导体内部的自由电子会重新分布，直到内部总场强 $\vec{E}=0$ 为止**（若 $\vec{E} \neq 0$，电子还会移动，就不是平衡态）。从这个根原理出发：
> - ① 是定义 → ② $E=0$ 意味着电势梯度为零，所以内部是等势体 → ③ 表面电场若有切向分量，电子会沿表面移动 → ④ 用高斯定理，取紧贴表面的扁平高斯面可证 → ⑤ 如果内部有净电荷，会产生电场使电子移动，直到电荷全被"赶"到表面。
>
> **一句话**：① 内部无电场 → ② 等势体 → ③ 表面 $E$ 垂直 → ④ 表面 $E=\sigma/\varepsilon_0$ → ⑤ 电荷全在表面。这是一个逻辑链，不是五条独立规则。

| 特性 | 说明 |
|------|------|
| ① 内部场强 | $\vec{E} = 0$ |
| ② 导体是**等势体** | 内部和表面电势处处相等 |
| ③ 表面是**等势面** | $\vec{E}$ 始终**垂直**于导体表面 |
| ④ 表面场强 | $\boxed{E = \dfrac{\sigma}{\varepsilon_0}}$（紧贴表面外侧） |
| ⑤ 电荷分布 | 仅分布在导体表面，内部无净电荷 |

> 🔬 特征③的推理：假设 $E$ 不垂直表面 → 有切向分量 → 电子沿表面移动 → 不是平衡态。所以**静电平衡必然导致 $E \perp$ 表面**。

#### ⚡ 重点辨析：$E = \sigma/\varepsilon_0$ vs $E = \sigma/2\varepsilon_0$

这是学生最容易搞混的两个公式。它们**不矛盾**，用叠加原理统一理解：

| 公式 | 适用场景 |
|------|----------|
| $E = \sigma/\varepsilon_0$ | **导体表面附近**（一面有场，内部 $E=0$） |
| $E = \sigma/(2\varepsilon_0)$ | **无限大均匀带电平面**（两面都有场）

**叠加原理统一理解**（三步走）：

1. 将导体表面一小块 $\Delta S$ 近似为无限大平面 → 自身场为 $\sigma/(2\varepsilon_0)$，两面各半
2. 除 $\Delta S$ 外的**其他所有电荷**产生的场记为 $E_{\text{other}}$
3. 由静电平衡条件：
   - 导体内：$E_{\text{other}} - \dfrac{\sigma}{2\varepsilon_0} = 0$ → $E_{\text{other}} = \dfrac{\sigma}{2\varepsilon_0}$
   - 导体外：$E_{\text{总}} = E_{\text{other}} + \dfrac{\sigma}{2\varepsilon_0} = \boxed{\dfrac{\sigma}{\varepsilon_0}}$ ✓

> 🔑 本质上：一个面电荷层在自己两侧各贡献 $\sigma/(2\varepsilon_0)$；在导体表面，其他电荷恰好补齐了另一半，使导体外总场翻倍。

**记忆口诀**："孤立平面分一半，导体表面翻一倍。"

#### 导体空腔与静电屏蔽

| 情况 | 特征 |
|------|------|
| 腔内无电荷 | 内表面无净电荷，腔内 $E=0$（完全屏蔽） |
| 腔内有 $+Q$ | 内表面感应 $-Q$，外表面感应 $+Q$ |

> 🛡️ **静电屏蔽**：空腔导体内部不受外电场影响（汽车里被雷击也是安全的），也可以反过来屏蔽内部电场对外部的影响（把带电体接地壳罩住）。

#### 接地问题

- 接地 → 导体电势 = 大地电势（取 $V=0$）
- 实质：导体与大地交换电荷，直至等势
- 接地导体附近有带电体时，表面产生感应电荷

### §6 电容与电容器——"存电"的能力

#### 电容的定义

孤立导体：$\boxed{C = \dfrac{Q}{V}}$

电容器（两导体系统）：$\boxed{C = \dfrac{Q}{U}}$

其中 $U$ 为两导体间电势差（电压），$Q$ 为正极板的电荷量。

单位：法拉（F），$1\ \text{F} = 1\ \text{C/V}$。常用 $\mu\text{F}$（$10^{-6}$）、$\text{pF}$（$10^{-12}$）。

> 📦 **电容 = 水库容量**：同样涨一米水位（升高一伏特电势），水库越大存的水越多（存的电荷越多）。地球的电容约 700 $\mu\text{F}$——听起来不小，但实际上一个手机充电器里的电解电容就能上万 $\mu\text{F}$。

#### 三类经典电容器

| 类型 | 公式 | 影响因素 |
|------|------|----------|
| **平行板** | $C = \dfrac{\varepsilon_0 A}{d}$ | $A$↑电容↑，$d$↓电容↑ |
| **圆柱形** | $C = \dfrac{2\pi\varepsilon_0 L}{\ln(R_2/R_1)}$ | $L$↑电容↑，$R_2/R_1$↓电容↑ |
| **球形** | $C = \dfrac{4\pi\varepsilon_0 R_1 R_2}{R_2 - R_1}$ | 间隙小→电容大；$R_2\to\infty$ → 回归孤立球 $4\pi\varepsilon_0 R_1$ |

**电容计算的通用四步法**：

1. **假设**两极板带电荷 $\pm Q$
2. 用高斯定理（或叠加原理）求极板间的**电场** $E(r)$
3. 积分求**电势差**：$U = \int \vec{E}\cdot d\vec{l}$
4. 代入 $C = Q/U$ → $Q$ 会约掉，得到仅与几何尺寸有关的 $C$

> 💡 第四步的"$Q$ 约掉"不是巧合——电容是导体系统的**固有属性**，只取决于几何形状和介质，与带电量无关。

#### 电容器串并联

| | 串联 | 并联 |
|------|------|------|
| 总电容 | $\dfrac{1}{C} = \sum\dfrac{1}{C_i}$ | $C = \sum C_i$ |
| 不变物理量 | **电荷 $Q$** 相同 | **电压 $U$** 相同 |
| 总电容大小 | **小于**最小者 | **大于**最大者 |
| 类比电阻 | **并联**（恰好相反！） | **串联**（恰好相反！） |

> ⚠️ **易错提醒**：电容的串并联公式与电阻恰好相反！电容串联 $1/C$ 相加 = 电阻并联 $1/R$ 相加。别搞混！

**串联分压公式**：$U_1 = \dfrac{C_2}{C_1 + C_2}\,U_{\text{总}}$

#### 电容器储能

$$\boxed{W = \frac{1}{2}CU^2 = \frac{1}{2}\frac{Q^2}{C} = \frac{1}{2}QU}$$

<details>
<summary><b>推导（充电过程的功）</b></summary>

充电过程中，电压 $u = q/C$（$q$ 为瞬时电荷量）：
$$dW = u\,dq = \frac{q}{C}\,dq$$
$$W = \int_0^Q \frac{q}{C}\,dq = \frac{Q^2}{2C} = \frac{1}{2}CU^2$$
</details>

**电场能量密度**：

$$\boxed{w_e = \frac{W}{V} = \frac{1}{2}\varepsilon_0 E^2}$$

> 🔬 **场论观点**：能量储存在**电场**中，而不是电荷本身。电场的能量密度正比于 $E^2$。哪里有电场，哪里就有能量。

### §7 电介质简介——从真空到物质

> 📝 本节为第六章"静电场中的导体和电介质"的预热内容。

#### 电介质对电场的影响

在电容器极板间插入电介质（相对介电常数 $\varepsilon_r > 1$）：

$$\boxed{C = \varepsilon_r C_0}$$

- 电容**增大**：$C > C_0$
- 本质原因：电介质在外电场中**极化** → 产生反向电场 → 削弱极板间总电场 → 同样电荷下 $U$ 减小 → $C = Q/U$ 增大

**极化的两种机制**：

| 机制 | 适用分子 | 过程 |
|------|----------|------|
| 位移极化 | 无极分子 | 正负电荷中心在外场下分离 → 感生偶极矩 |
| 取向极化 | 有极分子（如 H₂O） | 固有偶极矩在外场下转向排列 |

#### 导体 vs 电介质（核心区别）

| | 导体 | 电介质 |
|------|------|------|
| 外电场中的行为 | 静电感应（内部 $E=0$） | 极化（内部 $E \neq 0$，被削弱） |
| 电场能否穿透 | 不能（静电平衡时） | 能（被减弱） |
| 电荷移动 | 自由电子宏观移动 | 束缚电荷微观位移 |
| 应用 | 导线、电极、屏蔽 | 电容器介质、绝缘材料 |

> 🧊 水分子（H₂O）的极性：O 端带负电，H 端带正电——天生的电偶极子。微波炉加热就是利用交变电场反复翻转水分子 → 分子摩擦生热。

| 22 | 电容计算的通用四步法？ | ①假设 $\pm Q$ → ②求极板间 $E$ → ③积分 $U = \int E\,dl$ → ④$C = Q/U$（$Q$ 会约掉） |
| 23 | 平行板电容器电容公式？圆柱形？球形？ | 平行板 $C = \varepsilon_0 A/d$；圆柱 $C = 2\pi\varepsilon_0 L/\ln(R_2/R_1)$；球形 $C = 4\pi\varepsilon_0 R_1R_2/(R_2-R_1)$ |
| 24 | 电容器串联和并联时，什么物理量不变？ | 串联：**$Q$** 相同（电荷守恒，中间极板净电荷为零）；并联：**$U$** 相同（所有电容器接同一电压） |
| 25 | 电容串并联公式与电阻串并联公式的关系？ | **恰好相反**！电容串联 $1/C$ 相加 = 电阻并联 $1/R$ 相加 |
| 26 | 两个 $C$ 相同的电容器串联/并联，总电容各是多少？ | 串联：$C/2$（减半）；并联：$2C$（加倍） |
| 27 | 电容器储能的三个等价公式？ | $W = \frac{1}{2}CU^2 = \frac{1}{2}Q^2/C = \frac{1}{2}QU$ |
| 28 | 电场能量密度公式？这个公式普适吗？ | $w_e = \frac{1}{2}\varepsilon_0 E^2$；**普适**（不限于平行板），电场就是能量的载体 |
| 29 | 电介质为什么能增大电容？ | 电介质极化 → 产生反向电场 → 削弱极板间总电场 → 同样 $Q$ 下 $U$ 减小 → $C = Q/U$ 增大 |
| 30 | $\nabla\cdot\vec{E} = \rho/\varepsilon_0$ 和 $\oint \vec{E}\cdot d\vec{l} = 0$ 分别说明静电场什么性质？ | 前者：**有源场**（正电荷发出电力线，负电荷汇聚）；后者：**无旋场/保守场**（电力线不闭合，做功与路径无关） |

## 🧪 综合自测

### 🟢 A 组 — 概念判断（12 题）

> 判断正误，错误的说明原因。

**A1.** 电场中某点场强方向，就是正点电荷在该点所受电场力的方向。

**A2.** 在静电平衡的导体内部，任意两点间的电势差为零。

**A3.** 高斯定理 $\oint \vec{E}\cdot d\vec{S} = \sum q/\varepsilon_0$ 中，$\vec{E}$ 仅由高斯面内的电荷产生。

**A4.** 静电场中，电势为零的地方电场强度也一定为零。

**A5.** 在等势面上，电场强度处处相等。

**A6.** 电容器串联时，每个电容器上分配的电压与其电容成正比。

**A7.** 均匀带电球壳外部任意点的电场等效于所有电荷集中在球心。

**A8.** 两个点电荷的电场中，电场强度为零的点电势也一定为零。

**A9.** 带电导体表面曲率越大的地方，电荷密度也越大。

**A10.** 高斯面内如果没有净电荷，面上各点的电场强度一定为零。

**A11.** 电势能是标量，所以电荷系的电势能等于各点电荷电势能的代数和。

**A12.** 一个接地的导体球壳，可以同时屏蔽内外电场。

### 🟡 B 组 — 基本计算（8 题，附答案）

**B1.** 真空中两个点电荷 $q_1 = +2.0\,\mu\text{C}$、$q_2 = -3.0\,\mu\text{C}$ 相距 50 cm。求 $q_1$ 所受的力的大小和方向。

<details>
<summary>答案</summary>

$$F = \frac{1}{4\pi\varepsilon_0}\frac{|q_1q_2|}{r^2} = 9\times10^9 \times \frac{2\times10^{-6} \times 3\times10^{-6}}{0.5^2} = 0.216\,\text{N}$$

方向：$q_1$ 受到 $q_2$ 的吸引力，指向 $q_2$。
</details>

**B2.** 均匀带电圆环（半径 $R=0.10\,\text{m}$，总电量 $Q = 5.0\,\mu\text{C}$）轴线上距环心 0.20 m 处的电场强度大小。

<details>
<summary>答案</summary>

$$E = \frac{1}{4\pi\varepsilon_0}\frac{Qz}{(z^2+R^2)^{3/2}} = 9\times10^9 \times \frac{5\times10^{-6} \times 0.20}{(0.20^2+0.10^2)^{3/2}}$$

$z^2+R^2 = 0.05$，$(z^2+R^2)^{3/2} = 0.05^{3/2} = 0.01118$

$$E = 9\times10^9 \times \frac{10^{-6}}{0.01118} = 8.05 \times 10^5\,\text{N/C}$$
</details>

**B3.** 半径为 $R$ 的无限长均匀带电圆柱面（面电荷密度 $\sigma$），求柱外距轴线 $r$ 处的电场强度。

<details>
<summary>答案</summary>

取同轴圆柱高斯面（半径 $r$，高 $L$）：

总电量 $Q = \sigma \cdot 2\pi R L$，线密度 $\lambda = Q/L = 2\pi R\sigma$

$$\Phi_e = E \cdot 2\pi rL = \frac{\lambda L}{\varepsilon_0} = \frac{2\pi R\sigma L}{\varepsilon_0}$$

$$\boxed{E = \frac{R\sigma}{\varepsilon_0 r}}$$
</details>

**B4.** 两个同心均匀带电球面，半径 $R_1=0.10\,\text{m}$（内球，$Q_1=+2.0\,\mu\text{C}$）、$R_2=0.20\,\text{m}$（外球，$Q_2=-1.0\,\mu\text{C}$）。求 $r=0.15\,\text{m}$ 处的电势。

<details>
<summary>答案</summary>

在 $r=0.15\,\text{m}$（两球之间）：
- 外球在该点的电势 = 球面内为常数 $V = Q_2/(4\pi\varepsilon_0 R_2)$
- 内球的电场相当于所有电荷在球心

$$V = \frac{Q_1}{4\pi\varepsilon_0 r} + \frac{Q_2}{4\pi\varepsilon_0 R_2}$$
$$= 9\times10^9 \times \left(\frac{2\times10^{-6}}{0.15} + \frac{-1\times10^{-6}}{0.20}\right)$$
$$= 9\times10^9 \times (1.333\times10^{-5} - 5\times10^{-6})$$
$$= 9\times10^9 \times 8.33\times10^{-6} = 7.5\times10^{4}\,\text{V}$$
</details>

**B5.** 一平行板电容器，板面积 $A=100\,\text{cm}^2$，板间距 $d=1.0\,\text{mm}$，两极板间加 $U=10\,\text{V}$ 电压。求：(1) 电容；(2) 极板上的电荷量；(3) 板间电场强度。

<details>
<summary>答案</summary>

(1) $C = \dfrac{\varepsilon_0 A}{d} = \dfrac{8.85\times10^{-12} \times 100\times10^{-4}}{1.0\times10^{-3}} = 8.85\times10^{-11}\,\text{F} = 88.5\,\text{pF}$

(2) $Q = CU = 8.85\times10^{-11} \times 10 = 8.85\times10^{-10}\,\text{C}$

(3) $E = U/d = 10 / 1.0\times10^{-3} = 1.0\times10^{4}\,\text{V/m}$
</details>

**B6.** 三个电容分别为 $C_1=2\,\mu\text{F}$、$C_2=3\,\mu\text{F}$、$C_3=6\,\mu\text{F}$ 的电容器串联后接在 100 V 电源上。求总电容和各电容器上的电压。

<details>
<summary>答案</summary>

总电容：$\dfrac{1}{C} = \dfrac{1}{2} + \dfrac{1}{3} + \dfrac{1}{6} = 1$ → $C = 1\,\mu\text{F}$

总电荷：$Q = CU = 1\times10^{-6} \times 100 = 1\times10^{-4}\,\text{C}$

各电压：$U_1 = Q/C_1 = 50\,\text{V}$，$U_2 = Q/C_2 = 33.3\,\text{V}$，$U_3 = Q/C_3 = 16.7\,\text{V}$

验证：$50 + 33.3 + 16.7 = 100\,\text{V}$ ✓
</details>

**B7.** 一个 $C=5\,\mu\text{F}$ 的电容器充电至 $U=200\,\text{V}$。求储存的能量。若将此电容器与一个未充电的 $5\,\mu\text{F}$ 电容器并联，系统总能量变为多少？解释能量减少的原因。

<details>
<summary>答案</summary>

初始储能：$W_1 = \frac{1}{2}CU^2 = \frac{1}{2}\times 5\times10^{-6} \times 40000 = 0.10\,\text{J}$

并联后总电容 $C_{\text{总}} = 10\,\mu\text{F}$，总电荷不变 $Q = 5\times10^{-6} \times 200 = 10^{-3}\,\text{C}$

$U_{\text{新}} = Q/C_{\text{总}} = 10^{-3} / 10^{-5} = 100\,\text{V}$

$W_2 = \frac{1}{2}C_{\text{总}}U_{\text{新}}^2 = \frac{1}{2}\times 10^{-5} \times 10^4 = 0.05\,\text{J}$

能量减少一半！**原因**：电荷重新分布过程中，连接导线中的电流产生焦耳热（或电磁辐射），能量以热/辐射形式耗散。
</details>

**B8.** 一圆柱形电容器（内半径 $R_1=2.0\,\text{cm}$，外半径 $R_2=4.0\,\text{cm}$，长度 $L=10\,\text{cm}$），求其电容。

<details>
<summary>答案</summary>

$$C = \frac{2\pi\varepsilon_0 L}{\ln(R_2/R_1)} = \frac{2\pi \times 8.85\times10^{-12} \times 0.10}{\ln(2)} = \frac{5.56\times10^{-12}}{0.693} = 8.02\times10^{-12}\,\text{F} \approx 8.0\,\text{pF}$$
</details>

### 🔴 C 组 — 综合应用（5 题，附提示）

**C1.** 一半径为 $R$ 的均匀带电球体（体电荷密度 $\rho$），内部挖去一个半径为 $R/2$ 的球形空腔，空腔中心距球心 $R/2$。求空腔内任意点的电场强度。

> 💡 **提示**：用**补偿法/负电荷叠加法**。空腔 = 完整均匀带电球体 + 空腔区域放一个密度为 $-\rho$ 的等大球体。分别求两个球体在空腔内产生的场，然后叠加。对于均匀带电球体内部，$E = \rho r/(3\varepsilon_0)$（方向径向）。

**C2.** 平行板电容器板面积 $A$、间距 $d$。保持两极板与电压为 $U$ 的电源相连。将一块厚度为 $d/2$ 的金属板平行插入极板正中间。(1) 插入前后电场强度如何变化？(2) 电容如何变化？(3) 极板电荷量如何变化？

> 💡 **提示**：金属板在静电平衡时内部 $E=0$，相当于把原来的间距 $d$ 缩小为 $d/2$（金属板占用的空间没有电场）。注意：金属板不是电介质！在金属板两侧表面会感应电荷。

**C3.** 四个全等的平行板电容器（每个电容 $C$），可以怎样连接来得到总电容为 (a) $4C$，(b) $C$，(c) $C/4$，(d) $2C/3$？

> 💡 **提示**：(a) 全并联；(b) 两串两并；(c) 全串联；(d) 三个串联再与一个并联……想想还有没有别的组合。

**C4.** 一半径为 $R$ 的导体球，带电荷 $Q$。球外罩一个内半径为 $2R$、外半径为 $3R$ 的同心导体球壳，球壳不带电。(1) 求各区域的电场分布和电势分布。(2) 若将球壳接地，结果如何？

> 💡 **提示**：分五个区域讨论：①$r < R$（导体球内部）②$R < r < 2R$ ③$2R < r < 3R$（导体球壳内部）④$r > 3R$。球壳内部 $E=0$。接地后 $V_{\text{壳}}=0$。

**C5.** ⭐挑战题 利用高斯定理的微分形式 $\nabla\cdot\vec{E} = \rho/\varepsilon_0$ 和电场与电势的关系 $\vec{E} = -\nabla V$，推导出电势满足的**泊松方程**：$\nabla^2 V = -\rho/\varepsilon_0$。并说明在无电荷区域（$\rho=0$），该方程简化为**拉普拉斯方程** $\nabla^2 V = 0$。

> 💡 **提示**：把 $\vec{E} = -\nabla V$ 代入 $\nabla\cdot\vec{E} = \rho/\varepsilon_0$ → $\nabla\cdot(-\nabla V) = \rho/\varepsilon_0$ → $-\nabla^2 V = \rho/\varepsilon_0$。这就是静电场的泊松方程，是比高斯定理更基本的偏微分方程形式。

## ⚠️ 常见错误 Top 10

| # | 错误 | 正确理解 |
|:--:|------|----------|
| 1 | 高斯定理的 $E$ 只是面内电荷的场 | $E$ 是**所有电荷**的总场。面内电荷只决定通量，不单独决定 $E$ |
| 2 | 面内无净电荷 → 面上 $E=0$ | 只保证通量为零。外部电荷仍可产生电场穿过高斯面 |
| 3 | 导体表面 $E=\sigma/(2\varepsilon_0)$ 和 $E=\sigma/\varepsilon_0$ 矛盾 | 不矛盾！前者适用于孤立带电平面（两面有场），后者适用于导体表面（内部无场）——用叠加原理统一 |
| 4 | 电容串联电阻串联公式相同 | **恰好相反！** 电容串联 $1/C$ 相加（类似电阻并联），电容并联 $C$ 相加（类似电阻串联） |
| 5 | $E = -\nabla V$ 中负号可以忽略 | 负号表示 $E$ 指向电势**降低**的方向。丢了负号方向就反了 |
| 6 | $E \propto 1/r^2$ 意味着 $V \propto 1/r^2$ 也成立 | 错！$V \propto 1/r$（少一个 $r$），因为 $V$ 是 $E$ 的积分 |
| 7 | 静电平衡的导体内部不应有任何电荷 | 有正负电荷，但**无净电荷**（代数和为零）。正负电荷可以同时存在于内部 |
| 8 | 球壳内部 $E=0$ 意味着必定 $V=0$ | $E=0$ 只意味着 $V$ 为常数，常数不一定是零。球内 $V$ = 球面电势 |
| 9 | 无限长带电直线的电势可取无穷远为零点 | 不可以！$V = -\frac{\lambda}{2\pi\varepsilon_0}\ln r + C$ 在 $r\to\infty$ 发散 → 必须在有限远处设参考点 |
| 10 | $C = Q/U$ 意味着 $C$ 依赖于 $Q$ 和 $U$ | 错！$C$ 只取决于几何尺寸和介质。$Q$ 和 $U$ 成比例变化，比值不变。计算时设 $Q$ → 最后 $Q$ 会约掉 |

### 基本定律与定义

| 公式 | 含义 |

| $\vec{E} = \vec{F}/q_0$ | 电场强度定义 |
| $\vec{p} = q\vec{l}$ | 电偶极矩 |

### 高斯定理

| 公式 | 含义 |
|------|------|
| $\displaystyle\oint_S \vec{E}\cdot d\vec{S} = \dfrac{\sum_{\text{内}} q_i}{\varepsilon_0}$ | 高斯定理（积分形式） |
| $\nabla\cdot\vec{E} = \dfrac{\rho}{\varepsilon_0}$ | 高斯定理（微分形式） |

### 电势

| 公式 | 含义 |
|------|------|
| $V_a = \displaystyle\int_a^{\infty} \vec{E}\cdot d\vec{l}$ | 电势定义（无穷远为零点） |
| $V = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r}$ | 点电荷电势 |
| $V_a - V_b = \displaystyle\int_a^b \vec{E}\cdot d\vec{l}$ | 电势差（电压） |
| $\vec{E} = -\nabla V$ | 电场与电势的梯度关系 |
| $\displaystyle\oint_L \vec{E}\cdot d\vec{l} = 0$ | 环路定理（静电场是保守场） |

### 导体静电平衡

| 公式 | 含义 |
|------|------|
| $\vec{E}_{\text{内}} = 0$ | 导体内部场强 |
| $E_{\text{表面}} = \dfrac{\sigma}{\varepsilon_0}$ | 导体表面附近场强 |
| $V_{\text{导体}} = \text{const}$ | 导体是等势体 |

### 电容与储能

| 公式 | 含义 |
|------|------|
| $C = \dfrac{Q}{U}$ | 电容定义 |
| $C = \dfrac{\varepsilon_0 A}{d}$ | 平行板电容器 |
| $C = \dfrac{2\pi\varepsilon_0 L}{\ln(R_2/R_1)}$ | 圆柱形电容器 |
| $C = \dfrac{4\pi\varepsilon_0 R_1 R_2}{R_2 - R_1}$ | 球形电容器 |
| $\dfrac{1}{C_{\text{串}}} = \sum\dfrac{1}{C_i}$ | 串联总电容 |
| $C_{\text{并}} = \sum C_i$ | 并联总电容 |
| $W = \dfrac{1}{2}CU^2 = \dfrac{Q^2}{2C} = \dfrac{1}{2}QU$ | 电容器储能 |

| $C = \varepsilon_r C_0$ | 电介质对电容的影响 |

### 静电场的两个基本性质

| 定理 | 数学表达式 | 物理意义 |
|------|-----------|---------|
| 高斯定理 | $\displaystyle\oint_S \vec{E}\cdot d\vec{S} = \dfrac{\sum q_i}{\varepsilon_0}$ | **有源场** |
