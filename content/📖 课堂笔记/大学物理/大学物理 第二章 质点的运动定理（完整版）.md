# 第二章 质点的运动定理

> *力不是维持运动的原因，力是改变运动的原因。* —— 这一章的四条定理，就是四种「力如何改变运动」的精确表述。

---

## 🏔️ 直觉地图

想象你在玩台球：

- **牛顿第二定律** 告诉你「母球受多大的力，就会产生多大的加速度」——力与加速度瞬时对应，不打折扣。
- **动量定理** 告诉你「白球撞击彩球那一瞬间发生了什么」——碰撞时间极短、力变化剧烈，我们不去纠结每一毫秒的力，只关心**总冲量**带来的速度改变。
- **动能定理** 告诉你「推球走多远，就给球注入多少能量」——力在空间上的积累，转化为球的动能。
- **角动量定理** 告诉你「切着打（有旋转的击球）会怎样」——力对球心的力矩会改变球的旋转状态。

> **直觉类比 1：动量定理 = 拳击手套缓冲**  
> 裸拳打墙，Δt 极短，力峰值巨大，手骨断裂；戴上拳击手套，同样的动量变化被拉长到几十毫秒，力峰值骤降，手安全。公式 $\vec{I} = \vec{F}\Delta t = \Delta\vec{p}$ 中，$\Delta\vec{p}$ 固定时，延长 $\Delta t$ 就能减小 $\vec{F}$。

> **直觉类比 2：保守力 = 不管走楼梯还是坐电梯，到五楼重力做功一样**  
> 你从一楼到五楼，重力做功只取决于高度差 $h$，与你是走楼梯、坐直梯还是翻窗户上去无关。这就是保守力的本质——做功与路径无关。

> ⚠️ **全章核心区分（考试高频）**  
> **冲量** 是过程量（取决于力的时间积累过程），**动量** 是状态量（取决于某一时刻的速度）  
> **功** 是过程量（取决于力的空间积累过程），**动能** 是状态量（取决于某一时刻的速度）

## 🔗 从运动学到动力学

> 第一章我们学会了"描述"运动：位置、速度、加速度——物体**在**怎样运动。这一章我们回答"**为什么**"这样运动：力、冲量、功——是什么**改变**了物体的运动状态。
>
> 两章的关系是：运动学提供"语言"（$x,v,a$），动力学提供"规律"（$F=ma$，守恒律）。有了语言才能表达规律，有了规律才能预测运动。

## 一、知识整合

### §2-1 牛顿运动定律 —— 一切定理的起点

#### 为什么学这个？

牛顿三定律是整个经典力学的公理基础。后续三条定理（动量、动能、角动量）本质上都是牛顿第二定律在不同方向上的积分形式，它们不是新的物理，而是**不同的数学视角**。掌握好牛顿定律的原始形式，才能理解为什么积分后的定理更适合解决特定类型的问题。

#### 第一定律：惯性定律

> 任何物体都保持静止或匀速直线运动状态，直到外力迫使它改变。

**物理含义**：
- 定义了**惯性参照系**：牛顿第一定律成立的参照系（无加速度的参照系）。地球近似为惯性系，但严格来说不是（它自转 + 公转）。
- 定义了**力**的概念：力不是维持运动的原因（亚里士多德错了），力是**改变**运动的原因（伽利略-牛顿对了）。

#### 第二定律：力 = 动量的时间变化率 ★ 核心

$$\boxed{\vec{F} = \frac{d\vec{p}}{dt}, \quad \vec{p} = m\vec{v}}$$

这是第二定律的**普遍形式**，在相对论中也成立（只需换用相对论动量）。

当 $v \ll c$ 且质量不变时，退化为大家熟悉的：

$$\vec{F} = m\vec{a} = m\frac{d\vec{v}}{dt}$$

**自然坐标系分解**（解决曲线运动）：
$$F_t = ma_t = m\frac{dv}{dt}, \qquad F_n = ma_n = m\frac{v^2}{\rho}$$

- $F_t$（切向力）改变速度大小
- $F_n$（法向力/向心力）改变速度方向

#### 第三定律：作用力与反作用力

> $\vec{F}_{12} = -\vec{F}_{21}$

四同：同大小、同性质、同一直线、同时存在同时消失。  
两不同：作用在**不同物体**上、产生**不同效果**（不能抵消！）。

<details>
<summary>🔍 为什么 $F=ma$ 不能用于变质量问题？</summary>

当 $m$ 不是常数时：
$$\vec{F} = \frac{d}{dt}(m\vec{v}) = m\frac{d\vec{v}}{dt} + \vec{v}\frac{dm}{dt}$$

即使用 $m$ 是时变的，右边也会多出 $\vec{v}\frac{dm}{dt}$ 一项。火箭推进、落链等问题必须用 $\vec{F}=d\vec{p}/dt$ 而非 $\vec{F}=m\vec{a}$。

</details>

#### 常见力速查

| 力 | 公式 | 要点 |
|----|------|------|
| 重力 | $\vec{G} = m\vec{g}$ | 竖直向下；$g \approx 9.8\ \text{m/s}^2$ |
| 弹簧弹力 | $\vec{F} = -k\vec{x}$ | 负号：与位移方向相反 |
| 静摩擦力 | $0 \leq f_s \leq f_{s,\max} = \mu_s N$ | 被动适应外力 |
| 滑动摩擦力 | $f_k = \mu_k N$ | 与相对运动方向相反 |
| 万有引力 | $\vec{F}_{12} = -G\frac{m_1 m_2}{r^2}\hat{e}_r$ | 负号：吸引力。📌 万有引力也是保守力——对应势能 $E_p = -G\frac{Mm}{r}$，详见 §2-5 |
| 浮力 | $F_b = \rho V g$ | 竖直向上 |

#### 惯性力（非惯性系中的「假力」）

在非惯性系中，牛顿第二定律形式上不成立。引入惯性力后：

$$\vec{F} + \vec{F}_{\text{惯性}} = m\vec{a}'$$

其中 $\vec{F}_{\text{惯性}} = -m\vec{a}_0$（$\vec{a}_0$ 是非惯性系相对惯性系的加速度）。

> ⚠️ 惯性力**没有施力物体**，不存在反作用力。它是数学工具，不是真实力。

**常见惯性力**：
- 平动非惯性系：$\vec{F}_i = -m\vec{a}$ （汽车加速时你感觉被向后推）
- 离心惯性力：$\vec{F}_i = m\omega^2 r$ （方向沿径向向外）

#### 解题五步法

1. **隔离物体**：明确研究对象
2. **受力分析**：画完整的受力图（别漏力、别添力）
3. **建立坐标**：选最方便的坐标系（注意正方向）
4. **列方程**：牛顿第二定律 + 运动学约束
5. **检验讨论**：量纲检查、极端情况验证

### §2-2 质点的动量定理 —— 时间上的积累效应

#### 为什么学这个？

碰撞、打击、爆炸——这些过程时间极短（毫秒级）、力变化极其剧烈（$10^4\ \text{N}$ 量级）、力的瞬时值几乎不可测量。牛顿第二定律要求知道每一时刻的 $\vec{F}$，这在实际中行不通。**动量定理**把问题从「每一时刻」提升到「时间累积」，只需要知道初末动量，完美绕过力的细节。

#### 冲量：力在时间上的积累

$$\boxed{\vec{I} = \int_{t_1}^{t_2} \vec{F}\,dt}$$

- **冲量是过程量** $\leftarrow$ 全书最重要的概念区分之一
- 冲量是矢量，方向与动量增量方向相同
- 平均冲力：$\langle F \rangle = \frac{I}{\Delta t}$

#### 动量定理

$$\boxed{\vec{I} = \vec{p}_2 - \vec{p}_1 = m\vec{v}_2 - m\vec{v}_1}$$

> 合外力的冲量 = 质点动量的增量。

**两种形式等价**：
- 积分形式（上面）：处理有限时间间隔，适合碰撞
- 微分形式：$\vec{F} = d\vec{p}/dt$ —— 其实就是牛顿第二定律本身

#### 碰撞问题的「套路」

1. **画图**：标注碰撞前后的速度矢量
2. **选正方向**：所有速度带符号
3. **列动量定理**：$\vec{I} = m\vec{v}_2 - m\vec{v}_1$
4. **注意矢量性**：改为标量方程时要带正负号

<details>
<summary>📐 例题：子弹穿木块</summary>

质量为 $10\ \text{g}$ 的子弹以 $400\ \text{m/s}$ 水平射入木块，以 $100\ \text{m/s}$ 穿出，碰撞时间 $0.001\ \text{s}$。求平均阻力。

**解**：
1. 以子弹初速方向为正
2. 动量增量：$\Delta p = 0.01 \times 100 - 0.01 \times 400 = -3\ \text{kg·m/s}$
3. 冲量 = 动量增量：$F_{\text{avg}} \times 0.001 = -3$
4. $F_{\text{avg}} = -3000\ \text{N}$（负号表示与初速方向相反）

平均阻力 $3000\ \text{N}$，相当于 $300\ \text{kg}$ 物体的重量！
</details>

#### 动量守恒定律

当 $\sum\vec{F}_{\text{外}} = 0$ 时：

$$\vec{p}_{\text{总}} = \text{常数}$$

> ⚠️ 注意：动量守恒条件是**合外力为零**（不是合外力矩）。如果只是某方向合外力为零，则该方向动量分量守恒。

### §2-3 质点的动能定理 —— 空间上的积累效应

#### 为什么学这个？

力不仅有时间积累（冲量），还有空间积累（功）。动量定理关心的是「力作用了多久」，动能定理关心的是「力推了多远」。许多问题中，位移比时间更容易获取（如弹簧压缩距离、物体下落高度），此时动能定理比动量定理更直接。

#### 功：力在空间上的积累

$$\boxed{A = \int_{A}^{B} \vec{F}\cdot d\vec{r} = \int_{A}^{B} F\cos\theta\, ds}$$

- **功是过程量** $\leftarrow$ 与冲量并列为全书最重要的过程量
- 功是标量，可正可负：力与位移同向 → 正功（加速）；反向 → 负功（减速）；垂直 → 不做功
- 功率：$P = \frac{dA}{dt} = \vec{F}\cdot\vec{v}$（瞬时做功快慢）

**几种常见力的功**：

| 力 | 从 A 到 B 做的功 | 特点 |
|----|------------------|------|
| 恒力 | $A = \vec{F}\cdot\Delta\vec{r} = Fs\cos\theta$ | 直线运动 |
| 重力 | $A = mg(h_A - h_B)$ | 只与高度差有关 |
| 弹簧弹力 | $A = \frac{1}{2}kx_A^2 - \frac{1}{2}kx_B^2$ | 只与形变量有关 |
| 摩擦力 | $A = -f_k \cdot s$（路程）| 与路径有关！|

#### 动能定理

$$\boxed{A_{\text{合}} = E_{k2} - E_{k1} = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2}$$

> 合外力做的功 = 质点动能的增量。

- **动能是状态量**（由瞬时速度决定）—— 与「功是过程量」形成鲜明对比
- 动能定理对**任何力**（保守力 + 非保守力）都成立
- 动能依赖于参照系选取，但动能定理的形式在所有惯性系中相同

<details>
<summary>📐 例题：刹车距离</summary>

汽车质量 $1500\ \text{kg}$，以 $72\ \text{km/h}$（$=20\ \text{m/s}$）行驶，紧急刹车。轮胎与路面摩擦系数 $\mu=0.7$。求刹车距离。

**解**（用动能定理）：
1. 合外力 = 摩擦力：$f = \mu mg = 0.7 \times 1500 \times 9.8 = 10290\ \text{N}$
2. 摩擦力做负功：$A = -f \cdot s$
3. 动能定理：$-fs = 0 - \frac{1}{2}mv_0^2$
4. $s = \frac{mv_0^2}{2f} = \frac{1500 \times 400}{2 \times 10290} \approx 29.1\ \text{m}$

> 💡 注意：刹车距离正比于 $v_0^2$！速度翻倍，刹车距离翻四倍。
</details>

#### 「过程量 vs 状态量」—— 本章最重要的概念区分

| | 过程量（依赖于路径/过程） | 状态量（只取决于当前状态） |
|------|------|------|
| 时间线 | **冲量** $I = \int F\,dt$ | **动量** $p = mv$ |
| 空间线 | **功** $A = \int \vec{F}\cdot d\vec{r}$ | **动能** $E_k = \frac{1}{2}mv^2$ |

> 考试陷阱：问「某时刻的冲量是多少」是无意义的——冲量不是瞬时量！同样，「某时刻的功」也没有物理意义。

### §2-4 质点的角动量定理 —— 转动中的「牛顿第二定律」

#### 为什么学这个？

平动世界用 $\vec{F}=m\vec{a}$，转动世界用 $\vec{M}=d\vec{L}/dt$。这是完全平行的结构——力 $\leftrightarrow$ 力矩，动量 $\leftrightarrow$ 角动量。当你研究行星轨道、陀螺旋转、或者任何涉及「绕某点转动」的问题时，角动量比线动量自然得多。

#### 力矩

$$\boxed{\vec{M} = \vec{r} \times \vec{F}}$$

大小：$M = rF\sin\theta = Fd$（$d = r\sin\theta$ 称为**力臂**）

> 力矩取决于参考点的选取！同一个力对不同参考点的力矩不同。

#### 角动量（动量矩）

$$\boxed{\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times (m\vec{v})}$$

大小：$L = rmv\sin\theta = mvr_\perp$

#### 角动量定理

$$\boxed{\vec{M} = \frac{d\vec{L}}{dt}}$$

> 合外力矩 = 角动量的时间变化率。

| 线量世界 | 角量世界 |
|---------|---------|
| 力 $\vec{F}$ | 力矩 $\vec{M} = \vec{r}\times\vec{F}$ |
| 动量 $\vec{p}=m\vec{v}$ | 角动量 $\vec{L} = \vec{r}\times\vec{p}$ |
| $\vec{F}=d\vec{p}/dt$ | $\vec{M}=d\vec{L}/dt$ |

#### 角动量守恒定律

当 $\sum\vec{M}_{\text{外}} = 0$ 时：

$$\vec{L} = \text{常数}$$

> ⚠️ **高频易错**：角动量守恒的条件是**合外力矩为零**，不是合外力为零！有心力（如万有引力、库仑力）对力心的力矩恒为零，所以有心力场中角动量守恒。

> **直觉类比**：花样滑冰运动员收臂时转速变快。因为合外力矩为零 → 角动量守恒 → $I\omega = \text{常数}$ → 转动惯量 $I$ 变小则角速度 $\omega$ 变大。

<details>
<summary>📐 用角动量守恒推导开普勒第二定律</summary>

行星受太阳引力（有心力，力矩为零）→ 角动量守恒：
$$\vec{L} = \vec{r} \times m\vec{v} = \text{常数}$$

角动量大小 $L = mrv\sin\theta = m \cdot r \cdot (r\,d\theta/dt)\sin\theta$，对于平面运动 $\theta=90°$：
$$L = mr^2\frac{d\theta}{dt}$$

而掠面速度 $= \frac{1}{2}r^2\frac{d\theta}{dt} = \frac{L}{2m} = \text{常数}$

这就是开普勒第二定律：行星与太阳连线在相等时间内扫过相等面积。
</details>

### §2-5 保守力与势能 —— 能量的「储存」机制

#### 为什么学这个？

有些力（重力、弹力、万有引力、静电力）做功与路径无关，这意味着我们可以定义一个**只依赖于位置**的函数——势能——来描述「储存的做功能力」。这大大简化了问题：我们不需要每一步都算功，只需要知道起点和终点的势能差。

#### 保守力的定义（三种等价表述）

1. **做功与路径无关**：$\displaystyle\int_{A(\text{路径1})}^{B} \vec{F}\cdot d\vec{r} = \int_{A(\text{路径2})}^{B} \vec{F}\cdot d\vec{r}$
2. **沿任意闭合路径做功为零**：$\displaystyle\oint \vec{F}\cdot d\vec{r} = 0$
3. **存在势能函数** $E_p$ 满足 $\vec{F} = -\nabla E_p$

> **直觉类比**：保守力 = 不管走楼梯还是坐电梯，到五楼重力做功一样。你消耗了同样的重力势能，只是人体内化学能的消耗路径不同而已。

#### 保守力与势能的「翻译」关系

$$\boxed{\vec{F} = -\nabla E_p}$$

一维情况下：$F = -\dfrac{dE_p}{dx}$

| 保守力 | 势能 $E_p$ | $F = -dE_p/dx$ |
|--------|-----------|----------------|
| 重力 | $mgh$ | $-mg$（向下的恒力）|
| 万有引力 | $-\dfrac{Gm_1m_2}{r}$ | $-\dfrac{Gm_1m_2}{r^2}$（引力）|
| 弹簧弹力 | $\dfrac{1}{2}kx^2$ | $-kx$（回复力）|
| 静电力 | $\dfrac{kq_1q_2}{r}$ | $\dfrac{kq_1q_2}{r^2}$（同号排斥）|

> 核心关系：**保守力做功 = 势能的减少量**
> $$\boxed{A_{\text{保}} = E_{p1} - E_{p2} = -\Delta E_p}$$

#### 万有引力与库仑力的矢量形式（优雅的统一）

$$\vec{F}_{12} = -G\frac{m_1 m_2}{r^2}\,\hat{e}_r \quad\text{（引力，负号表示吸引）}$$

$$\vec{F}_{12} = k\frac{q_1 q_2}{r^2}\,\hat{e}_r \quad\text{（同号正=排斥，异号负=吸引）}$$

> 💡 矢量写法中，正负号自动决定方向，比分别讨论「同号还是异号」优雅得多。数学替你做了判断。

<details>
<summary>🔍 万有引力为保守力的证明</summary>

$$W = \int_{r_A}^{r_B} \left(-G\frac{m_1 m_2}{r^2}\right) dr = Gm_1 m_2\left(\frac{1}{r_B} - \frac{1}{r_A}\right)$$

结果只依赖 $r_A$ 和 $r_B$，与路径无关 → 保守力 ✅
</details>

### §2-6 功能原理与机械能守恒 —— 能量的全局视角

#### 为什么学这个？

动能定理 $A_{\text{合}} = \Delta E_k$ 对所有力一视同仁，但在实际问题中我们通常知道保守力的势能表达式。功能原理**把保守内力做的功「内化」为势能变化**，把焦点放在外力和非保守内力上，让能量分析更精确。

#### 内力做功的关键事实

> ⚠️ **内力虽然成对等大反向，但做功之和不一定为零！**

一对内力做的总功 = $\vec{F}_{12} \cdot d\vec{r}_{12}$（$d\vec{r}_{12}$ 是两质点的相对位移）。

**例子**：滑块在车板上滑动。摩擦力对滑块做负功 $-fS$，对车板做正功 $f(S-L)$（车板位移为 $S-L$），一对摩擦力总功 $= -fL$（$L$ 为相对滑动距离）。

> 一对内力做功 = 内力大小 × 相对位移

#### 功能原理

将内力分解为保守内力 + 非保守内力：

$$\boxed{A_{\text{外}} + A_{\text{非保守内}} = \Delta(E_k + E_p) = \Delta E_{\text{机械能}}}$$

> 外力和非保守内力做的功 = 机械能的增量。

#### 机械能守恒定律

当 $A_{\text{外}} = 0$ 且 $A_{\text{非保守内}} = 0$ 时：

$$\boxed{E_k + E_p = \text{常量}}$$

> ⚠️ **高频易错**：弹簧弹性势能的变量是**形变量 $\Delta x$**，不是弹簧总长度！
> $$\text{❌ 错误：}E_p = \frac{1}{2}kl^2 \qquad \text{✅ 正确：}E_p = \frac{1}{2}k(l - L_0)^2$$
> 其中 $L_0$ 是弹簧原长，$l$ 是当前长度。

#### 弹簧连接体问题 —— 两守恒联立的经典范式

**两球-弹簧系统（光滑水平面）**：

两质量均为 $m$ 的物体由弹簧（劲度系数 $k$）连接。给左球一个瞬时冲量，使其获得速度 $v_0$。求弹簧最大压缩量。

1. **动量守恒**（水平方向合外力为零）：$mv_0 = mv_1 + mv_2 \;\Rightarrow\; v_1 + v_2 = v_0$
2. **机械能守恒**（无摩擦、弹簧是保守力）：$\frac{1}{2}mv_0^2 = \frac{1}{2}mv_1^2 + \frac{1}{2}mv_2^2 + \frac{1}{2}k(\Delta x)^2$
3. **最大压缩条件**：$v_1 = v_2 = v_0/2$（两球速度相同的瞬间，弹簧不再继续压缩）
4. 代入：$\frac{1}{2}mv_0^2 = \frac{1}{2}m\left(\frac{v_0}{2}\right)^2 \times 2 + \frac{1}{2}k(\Delta x_{\max})^2$
5. 解得：$\boxed{\Delta x_{\max} = v_0\sqrt{\dfrac{m}{2k}}}$

> ✅ **本节检查**：如果桌面有摩擦（$\mu \neq 0$），机械能还守恒吗？如果不守恒，少掉的能量去哪了？

### §2-7 变质量问题

> 📌 本节用单质点视角处理变质量问题。第三章 §3-6 将从动量守恒视角给出更系统的处理——两种方法本质上等价。 —— 质量不再是常数的世界

#### 为什么学这个？

火箭喷出燃气减重、雨滴下落吸附水汽增重、链条从桌面滑落……这些系统中质量随时间变化，经典的 $F=ma$ 不再成立。变质量问题教会我们**从动量视角看世界**，而不是死守 $F=ma$。

#### 核心公式

$$\boxed{\vec{F} = \frac{d}{dt}(m\vec{v}) = m\frac{d\vec{v}}{dt} + \vec{v}\frac{dm}{dt}}$$

- $\vec{F}$ 是**系统受到的合外力**（不包括质量流入/流出时的内部作用力）
- $m\frac{d\vec{v}}{dt}$：质量变化率为零时的加速度项（经典 $ma$）
- $\vec{v}\frac{dm}{dt}$：质量变化带来的动量变化率

> 💡 **老师强调**：不要死记公式！核心是**动量的增量 = 合外力对时间的积累**。无论落链、漏斗装沙还是火箭喷射，本质都是在求 $\Delta\vec{p}$。

#### 特殊情况：吸附物初速度为零

当被吸附的物质在吸附前速度为零（如落链中即将离开桌面的链节、漏斗中下落的沙子），则 $\vec{v}_{\text{吸附物}} = 0$，$\vec{v}\frac{dm}{dt} = 0$：

$$\vec{F} = m\frac{d\vec{v}}{dt}$$

> ⚠️ 注意：此时 $m$ 仍然是时变的！虽然公式形式与 $F=ma$ 相同，但 $m$ 不再是常数。

#### 两类经典变质量问题

| 类型 | 质量变化 | 典型例子 | 关键 |
|------|---------|---------|------|
| **减质量** | $\frac{dm}{dt} < 0$ | 火箭喷射燃料 | 排出物带走动量 |
| **增质量** | $\frac{dm}{dt} > 0$ | 落链、雨滴增长 | 吸附物引入动量 |

<details>
<summary>📐 例题：落链问题（完整推导）</summary>

**题目**：均匀链条总长 $L$、总质量 $M$。$t=0$ 时链条自然下垂，下垂长度 $x_0$。桌面光滑。求链条脱离桌面瞬间的速度。

**解**（用动能定理 + 微积分）：

1. **受力**：下垂部分受重力 $mg = \frac{M}{L}x \cdot g$，桌上部分受支持力与重力平衡（不做功）
2. **功**：重力做功 $A = \int_{x_0}^{L} \frac{M}{L}x\,g\,dx = \frac{Mg}{L} \cdot \frac{L^2 - x_0^2}{2}$
3. **动能定理**：$A = \frac{1}{2}Mv^2 - 0$
4. **解得**：$v = \sqrt{gL\left(1 - \frac{x_0^2}{L^2}\right)}$

若 $x_0 \to 0$（初始几乎全部在桌面），$v \to \sqrt{gL}$。
</details>

<details>
<summary>📐 例题：火箭问题（齐奥尔科夫斯基公式思路）</summary>

火箭以相对速度 $u$ 向后喷出燃气，火箭质量 $m(t)$ 递减。取火箭 + 喷出燃气为系统：

1. $dt$ 时间内喷出质量 $-dm$（$dm < 0$），获得速度增量 $dv$
2. 动量守恒：$mv = (m+dm)(v+dv) + (-dm)(v-u)$
3. 整理得：$m\,dv = -u\,dm$
4. 积分：$\displaystyle\int_{v_0}^{v} dv = -u\int_{m_0}^{m} \frac{dm}{m} \;\Rightarrow\; v - v_0 = u\ln\frac{m_0}{m}$

这就是著名的**齐奥尔科夫斯基公式**：$\boxed{\Delta v = u\ln\dfrac{m_0}{m}}$

> 💡 提高末速度的关键：增大喷气速度 $u$，或提高质量比 $m_0/m$。
</details>

### §2-8 卫星运动与黑洞概念（拓展）

#### 第一宇宙速度（环绕速度）

卫星绕地球做匀速圆周运动，万有引力提供向心力：

$$\frac{GMm}{R^2} = \frac{mv^2}{R} \quad\Rightarrow\quad \boxed{v_1 = \sqrt{\frac{GM}{R}}}$$

对地球（$M \approx 5.97\times 10^{24}\ \text{kg}$，$R \approx 6371\ \text{km}$）：$v_1 \approx 7.9\ \text{km/s}$

#### 第二宇宙速度（逃逸速度）

逃逸条件：动能 ≥ 从地表到无穷远的引力势能增量：

$$\frac{1}{2}mv^2 - \frac{GMm}{R} = 0 \quad\Rightarrow\quad \boxed{v_2 = \sqrt{\frac{2GM}{R}} = \sqrt{2}\,v_1}$$

对地球：$v_2 \approx 11.2\ \text{km/s}$

> **直觉类比**：就像你想跳出一个坑，动能必须足够克服重力做的负功。逃逸速度就是「刚好能跳出地球引力坑」的最低速度。

#### 黑洞的史瓦西半径

逃逸速度达到光速 $c$ 时，连光都无法逃脱：

$$v_{\text{逃逸}} = \sqrt{\frac{2GM}{R}} \geq c \quad\Rightarrow\quad \boxed{R_s = \frac{2GM}{c^2}}$$

$R_s$ 称为**史瓦西半径**。任何物体被压缩到自身史瓦西半径以内，就成为黑洞。

> 💡 「吸收」指的是吸收电磁波（光/射电等）。任何密度极大的天体（中子星等）都有类似效应，不是黑洞独有。

| 天体 | 质量 | 史瓦西半径 |
|------|------|:---:|
| 地球 | $6\times 10^{24}\ \text{kg}$ | $\sim 9\ \text{mm}$ |
| 太阳 | $2\times 10^{30}\ \text{kg}$ | $\sim 3\ \text{km}$ |
| 超大质量黑洞 | $10^9 M_\odot$ | $\sim 3\times 10^9\ \text{km}$（约 20 AU）|

| C3 | 质量 $m$ 的小球系于轻绳一端，另一端固定在光滑水平面的钉子上。给小球一个垂直于绳的初速度 $v_0$，绳渐渐绕在钉子上，绳长从 $r_0$ 减至 $r_0/2$。求此时小球的速度和绳中张力。 | 绳子拉力沿径向（有心力），力矩为零 → 角动量守恒：$mr_0v_0 = m(r_0/2)v \Rightarrow v = 2v_0$。张力 $T = mv^2/(r_0/2) = m(4v_0^2)/(r_0/2) = 8mv_0^2/r_0$。 |
| C4 | 两颗相同卫星 A 和 B，A 在轨道半径 $r$ 上做圆周运动，B 在 $2r$ 上。比较它们的：线速度比、周期比、总机械能比。 | $v \propto 1/\sqrt{r}$ → $v_A/v_B = \sqrt{2}$；由开普勒第三定律 $T \propto r^{3/2}$ → $T_A/T_B = 2^{-3/2}$；$E = -\frac{GMm}{2r}$ → $E_A/E_B = 2$（A 势能更低但动能更高，综合更负即更束缚）。 |

## ⚠️ 常见错误 Top 10

| # | 错误 | 正确理解 |
|:---:|------|------|
| 1 | 把冲量当成状态量，问「某一时刻的冲量」 | 冲量是过程量，必须对应时间间隔：$\vec{I} = \int_{t_1}^{t_2} \vec{F}\,dt$ |
| 2 | 把功当成状态量，问「某一时刻做的功」 | 功也是过程量，对应位移：$A = \int \vec{F}\cdot d\vec{r}$。只有动能才是状态量！|
| 3 | 在变质量问题中仍用 $F=ma$ | $m$ 不是常数时必须用 $F = d(mv)/dt$！火箭、落链、雨滴都在此列 |
| 4 | 弹簧弹性势能用总长度 $l$ 而非形变量 $\Delta x$ | 正确：$E_p = \frac{1}{2}k(l-L_0)^2$，$L_0$ 是原长 |
| 5 | 认为一对内力做功之和一定为零 | 内力做功之和 = 力 × 相对位移。摩擦力对滑块-车板系统的总功 = $-fL$ ≠ 0 |
| 6 | 混淆角动量守恒条件（合外力矩为零）和动量守恒条件（合外力为零） | 有心力力矩为零但力不为零 → 角动量守恒但动量不守恒 |
| 7 | 机械能守恒时忘记排除非保守力 | 有摩擦力 → 机械能减小（转化为内能），不守恒 |
| 8 | 忘记载体（矢量）方向 | 动量定理和动量守恒是矢量方程，必须选正方向，所有速度带符号 |
| 9 | 认为只要合外力为零，角动量也一定守恒 | 正确（充分条件），但逆命题不成立：角动量守恒不需要合外力为零 |
| 10 | 混淆第一和第二宇宙速度 | 第一宇宙速度（环绕）：$v_1 = \sqrt{GM/R}$ → 圆周轨道。第二宇宙速度（逃逸）：$v_2 = \sqrt{2}\,v_1$ → 脱离地球引力束缚 |

## 📋 公式速查

### 核心定理

| 定理 | 公式 | 物理含义 |
|------|------|------|
| 牛顿第二定律 | $\vec{F} = \dfrac{d\vec{p}}{dt}$ | 力 = 动量变化率 |
| 动量定理 | $\vec{I} = \Delta\vec{p} = m\vec{v}_2 - m\vec{v}_1$ | 冲量 = 动量增量 |
| 动能定理 | $A = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$ | 功 = 动能增量 |
| 角动量定理 | $\vec{M} = \dfrac{d\vec{L}}{dt}$ | 力矩 = 角动量变化率 |
| 机械能守恒 | $E_k + E_p = \text{常量}$（条件：只有保守力做功） | 动能 + 势能 = 不变 |

### 守恒定律条件

| 守恒量 | 条件 | 公式 |
|--------|------|------|
| 动量 | $\sum\vec{F}_{\text{外}} = 0$ | $\sum m_i\vec{v}_i = \text{常数}$ |
| 角动量 | $\sum\vec{M}_{\text{外}} = 0$ | $\sum \vec{r}_i\times m_i\vec{v}_i = \text{常数}$ |
| 机械能 | $A_{\text{外}}=0$ 且 $A_{\text{非保守内}}=0$ | $E_k + E_p = \text{常数}$ |

### 保守力与势能

| 保守力 | 势能 | $F = -dE_p/dx$ |
|--------|------|----------------|
| 重力（近地表） | $mgh$ | $-mg$ |
| 万有引力 | $-\dfrac{GMm}{r}$ | $-\dfrac{GMm}{r^2}$ |
| 弹簧弹力 | $\dfrac{1}{2}kx^2$ | $-kx$ |
| 静电力 | $\dfrac{kq_1q_2}{r}$ | $\dfrac{kq_1q_2}{r^2}$ |

### 宇宙速度

| 速度 | 公式 | 地球值 |
|------|------|:---:|
| 第一宇宙速度（环绕）| $v_1 = \sqrt{GM/R}$ | $7.9\ \text{km/s}$ |
| 第二宇宙速度（逃逸）| $v_2 = \sqrt{2GM/R}$ | $11.2\ \text{km/s}$ |
| 史瓦西半径 | $R_s = 2GM/c^2$ | — |

### 变质量问题

$$\vec{F} = \frac{d(m\vec{v})}{dt} = m\frac{d\vec{v}}{dt} + \vec{v}\frac{dm}{dt}$$

**齐奥尔科夫斯基公式**：$\Delta v = u\ln\dfrac{m_0}{m}$（火箭，忽略外力）
