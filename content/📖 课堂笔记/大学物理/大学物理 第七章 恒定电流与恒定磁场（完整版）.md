# 第七章 恒定电流与恒定磁场（完整版）

> 📝 **整合来源**：郭华忠老师第七章课件（§7.1–§7.8），涵盖恒定电流、磁感应强度、毕奥-萨伐尔定律、高斯定理、安培环路定理、洛伦兹力、安培力、磁介质。
>
> 本章是电磁学从"静"到"动"的转折点——前两章研究**静止电荷**产生的静电场，本章研究**运动电荷（恒定电流）** 产生的恒定磁场。

---

## 🏔️ 直觉地图

> **磁场线 = 闭合水流，安培环路 = 绕广场走一圈，洛伦兹力 = 侧风推人。**

这一章的核心图像可以这样理解：

- **电流**是"河流"——电荷往前走，周围就产生磁场。水流越快、水越多，周围的漩涡越强。电流密度 $\vec{J}$ 就是"水流密度"。
- **电源电动势**是"水泵"——把水从低处抽到高处。外电路电荷从高电势滚到低电势（水往低处流），内电路中水泵（非静电力）把电荷从低电势推回高电势。
- **磁感应线**是**闭合的环**，没有起点也没有终点——像漩涡，不像电场线有头有尾（正电荷发出、负电荷汇聚）。磁场是**无源场**（高斯定理 = 0），电场是**有源场**。
- **毕奥-萨伐尔定律**是磁学的"库仑定律"——每个电流元都是一小段"发条"，在周围空间拧出磁场。所有电流元的磁场叠加起来就是总场。
- **安培环路定理**：绕闭合环路走一圈，磁场沿环路做的"功"（环流）等于环路内穿过的总电流乘 $\mu_0$。类比：绕广场走一圈，你感受到的风的总推动力 = 广场里有多少人在跑（电流）——外面跑的人也会吹风到你身上，但他们每圈进出的推动作用互相抵消。
- **洛伦兹力**：带电粒子在磁场中运动，受到一个垂直于速度和磁场的力。像侧风推人——不让你加速也不让你减速（不做功），只让你拐弯。
- **安培力**：载流导线在磁场中受力——本质是导线里每个运动的电荷都受洛伦兹力，加起来就是整根导线的受力。

## 🔗 从静电到磁场——运动电荷打开新世界

> 第五章和第六章研究的是**静止电荷**产生的静电场：库仑定律、高斯定理、电势……一切都是从"电荷不动"出发的。
>
> 这一章，电荷**动起来**了——恒定电流（电荷的恒定流动）产生了**磁场**。从此，电和磁不再孤立：**运动电荷是磁场的源**，电流元相当于磁学中的"点电荷"。
>
> 你会发现惊人的对称性：毕奥-萨伐尔定律 ↔ 库仑定律（都是 $1/r^2$ 衰减）；安培环路定理 ↔ 高斯定理（都用对称性简化计算）；磁场高斯定理 = 0 ↔ 电场高斯定理 $\neq$ 0（有源 vs 无源）。但不对称的地方同样重要：电力线有头有尾，磁感应线永远是闭合的——这决定了两个场的本质区别。

### §7.1 恒定电流——磁场的"发动机"

#### 为什么先学电流？

磁场由**运动的电荷**产生。没有电流就没有（恒定）磁场。这一节建立描述电流的语言，为后续所有磁场计算打好基础。

#### 电流与电流密度

**电流强度**（标量）：

$$\boxed{I = \frac{dq}{dt}}$$

恒定电流：$I = \text{恒量}$（单位时间内通过导体截面的电荷量恒定）。

但 $I$ 只能描述**总流量**，无法描述电流在截面上的**分布**。引如**电流密度矢量** $\vec{J}$：

$$\boxed{\vec{J} = nq\vec{v}_d}$$

| 符号 | 含义 | 单位 |
|:--:|------|:--:|
| $n$ | 载流子浓度（单位体积载流子数） | $\text{m}^{-3}$ |
| $q$ | 每个载流子的电荷量 | C |
| $\vec{v}_d$ | 漂移速度（载流子定向运动的平均速度） | m/s |

$\vec{J}$ 的方向 = 正电荷运动方向。大小 = 通过垂直于电流方向的单位面积的电流。

通过任意曲面 $S$ 的电流：

$$\boxed{I = \int_S \vec{J} \cdot d\vec{S}}$$

> 🚰 **水管类比**：$I$ 是水管出口总流量（每秒多少升），$\vec{J}$ 是水管截面上各点的流速分布（有的地方流得快有的慢）。$I = \int \vec{J}\cdot d\vec{S}$ 就是把截面上每一点的小流速加起来。

> ⚡ **漂移速度有多慢？** 铜导线中自由电子密度 $n \approx 8.5 \times 10^{28}\,\text{m}^{-3}$，若 $I = 1\,\text{A}$、截面积 $1\,\text{mm}^2$，则 $v_d \approx 7.4 \times 10^{-5}\,\text{m/s}$——比蜗牛爬还慢！但电磁场传播速度接近光速，所以一合开关灯就亮。

#### 电源与电动势

电源提供**非静电力**（化学力、电磁力等），在电源内部将正电荷从低电势推到高电势。

| 区域 | 电荷运动方向 | 做功的力 |
|------|------------|---------|
| 外电路 | 高电势 → 低电势 | 静电力 |
| 内电路（电源内部） | 低电势 → 高电势 | **非静电力** |

**非静电场强**：$\vec{E}_k = \vec{F}_k / q$（单位正电荷受到的非静电力）

**电动势**（电源的"总推动力"）：

$$\boxed{\mathcal{E} = \oint_L \vec{E}_k \cdot d\vec{l}}$$

将单位正电荷沿闭合回路移动一周，非静电力做的功。

> 🔋 **水泵类比**：电源 = 水泵。水（电荷）在外管道中从高处流到低处（外电路），水泵（电源的非静电力）把水从低处抽回高处（内电路）。电动势 = 水泵的扬程。

> 📌 **电动势的方向**：电源内部**电势升高的方向**（从负极到正极）。

### §7.2 磁场与磁感应强度——新物理量的诞生

#### 磁现象的发现

| 时间 | 发现 | 意义 |
|------|------|------|
| 古代 | 永磁体（N/S极），同性相斥异性相吸 | 磁极不能单独存在——切开一块磁铁，每块都仍有N/S极 |
| 1820 | **奥斯特实验**：电流使附近磁针偏转 | 电流产生磁场——电和磁首次建立联系 |
| 后续 | **安培分子电流假说**：一切磁现象的根源是电流 | 统一了永磁体和电磁体的本质 |

> 🧲 安培分子电流假说：每个分子相当于一个微小环形电流（分子磁矩），永磁体的磁性就是这些分子环流定向排列的宏观表现。所以——**所有的磁现象本质上都是电流产生的**。

#### 磁感应强度 $\vec{B}$

仿照用电场力定义 $\vec{E}$ 的方法，用磁场对运动电荷的力定义 $\vec{B}$：

$$\boxed{B = \frac{F_{\max}}{qv}}$$

单位：特斯拉（T），$1\,\text{T} = 1\,\text{N}/(\text{A·m})$。地磁场约 $5 \times 10^{-5}\,\text{T}$，医用 MRI 可达 1.5–3 T。

方向：$\vec{F}_{\max} \times \vec{v}$ 的方向（即小磁针 N 极所指的方向）。

#### 磁感应线——与电场线的根本区别

| | 电场线（静电场） | **磁感应线（磁场）** |
|------|------|------|
| 起点/终点 | 始于正电荷，终于负电荷 | **无起点、无终点——闭合曲线** |
| 是否闭合 | 不闭合（有源场） | **必闭合（无源场）** |
| 高斯定理 | $\oint \vec{E}\cdot d\vec{S} = \sum q/\varepsilon_0 \neq 0$ | $\oint \vec{B}\cdot d\vec{S} = 0$ |

四种典型电流的磁感应线分布：
- **条形磁铁**：外部 N → S，内部 S → N（闭合）
- **长直电流**：右手定则——右手握住导线，拇指指向电流方向，四指弯曲方向为 $\vec{B}$ 方向（同心圆）
- **圆形电流**：右手定则——右手四指弯曲方向为电流方向，拇指指向中心轴上 $\vec{B}$ 方向
- **螺线管**：内部 $\vec{B}$ 均匀，方向沿轴线（由右手定则确定）

> 💫 **漩涡 vs 喷泉**：电场线像喷泉——泉水从泉眼（正电荷）喷出，流入地漏（负电荷），有始有终。磁感应线像水中的漩涡——一直在转圈，既没有起点也没有终点。这是电场和磁场**最根本的区别**。

✅ **本节检查**：
- [ ] 磁感应线为什么一定是闭合的？试着用"没有磁单极子"来解释。
- [ ] $\vec{B}$ 的定义式 $B = F_{\max}/(qv)$ 中，为什么取"最大"磁场力？如果 $v \parallel B$，力是多少？
- [ ] 条形磁铁内部 $\vec{B}$ 的方向是什么？（注意：不是从 N 到 S！）

### §7.3 毕奥-萨伐尔定律——磁学的"库仑定律" ⭐核心

#### 定律内容

电流元 $Id\vec{l}$ 在距其 $\vec{r}$ 处产生的磁感应强度微元：

$$\boxed{d\vec{B} = \frac{\mu_0}{4\pi} \frac{Id\vec{l} \times \hat{r}}{r^2}}$$

其中 $\mu_0 = 4\pi \times 10^{-7}\,\text{T·m/A}$（真空磁导率）。

方向：由 $Id\vec{l} \times \hat{r}$ 确定——右手四指从 $Id\vec{l}$ 转向 $\hat{r}$，拇指方向即为 $d\vec{B}$ 方向。

> 🔗 **与库仑定律的平行结构**：
> $$d\vec{E} = \frac{1}{4\pi\varepsilon_0} \frac{dq}{r^2}\hat{r} \quad\leftrightarrow\quad d\vec{B} = \frac{\mu_0}{4\pi} \frac{Id\vec{l} \times \hat{r}}{r^2}$$
> 都是 $1/r^2$ 衰减，但电场是球对称（沿 $\hat{r}$），磁场是**叉积**方向（垂直于 $Id\vec{l}$ 和 $\hat{r}$ 所在平面）。

**叠加原理**：$\displaystyle\vec{B} = \int d\vec{B}$

#### 四大经典应用

> 📐 以下四个应用的积分推导是本章的**计算基本功**——考试大概率考至少一个。

---

**应用一：载流直导线的磁场**

有限长直导线，距导线垂直距离 $a$ 处：

$$\boxed{B = \frac{\mu_0 I}{4\pi a}(\cos\theta_1 - \cos\theta_2)}$$

其中 $\theta_1$、$\theta_2$ 分别为场点到导线两端的连线与电流方向的夹角。

| 极限情况 | 公式 | 
|---------|------|
| 无限长直导线（$\theta_1 = 0,\;\theta_2 = \pi$） | $\boxed{B = \dfrac{\mu_0 I}{2\pi a}}$ |
| 半无限长直导线（一端延伸到无穷远） | $\boxed{B = \dfrac{\mu_0 I}{4\pi a}}$ |

> 📏 **直觉检验**：无限长 > 半无限长（两倍的源头 → 两倍的场）✅。距离翻倍 → $B$ 减半（$1/a$ 衰减）✅。

---

**应用二：圆形载流线圈轴线上的磁场** ⭐最常考

半径 $R$ 的圆电流，轴线上距圆心 $x$ 处：

$$\boxed{B = \frac{\mu_0 I R^2}{2(x^2 + R^2)^{3/2}}}$$

方向沿轴线，由右手定则确定。

| 特例 | $B$ 值 |
|------|--------|
| 圆心处 ($x = 0$) | $\boxed{B = \dfrac{\mu_0 I}{2R}}$ |
| 远场 ($x \gg R$) | $B \approx \dfrac{\mu_0 I R^2}{2x^3}$ |

**磁矩**（载流线圈的"磁性身份证"）：

$$\boxed{\vec{m} = NI\vec{S} = NIS\,\hat{n}}$$

其中 $S$ 为线圈面积，$\hat{n}$ 为法向（右手定则：四指沿电流方向，拇指为 $\hat{n}$）。

有了磁矩，圆电流远场可简洁写为：

$$\boxed{B = \frac{\mu_0}{2\pi}\frac{m}{x^3}}$$

> 🧲 **类比电偶极子**：电场中 $\vec{p} = q\vec{l}$（电偶极矩），远场 $E \propto p/r^3$；磁场中 $\vec{m} = NIS\hat{n}$（磁矩），远场 $B \propto m/r^3$。结构完全平行！

> 📍 **喘口气** ——前面两个应用（直导线 + 圆线圈）是考试最高频的计算题，建议先把它们的推导练熟（遮住笔记自己推一遍），再往下看螺线管和运动电荷。

---

**应用三：载流直螺线管轴线上的磁场**

单位长度匝数 $n$ 的螺线管，轴线上：

$$\boxed{B = \frac{\mu_0 nI}{2}(\cos\theta_2 - \cos\theta_1)}$$

其中 $\theta_1$、$\theta_2$ 为场点到螺线管两端的连线与轴线的夹角。

无限长螺线管内部（$\theta_1 \to \pi,\;\theta_2 \to 0$）：

$$\boxed{B = \mu_0 nI}$$

> 📐 **从有限长到无限长**：有限长公式 $B = \frac{\mu_0 nI}{2}(\cos\theta_2 - \cos\theta_1)$ 中，当螺线管无限长时，场点到两端的张角分别趋近 $\theta_1 \to 180°$（$\cos\theta_1 = -1$）和 $\theta_2 \to 0°$（$\cos\theta_2 = 1$），代入得 $B = \frac{\mu_0 nI}{2}(1 - (-1)) = \mu_0 nI$。

> 🎯 无限长螺线管内部是**均匀磁场**——方向和大小处处相同。这是实验中最常用的均匀磁场源。

---

**应用四：运动电荷的磁场**

以速度 $\vec{v}$ 运动的点电荷 $q$，在距其 $\vec{r}$ 处产生的磁场：

$$\boxed{\vec{B} = \frac{\mu_0}{4\pi} \frac{q\vec{v} \times \hat{r}}{r^2}}$$

这就是毕奥-萨伐尔定律的微观形式（$Id\vec{l} \to q\vec{v}$）。

**经典例子**：氢原子轨道磁矩

电子以速度 $v$ 绕核做圆周运动（半径 $r$），轨道角动量 $L = m_e vr$。

轨道磁矩：$\mu = I \cdot \pi r^2 = \frac{e}{T} \cdot \pi r^2 = \frac{ev}{2\pi r} \cdot \pi r^2 = \frac{evr}{2}$

$$\boxed{\vec{\mu} = -\frac{e}{2m_e}\vec{L}}$$

> 🔬 负号表明：电子带负电，磁矩方向与角动量方向相反。这个关系是原子磁性的理论基础。

### §7.4 磁场中的高斯定理——磁场没有"源"

#### 磁通量

仿照电通量，定义通过曲面 $S$ 的磁通量：

$$\boxed{\Phi_m = \int_S \vec{B} \cdot d\vec{S}}$$

单位：韦伯（Wb），$1\,\text{Wb} = 1\,\text{T·m}^2$。

#### 磁场高斯定理

$$\boxed{\oint_S \vec{B} \cdot d\vec{S} = 0}$$

**物理意义**：磁场是**无源场**——磁感应线永远是闭合曲线，没有起点也没有终点。这等价于**不存在磁单极子**（迄今为止所有实验均未发现）。

#### 与电场高斯定理的对比

| | 电场（静电场） | 磁场 |
|------|------|------|
| 高斯定理 | $\displaystyle\oint_S \vec{E}\cdot d\vec{S} = \frac{\sum q_i}{\varepsilon_0}$ | $\displaystyle\oint_S \vec{B}\cdot d\vec{S} = 0$ |
| 场线特点 | 始于正电荷，终于负电荷（不闭合） | **闭合曲线，无起点无终点** |
| 场的类型 | **有源场** | **无源场** |
| 微分形式 | $\nabla\cdot\vec{E} = \rho/\varepsilon_0$ | $\nabla\cdot\vec{B} = 0$ |

> 🧲 **最深刻的对比**：找遍全宇宙，你可以找到一个**单独的正电荷**（质子），却永远找不到一个**单独的 N 极**（磁单极子）。这就是磁场高斯定理 = 0 的根本原因。

### §7.5 安培环路定理——磁场的"高斯定理" ⭐核心

#### 定理内容

真空中，磁感应强度沿任意闭合环路的线积分，等于环路所包围的电流代数和的 $\mu_0$ 倍：

$$\boxed{\oint_L \vec{B} \cdot d\vec{l} = \mu_0 \sum I_{\text{内}}}$$

#### 三个最容易混淆的点（与高斯定理一模一样的问题结构！）

| 易混淆点 | 正确理解 |
|---------|---------|
| ① $\vec{B}$ 是**谁的**场？ | $\vec{B}$ 是**空间所有电流**在该点产生的**总场**（不仅是环路内电流） |
| ② $\sum I_{\text{内}}$ 是哪些电流？ | 仅包含**环路所包围**的电流的代数和 |
| ③ 环路外电流能影响环流吗？ | 不能——外部电流的 $\vec{B}$ 沿环路的线积分为零 |

> 🏟️ **绕广场走一圈**：广场内有很多人在跑步（电流），广场外也有。你绕广场走一圈，**只有广场里面的人**的总跑步量决定你感受的"总推动力"（环流）。外面的人的"推动"走一圈后正负抵消。但你在路径上任意一点的瞬间感受（$B$），是由广场内外所有人共同决定的。

#### 电流的符号约定

右手定则：右手四指沿**环路绕行方向**弯曲，拇指指向穿过环路的电流方向——与拇指同向的 $I$ 取正，反向取负。

#### 能用安培环路定理直接求 $\vec{B}$ 吗？

⚠️ 安培环路定理**永远成立**，但要用来直接求出 $B$ 的数值，需要：

1. **对称性**：载流系统具有足够对称性（柱对称 / 螺线管 / 螺线环）
2. **环路选取**：环路上 $B$ 大小处处相等，且与 $d\vec{l}$ 夹角恒为 $0°$ 或 $90°$
3. **$B$ 可提出积分号**：若环路上各处 $B$ 大小不同，不能直接求解

> 📝 与高斯定理的平行结构：高斯定理用对称性求 $E$，安培环路定理用对称性求 $B$——两者是电磁学最漂亮的"对称性简化法"。

#### 三大经典应用

---

**应用一：长直螺线管内部磁场**

$$\boxed{B = \mu_0 nI}$$

$n = N/L$ 为单位长度匝数。无限长螺线管内部是**均匀磁场**。

> 推导要点：矩形环路，一条边在管内（$B$ 待求），一条边在管外很远处（$B \approx 0$），两条边垂直于管轴（$\vec{B} \perp d\vec{l}$，无贡献）。

---

**应用二：螺线环内部磁场**

$$\boxed{B = \frac{\mu_0 NI}{2\pi r}}$$

$N$ 为总匝数，$r$ 为环内某点到环心的距离。

> 推导要点：取半径为 $r$ 的同心圆为环路，环路包围的电流 = $NI$（$N$ 匝每匝穿过环路一次）。

当螺线环截面很小时（$r \approx R$），$B \approx \mu_0 nI$（回归到长直螺线管的结果）。

---

**应用三：无限长载流圆柱导体的磁场**

| 区域 | $B$ | 说明 |
|------|-----|------|
| 柱外 ($r > R$) | $\boxed{B = \dfrac{\mu_0 I}{2\pi r}}$ | 等效于所有电流集中在轴线 |
| 柱内 ($r < R$) | $\boxed{B = \dfrac{\mu_0 I r}{2\pi R^2}}$ | 正比于 $r$（电流均匀分布在截面） |
| 柱面 ($r = R$) | $B = \dfrac{\mu_0 I}{2\pi R}$ | 两种极限的连续过渡 |

> 推导要点：取半径为 $r$ 的同心圆为环路。柱内包围的电流按面积比计算：$I_{\text{内}} = I \cdot (r^2/R^2)$。

> 📐 **用安培环路定理解题的通用步骤**：
> ①分析对称性 → ②选取合适的安培环路 → ③计算环流 $\oint \vec{B}\cdot d\vec{l}$ → ④计算环路内包围的电流代数和 → ⑤代入定理 → ⑥解出 $B$ → ⑦极限检验

#### 安培环路定理与高斯定理的完美对称

| | 高斯定理（电场） | 安培环路定理（磁场） |
|------|------|------|
| 公式 | $\oint \vec{E}\cdot d\vec{S} = \sum q/\varepsilon_0$ | $\oint \vec{B}\cdot d\vec{l} = \mu_0\sum I$ |
| 积分类型 | **面积分**（闭合曲面） | **线积分**（闭合环路） |
| 源 | 电荷 $q$ | 电流 $I$ |
| 对称性 | 球/柱/面对称 → 高斯面 | 柱/螺线管/螺线环 → 安培环路 |
| 计算前提 | $E$ 在面上大小恒定 | $B$ 在环路上大小恒定 |

### §7.6 磁场对运动电荷的作用——洛伦兹力

#### 洛伦兹力

$$\boxed{\vec{F} = q\vec{v} \times \vec{B}}$$

**三大特征**：

| 特征 | 说明 |
|------|------|
| $\vec{F} \perp \vec{v}$ 且 $\vec{F} \perp \vec{B}$ | $\vec{F}$ 垂直于 $\vec{v}$ 和 $\vec{B}$ 所在平面 |
| **不做功** | 力始终垂直于速度 → $P = \vec{F}\cdot\vec{v} = 0$ → 动能不变 |
| 只改变方向不改变速率 | 做匀速圆周运动或螺旋运动 |

> 🌬️ **侧风类比**：你在一个广场上跑，一阵侧风推你。风的方向始终垂直于你跑步的方向——风不让你跑更快也不让你跑更慢，只让你拐弯。磁场对带电粒子的力就是这样。

#### 三种运动模式

| 初速度方向 | 运动类型 | 关键公式 |
|:--:|------|------|
| $\vec{v} \parallel \vec{B}$ | 匀速直线运动 | — |
| $\vec{v} \perp \vec{B}$ | **匀速圆周运动** | $R = \dfrac{mv}{qB}$，$T = \dfrac{2\pi m}{qB}$ |
| $\vec{v}$ 与 $\vec{B}$ 成 $\theta$ 角 | **螺旋运动** | $R = \dfrac{mv\sin\theta}{qB}$，螺距 $h = \dfrac{2\pi m v\cos\theta}{qB}$ |

> 🔬 **重要性质**：$T = 2\pi m/(qB)$ **与速度无关**！这意味着一束速度不同但 $q/m$ 相同的粒子在均匀磁场中的回旋周期相同——这是**回旋加速器**的理论基础。

#### 应用速查表

| 应用 | 原理 | 关键公式 |
|------|------|---------|
| **速度选择器** | $F_E = F_B$ 时粒子直线通过 | $\boxed{v = \dfrac{E}{B}}$ |
| **汤姆孙实验** | 电场偏转 + 磁场补偿 → 测比荷 | $\dfrac{e}{m} = \dfrac{E}{\theta B^2 L}$ |
| **质谱仪** | $R = \dfrac{mv}{qB}$ → 不同 $m/q$ 粒子分开 | 分离同位素 |
| **霍耳效应** | 磁场使载流子偏转 → 横向电势差 | $\boxed{U_H = \dfrac{1}{nq}\dfrac{IB}{d} = R_H\dfrac{IB}{d}}$ |
| **回旋加速器** | $T$ 与 $v$ 无关 → 周期性加速 | $T = 2\pi m/(qB)$ |

#### 霍耳效应详解

当电流通过置于磁场中的导体/半导体时，载流子在洛伦兹力作用下偏转，在导体两侧产生横向电势差：

$$\boxed{U_H = R_H \frac{IB}{d}}$$

其中霍耳系数 $R_H = \dfrac{1}{nq}$。

| 载流子类型 | $R_H$ 符号 | 应用 |
|:--:|:--:|------|
| 正电荷（p 型半导体） | $R_H > 0$ | 判断半导体类型 |
| 负电荷（n 型半导体） | $R_H < 0$ | 测量载流子浓度 $n$ |

> 🎯 霍耳效应是半导体物理的基础测量手段——测出 $U_H$ → 算出 $R_H$ → 判断是 p 型还是 n 型 → 算出载流子浓度。一个实验，得两个物理量。

### §7.7 磁场对载流导线的作用——安培力

#### 安培定律

载流导线上的电流元在磁场中受力：

$$\boxed{d\vec{F} = Id\vec{l} \times \vec{B}}$$

这就是**安培定律**——本质上是导线中每个载流子所受洛伦兹力的宏观总和。

> 🔗 微观到宏观：$d\vec{F} = (nSdl) \cdot q\vec{v}_d \times \vec{B} = (nqSv_d) d\vec{l} \times \vec{B} = I d\vec{l} \times \vec{B}$。$nqSv_d = J \cdot S = I$。

#### 均匀磁场中载流直导线

$$\boxed{F = ILB\sin\theta}$$

其中 $\theta$ 为导线方向与 $\vec{B}$ 方向的夹角。

#### 平行电流间的相互作用

两根相距 $a$ 的无限长平行直导线，分别通以电流 $I_1$、$I_2$：

$$\boxed{\frac{F}{l} = \frac{\mu_0 I_1 I_2}{2\pi a}}$$

| 电流方向 | 相互作用 |
|:--:|:--:|
| **同向** | **相吸** 🤝 |
| **反向** | **相斥** 💥 |

> 📏 **"安培"的国际定义**（2019年前）：真空中相距 1 m 的两根无限长平行导线，通以相等电流，若单位长度受力为 $2\times 10^{-7}\,\text{N/m}$，则导线中电流为 1 A。
>
> （注：2019 年 SI 新定义后，"安培"改为由基本电荷 $e$ 定义，但上述"磁力定义"仍然是理解安培物理意义的最佳方式。）

#### 载流线圈在磁场中的磁力矩

$$\boxed{\vec{M} = \vec{m} \times \vec{B}}$$

其中 $\vec{m} = NIS\,\hat{n}$ 为线圈的磁矩。

| 角度 $\theta$（$\vec{m}$ 与 $\vec{B}$ 的夹角） | 物理状态 |
|:--:|------|
| $\theta = 0°$ | **稳定平衡**——$\vec{m} \parallel \vec{B}$，力矩为零 |
| $\theta = 90°$ | **力矩最大**——$M = mB$ |
| $\theta = 180°$ | **非稳定平衡**——$\vec{m} \uparrow\downarrow \vec{B}$，一扰动就翻转 |

> 🧲 **小磁针类比**：载流线圈在磁场中的行为就像一个微小的条形磁铁——它倾向于把自己的磁矩 $\vec{m}$ 转向与 $\vec{B}$ 平行的方向（N 极指向 S 极）。这就是为什么指南针的 N 极指向地理北极（地磁 S 极）。

#### 磁力矩的功

$$\boxed{A = I\Delta\Phi_m}$$

线圈在磁场中转动时，磁力矩做的功 = 电流 × 通过线圈的磁通量变化。这个公式在电动机和发电机的能量转换中至关重要。

### §7.8 磁介质——磁场中的物质

#### 磁化现象

磁介质在外磁场 $\vec{B}_0$ 中**磁化**，产生附加磁场 $\vec{B}'$。

总磁场：$\vec{B} = \vec{B}_0 + \vec{B}'$

**相对磁导率**：$\boxed{\mu_r = \dfrac{B}{B_0}}$，**磁导率**：$\boxed{\mu = \mu_0\mu_r}$

#### 四类磁介质

| 类型 | $\mu_r$ 值 | 特点 | 例子 |
|------|:--:|------|------|
| **顺磁质** | $\mu_r > 1$（略大于 1） | 有固有分子磁矩，外场下转向排列，$B'$ 与 $B_0$ 同向 | 铝、铂、氧 |
| **抗磁质** | $\mu_r < 1$（略小于 1） | 无固有分子磁矩，外场下产生反向感应磁矩，$B'$ 与 $B_0$ 反向 | 铜、铋、水 |
| **铁磁质** | $\mu_r \gg 1$（$10^2$–$10^5$） | 极强的磁化效应，$B$-$H$ 非线性，有磁滞回线 | 铁、钴、镍 |
| **完全抗磁体** | $\mu_r = 0$ | 内部 $B = 0$（迈斯纳效应） | 超导体（$T < T_c$） |

#### 磁化强度

单位体积内分子磁矩的矢量和：

$$\boxed{\vec{M} = \frac{\sum \vec{m}_i}{\Delta V}}$$

顺磁质中分子磁矩趋向于与 $\vec{B}_0$ 同向排列 → $\vec{M} \neq 0$；抗磁质中感应出反向磁矩 → $\vec{M}$ 与 $\vec{B}_0$ 反向。

#### 磁化电流

分子磁矩有序排列的宏观效果等价于在磁介质表面出现**磁化电流** $I_s$（也称束缚电流）。

> ⚡ 磁化电流与传导电流不同：磁化电流是分子环流的宏观表现，**不产生焦耳热**。

磁化电流面密度：$\boxed{j_s = M}$（数值上等于磁化强度）。

#### 磁场强度 $\vec{H}$ 与介质中的安培环路定理

引入辅助量——**磁场强度**：

$$\boxed{\vec{H} = \frac{\vec{B}}{\mu_0} - \vec{M}}$$

单位：A/m。

**有介质时的安培环路定理**：

$$\boxed{\oint_L \vec{H} \cdot d\vec{l} = \sum I_0}$$

其中 $\sum I_0$ 只包含**传导电流**（自由电流），不包含磁化电流。这是处理磁介质问题的核心工具！

> 🔑 **为什么引入 $\vec{H}$？** 因为 $\vec{B}$ 的环流涉及所有电流（传导 + 磁化），而磁化电流通常未知。$\vec{H}$ 的环流只涉及已知的传导电流，使问题大大简化。

#### 各向同性非铁磁质的本构关系

$$\vec{M} = \chi_m \vec{H}$$

$$\boxed{\vec{B} = \mu_0(1 + \chi_m)\vec{H} = \mu_0\mu_r\vec{H} = \mu\vec{H}}$$

其中 $\chi_m$ 为**磁化率**，$\mu_r = 1 + \chi_m$。

| 介质类型 | $\chi_m$ | $\mu_r$ |
|:--:|:--:|:--:|
| 顺磁质 | $> 0$（$10^{-6}$–$10^{-3}$） | $> 1$ |
| 抗磁质 | $< 0$（$10^{-6}$–$10^{-5}$） | $< 1$ |
| 真空 | $0$ | $1$ |

#### 铁磁质的特殊性

| 特征 | 描述 |
|------|------|
| **高磁导率** | $\mu_r$ 可达 $10^2$–$10^5$ |
| **$B$-$H$ 非线性** | $B$ 与 $H$ 不是正比关系 |
| **磁滞回线** | 磁化曲线不沿原路返回——剩磁 $B_r$ 和矫顽力 $H_c$ |
| **磁畴** | 铁磁质内部自发磁化的小区域（$10^{-12}$–$10^{-8}\,\text{m}^3$） |
| **居里点 $T_c$** | 超过此温度 → 铁磁质变为顺磁质（磁畴瓦解） |

<details>
<summary><b>磁滞回线关键参数图解</b></summary>

从 $H=0, B=0$ 出发：
1. $H$ 增大 → $B$ 沿初始磁化曲线上升 → 达到**饱和磁化** $B_s$
2. $H$ 减小 → $B$ 不沿原路返回 → 当 $H=0$ 时 $B = B_r$（**剩磁**）
3. 反向加 $H$ → $B$ 继续减小 → 当 $B=0$ 时 $H = -H_c$（**矫顽力**）
4. 继续反向 → 反向饱和 → 形成闭合的磁滞回线

> 磁滞回线面积 = 一个磁化循环中单位体积的**能量损耗**（以热的形式耗散）。
</details>

**铁磁材料分类**：

| 类型 | 矫顽力 | 剩磁 | 磁滞回线 | 应用 |
|------|:--:|:--:|:--:|------|
| **软磁材料** | 低 $H_c$ | 低 $B_r$ | 窄瘦 | 变压器铁芯、电磁铁 |
| **硬磁材料** | 高 $H_c$ | 高 $B_r$ | 宽胖 | 永磁铁、扬声器 |
| **矩磁材料** | — | — | 矩形 | 磁存储、磁芯存储器 |

> 🧲 软磁 = 容易磁化也容易退磁（省能）；硬磁 = 难磁化也难退磁（永磁）；矩磁 = 只有两种稳定状态（正好对应二进制的 0 和 1）。

#### 与电介质的对称对比

| | 电介质（第六章） | 磁介质（本章 §7.8） |
|------|------|------|
| 极化/磁化 | $\vec{P}$ — 电极化强度 | $\vec{M}$ — 磁化强度 |
| 辅助场 | $\vec{D} = \varepsilon_0\vec{E} + \vec{P}$ | $\vec{H} = \vec{B}/\mu_0 - \vec{M}$ |
| 介质定理 | $\oint \vec{D}\cdot d\vec{S} = \sum q_{\text{自由}}$ | $\oint \vec{H}\cdot d\vec{l} = \sum I_0$ |
| 本构关系 | $\vec{D} = \varepsilon\vec{E}$ | $\vec{B} = \mu\vec{H}$ |
| 极化/磁化率 | $\vec{P} = \varepsilon_0\chi_e\vec{E}$ | $\vec{M} = \chi_m\vec{H}$ |

## 二、电与磁——整章的对称性总结

| | 静电场（第五、六章） | 恒定磁场（第七章） |
|------|------|------|
| **源** | 静止电荷 $q$ | 运动电荷 / 恒定电流 $I$ |
| **基本定律** | 库仑定律 $F = \dfrac{1}{4\pi\varepsilon_0}\dfrac{q_1q_2}{r^2}$ | 毕奥-萨伐尔定律 $d\vec{B} = \dfrac{\mu_0}{4\pi}\dfrac{Id\vec{l}\times\hat{r}}{r^2}$ |
| **场的定义** | $\vec{E} = \vec{F}/q$ | $B = F_{\max}/(qv)$ |
| **高斯定理** | $\oint \vec{E}\cdot d\vec{S} = \sum q/\varepsilon_0$ | $\oint \vec{B}\cdot d\vec{S} = 0$ |
| **场的类型** | **有源场**（场线有头有尾） | **无源场**（场线必闭合） |
| **环路/安培定理** | $\oint \vec{E}\cdot d\vec{l} = 0$（保守场） | $\oint \vec{B}\cdot d\vec{l} = \mu_0\sum I_{\text{内}}$（非保守场） |
| **力** | $\vec{F} = q\vec{E}$ | $\vec{F} = q\vec{v}\times\vec{B}$（洛伦兹力） |
| **力做功？** | 可以做功（保守力） | **不做功**（力 $\perp$ 速度） |
| **介质** | 电介质：极化 → $\vec{D}$ | 磁介质：磁化 → $\vec{H}$ |

> 🎯 **核心洞察**：电场和磁场像一对双胞胎——很多性质完美对称（都有高斯定理和积分定理），但每个对称中又隐藏着关键的不对称。最根本的两个不对称：(1) **有源 vs 无源**（有没有磁单极子？）；(2) **保守 vs 非保守**（磁场力不做功！）。

<details>
<summary>答案</summary>

(1) 圆心：$B_0 = \dfrac{\mu_0 I}{2R} = \dfrac{4\pi\times 10^{-7} \times 2.0}{2 \times 0.10} = \dfrac{8\pi\times 10^{-7}}{0.20} = 4\pi\times 10^{-6} \approx 1.26\times 10^{-5}\,\text{T}$

$$B = \frac{\mu_0 I R^2}{2(x^2+R^2)^{3/2}} = \frac{4\pi\times 10^{-7} \times 2.0 \times 0.01}{2(0.04+0.01)^{3/2}}$$

### 🔴 C 组 — 综合应用（5 题，附提示）

**C1.** 一半径为 $R$ 的薄圆盘，均匀带电（面电荷密度 $\sigma$），以角速度 $\omega$ 绕通过圆心且垂直于盘面的轴旋转。求：(1) 盘心的磁感应强度；(2) 圆盘的磁矩。

> 💡 **提示**：(1) 将圆盘分割为无数个半径为 $r$、宽度为 $dr$ 的同心圆环，每个环 = 一个等效圆电流 $dI = \sigma \omega r\,dr$。所有圆环在圆心的磁场叠加。(2) 每个圆环的磁矩 $dm = \pi r^2\,dI$，积分得总磁矩。答案：(1) $B_0 = \dfrac{\mu_0\sigma\omega R}{2}$；(2) $m = \dfrac{\pi\sigma\omega R^4}{4}$。

**C2.** 一根无限长直导线弯成如图所示的形状（中间为一半径 $R$ 的半圆，两侧为直线段无限延伸）。导线通以电流 $I$。求半圆圆心 $O$ 处的磁感应强度。

> 💡 **提示**：这是"分段叠加"的典型题。三条线段分别贡献：①左端半无限长直线：$B_1 = \mu_0 I/(4\pi R)$（方向 ⊙）；②半圆弧：$B_2 = \mu_0 I/(4R)$（半圆弧贡献是整圆的一半）；③右端半无限长直线：$B_3 = \mu_0 I/(4\pi R)$（方向 ⊙）。三段同向叠加 → 总 $B = \dfrac{\mu_0 I}{2\pi R} + \dfrac{\mu_0 I}{4R}$。

**C3.** 一电子在互相垂直的均匀电场 $\vec{E}$ 和均匀磁场 $\vec{B}$ 中运动。已知 $E = 3.0\times 10^4\,\text{V/m}$，$B = 2.0\times 10^{-2}\,\text{T}$。若电子要作匀速直线运动，(1) 速度应多大？(2) 速度方向应如何？

> 💡 **提示**：(1) 匀速直线运动的条件是 $\sum\vec{F} = 0$，即 $q\vec{E} + q\vec{v}\times\vec{B} = 0$ → $\vec{E} + \vec{v}\times\vec{B} = 0$。(2) $\vec{v}$ 必须垂直于 $\vec{E}$ 和 $\vec{B}$ 两者，且大小满足 $v = E/B$（与速度选择器相同逻辑）。$v = 3.0\times 10^4 / 2.0\times 10^{-2} = 1.5\times 10^6\,\text{m/s}$。

**C4.** 一载流螺线环，平均半径 $R = 0.10\,\text{m}$，总匝数 $N = 500$，通以电流 $I = 2.0\,\text{A}$。环内充满相对磁导率 $\mu_r = 1000$ 的铁磁质。求环内 (1) 磁场强度 $H$；(2) 磁感应强度 $B$；(3) 磁化强度 $M$。

> 💡 **提示**：(1) 用介质中的安培环路定理：$\oint \vec{H}\cdot d\vec{l} = \sum I_0$ → $H \cdot 2\pi R = NI$ → $H = NI/(2\pi R)$。(2) $B = \mu_0\mu_r H$。(3) $M = (\mu_r - 1)H$（因为 $\vec{B} = \mu_0(\vec{H} + \vec{M})$）。数值：$H \approx 1.59\times 10^3\,\text{A/m}$，$B \approx 2.0\,\text{T}$，$M \approx 1.59\times 10^6\,\text{A/m}$。

**C5.** ⭐挑战题 无限大均匀载流平板（面电流密度 $j_s$，单位 A/m），求空间各点的磁感应强度。（提示：利用对称性和安培环路定理）

> 💡 **提示**：这是"安培环路定理在磁学中的典型应用"。面对称磁场 → 取矩形安培环路，两条边平行于平板。平板两侧的 $B$ 大小相等、方向相反（由对称性 + 右手定则确定）。结果：$\boxed{B = \dfrac{\mu_0 j_s}{2}}$（与距离无关，均匀场！）

> 类比：无限大均匀带电平面的电场 $E = \sigma/(2\varepsilon_0)$，也是不衰减的均匀场。二维对称性 → 不衰减，这是结构性的规律。

## ⚠️ 常见错误 Top 10

| # | 错误 | 正确理解 |
|:--:|------|----------|
| 1 | 毕奥-萨伐尔定律的 $dB$ 方向平行于 $Id\vec{l}$ | 错！方向由 $Id\vec{l} \times \hat{r}$ 决定，**垂直于** $Id\vec{l}$ 和 $\hat{r}$ 所在平面——用右手定则确定 |
| 2 | 安培环路定理的 $B$ 只是环路内电流的场 | $B$ 是**所有电流**的总场。环路内电流决定的是**环流**，不单独决定 $B$ |
| 3 | 洛伦兹力可以做功 | 永远不做功！$\vec{F} \perp \vec{v}$ → 功率 $P = \vec{F}\cdot\vec{v} = 0$。磁场只改变方向，不改变速率/动能 |
| 4 | 磁场高斯定理 = 0 意味着磁场比电场弱 | 不是！= 0 说明磁场是**无源场**（磁感应线闭合），不是弱。这跟磁场强度大小无关 |
| 5 | 磁感应线和电场线一样有起点和终点 | 电场线：正电荷 → 负电荷（不闭合）。**磁感应线：永远闭合**（无磁单极子） |
| 6 | 无限长直导线的 $B \propto 1/a$（一次方），觉得跟点电荷电场 $E \propto 1/r^2$ 矛盾 | 不矛盾！维度不同：点电荷是 0 维源 → $1/r^2$；无限长线是 1 维源 → $1/r$；无限大平面是 2 维源 → 不衰减。**维度越高，衰减越慢** |
| 7 | 圆形线圈轴线上 $B = \mu_0 I/(2R)$ 适用于任何位置 | 只适用于**圆心**（$x=0$）！一般位置 $B = \mu_0 I R^2/[2(x^2+R^2)^{3/2}]$ |
| 8 | 安培环路定理中，环路外电流对环流也有贡献 | 外部电流的 $B$ 沿环路有值，但走一圈的**线积分为零**（进的正功 = 出的负功） |
| 9 | 无限长螺线管内部 $B = \mu_0 nI$ 只在真空中成立 | 在介质中 $B = \mu_0\mu_r nI = \mu nI$（有铁芯时 $B$ 可增大上千倍！） |
| 10 | $U_H = R_H IB/d$ 中无论什么材料 $R_H$ 都是常数 | $R_H = 1/(nq)$，$n$ 和载流子类型因材料而异。p 型 $R_H>0$，n 型 $R_H<0$。对某些材料，$R_H$ 还会随温度变化 |

## 📋 公式速查

### 恒定电流

| 公式 | 含义 |
|------|------|
| $I = dq/dt$ | 电流强度定义 |
| $\vec{J} = nq\vec{v}_d$ | 电流密度矢量 |
| $I = \int_S \vec{J}\cdot d\vec{S}$ | 电流与电流密度的关系 |
| $\mathcal{E} = \oint \vec{E}_k \cdot d\vec{l}$ | 电动势定义 |

### 磁感应强度与毕奥-萨伐尔定律

| 公式 | 含义 |
|------|------|
| $B = F_{\max}/(qv)$ | 磁感应强度定义 |
| $d\vec{B} = \dfrac{\mu_0}{4\pi}\dfrac{Id\vec{l} \times \hat{r}}{r^2}$ | 毕奥-萨伐尔定律 |
| $B = \dfrac{\mu_0 I}{4\pi a}(\cos\theta_1 - \cos\theta_2)$ | 有限长直导线 |
| $B = \dfrac{\mu_0 I}{2\pi a}$ | 无限长直导线 |
| $B = \dfrac{\mu_0 I R^2}{2(x^2+R^2)^{3/2}}$ | 圆电流轴线上 |
| $B = \dfrac{\mu_0 I}{2R}$ | 圆电流圆心处 |
| $B = \dfrac{\mu_0 nI}{2}(\cos\theta_2 - \cos\theta_1)$ | 有限长螺线管轴线上 |
| $B = \mu_0 nI$ | 无限长螺线管内部 |
| $\vec{B} = \dfrac{\mu_0}{4\pi}\dfrac{q\vec{v} \times \hat{r}}{r^2}$ | 运动电荷的磁场 |
| $\vec{m} = NIS\,\hat{n}$ | 载流线圈的磁矩 |

### 磁场高斯定理与安培环路定理

| 公式 | 含义 |
|------|------|
| $\Phi_m = \int_S \vec{B}\cdot d\vec{S}$ | 磁通量定义 |
| $\displaystyle\oint_S \vec{B}\cdot d\vec{S} = 0$ | 磁场高斯定理（无源场） |
| $\displaystyle\oint_L \vec{B}\cdot d\vec{l} = \mu_0\sum I_{\text{内}}$ | 安培环路定理（真空） |
| $B = \dfrac{\mu_0 I r}{2\pi R^2}$（$r<R$） | 载流圆柱导体内部 |
| $B = \dfrac{\mu_0 I}{2\pi r}$（$r>R$） | 载流圆柱导体外部 |
| $B = \mu_0 nI$ | 长直螺线管内部（安培定理法） |
| $B = \dfrac{\mu_0 NI}{2\pi r}$ | 螺线环内部 |

### 磁场对运动电荷和载流导线的作用

| 公式 | 含义 |
|------|------|
| $\vec{F} = q\vec{v} \times \vec{B}$ | 洛伦兹力 |
| $R = \dfrac{mv}{qB}$ | 圆周运动半径（$v \perp B$） |
| $T = \dfrac{2\pi m}{qB}$ | 回旋周期（与 $v$ 无关！） |
| $h = \dfrac{2\pi m v\cos\theta}{qB}$ | 螺旋运动螺距 |
| $v = \dfrac{E}{B}$ | 速度选择器条件 |
| $U_H = R_H\dfrac{IB}{d},\; R_H = \dfrac{1}{nq}$ | 霍耳效应 |
| $d\vec{F} = Id\vec{l} \times \vec{B}$ | 安培定律 |
| $F = ILB\sin\theta$ | 均匀磁场中直导线受力 |
| $\dfrac{F}{l} = \dfrac{\mu_0 I_1 I_2}{2\pi a}$ | 平行电流间相互作用力 |
| $\vec{M} = \vec{m} \times \vec{B}$ | 载流线圈磁力矩 |
| $A = I\Delta\Phi_m$ | 磁力矩的功 |

### 磁介质

| 公式 | 含义 |
|------|------|
| $\mu_r = B/B_0$ | 相对磁导率 |
| $\mu = \mu_0\mu_r$ | 磁导率 |
| $\vec{M} = \sum\vec{m}_i/\Delta V$ | 磁化强度 |
| $\vec{H} = \vec{B}/\mu_0 - \vec{M}$ | 磁场强度定义 |
| $\displaystyle\oint_L \vec{H}\cdot d\vec{l} = \sum I_0$ | 介质中的安培环路定理 |
| $\vec{B} = \mu_0\mu_r\vec{H} = \mu\vec{H}$ | 各向同性非铁磁质的本构关系 |
| $\vec{M} = \chi_m\vec{H}$ | 磁化率关系 |
| $\mu_r = 1 + \chi_m$ | 相对磁导率与磁化率 |

### 电与磁的基本对比

| 定理 | 电场（静电场） | 磁场（恒定磁场） |
|------|------|------|
| 高斯定理 | $\oint \vec{E}\cdot d\vec{S} = \sum q/\varepsilon_0$ | $\oint \vec{B}\cdot d\vec{S} = 0$ |
| 环路/安培定理 | $\oint \vec{E}\cdot d\vec{l} = 0$（保守场） | $\oint \vec{B}\cdot d\vec{l} = \mu_0\sum I_{\text{内}}$ |
| 场的性质 | 有源无旋 | **无源有旋** |
| 场线 | 不闭合（正 → 负） | **必闭合** |
