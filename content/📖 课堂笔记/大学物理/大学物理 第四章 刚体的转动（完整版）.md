# 第四章 刚体的转动（完整版）

## 🔥 核心直觉

**"为什么学刚体转动？"** ——因为你不能一直把世界当成质点。现实中的物体有大小、有形状、会旋转。自行车轮、发动机飞轮、陀螺仪、地球自转——这些都不能用 $F=ma$ 简单描述。**转动力学 = 质点力学在旋转世界的平行宇宙**，公式一一对应，直觉一一相通。

## 🏔️ 直觉地图

> **转动惯量 $J$ = 旋转世界里的"质量"（惯性）。**
> 质量大 → 难推动；转动惯量大 → 难转动。
> 质量分布越远离转轴，$J$ 越大——就像推旋转门，手放边缘比放转轴旁边更有"重量感"。

> **角动量守恒 = 花样滑冰收臂加速。**
> 张臂时 $J$ 大、$\omega$ 小（转得慢）；收臂后 $J$ 变小、$\omega$ 变大（转得快）。
> $L=J\omega$ = 常数 —— 手臂靠近身体，身子转得更快，不需要额外用力！

> **$M=J\alpha$ 就是旋转版的 $F=ma$。**
> 力产生加速度；力矩产生角加速度。惯性抵挡加速度；转动惯量抵挡角加速度。
> 把「力→力矩」「质量→转动惯量」「加速度→角加速度」换了，一切都通了。

## 🔗 从质点到刚体——转动世界的入场券

> 前三章我们把所有物体都当**质点**处理——有质量、没大小、不会转。但现实世界不是这样：自行车轮会转、地球会自转、扳手拧螺丝时整个扳手在旋转。当你不能再忽略物体的形状和大小时，就进入了**刚体力学**。
>
> 好消息是：刚体力学不是"新"物理——它是质点力学的**旋转版**。把质量换成转动惯量、力换成力矩、速度换成角速度……规律的结构完全一样。本章就是帮你完成这个"翻译"。

## 一、刚体的平动与转动

### 1.1 刚体的定义

**刚体** = 在任何外力作用下，形状和体积都保持不变的物体。（理想模型——真实世界中不存在绝对刚体，但石头、金属块等在受力不大时可近似。）

刚体的一般运动 = **平动 + 转动**

| 运动类型 | 特点 | 描述参数 |
|---------|------|---------|
| **平动** | 体内任意直线方向始终不变 | 位移 $\vec{x}$、速度 $\vec{v}$、加速度 $\vec{a}$ |
| **定轴转动** | 绕固定轴旋转，所有质元做圆周运动 | 角位移 $\theta$、角速度 $\omega$、角加速度 $\alpha$ |

### 1.2 定轴转动的特点

- 轴上各点静止，其余质元以轴为中心做圆周运动
- **所有质元的角量 ($\theta, \omega, \alpha$) 完全相同**
- **各质元的线量 ($v, a$) 随到轴的距离 $r$ 变化**

> 🎯 **直觉**：转轴上所有点"角步调"一致——就像一排人跳广场舞，看的是一个节奏（角速度），但站得远的人手动得远（线速度大）。

## 二、角量与线量的关系

### 2.1 基本关系

| 角量 | 线量 | 关系 |
|------|------|------|
| 角位移 $\Delta\theta$ | 弧长 $\Delta s$ | $\Delta s = r\Delta\theta$ |
| 角速度 $\omega = \dfrac{d\theta}{dt}$ | 线速度 $v$ | $\boxed{v = r\omega}$ |
| 角加速度 $\alpha = \dfrac{d\omega}{dt}$ | 切向加速度 $a_t$ | $\boxed{a_t = r\alpha}$ |
| — | 向心加速度 $a_n$ | $\boxed{a_n = \dfrac{v^2}{r} = \omega^2 r}$ |

**矢量形式**：$\vec{v}=\vec{\omega}\times\vec{r}$，$\vec{a}_t=\vec{\alpha}\times\vec{r}$

> ⚠️ 角速度和角加速度都是矢量，方向由**右手定则**确定（沿转轴）。加速转动时同向，减速转动时反向。

### 2.2 匀变速转动公式

完全类比匀变速直线运动，替换 $(x,v,a) \to (\theta,\omega,\alpha)$：

$$\boxed{\omega = \omega_0 + \alpha t}$$
$$\boxed{\theta = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2}$$
$$\boxed{\omega^2 = \omega_0^2 + 2\alpha(\theta - \theta_0)}$$

> 📌 转速换算：$n$ 转/分 $= \dfrac{2\pi n}{60}$ rad/s。一圈 = $2\pi$ 弧度。

## 三、转动惯量 ⭐（本章最核心的概念）

### 3.1 定义：为什么要引入转动惯量？

> 🎯 **直觉类比**：质量 $m$ 衡量物体抗拒**平动**加速的能力；**转动惯量 $J$ 衡量物体抗拒**转动**加速的能力。** $J$ 越大 → 越难让它转起来 → 需更大的力矩。

> ❓ **为什么 $J$ 是 $r^2$ 而不是 $r$？** 力矩含有一个 $r$（$M = rF$），角加速度与线加速度之间也有一个 $r$（$a_t = r\alpha$）。代入转动定律 $M = J\alpha$ → $rF = J \cdot (a_t/r)$ → 两边各有一个 $r$，合起来 $r^2 F = J a_t$。所以 $J$ 身上背着两个 $r$ 的因子——一个是力矩带来的，一个是角-线转换带来的。**$J = \sum m_i r_i^2$ 不是随便定义的，而是 $M=J\alpha$ 反推出来的必然结果。**

**定义式**：

$$\boxed{J = \sum_i \Delta m_i r_i^2 \quad \text{（离散）}}$$
$$\boxed{J = \int r^2\,dm \quad \text{（连续）}}$$

$r$ 是质量微元 $dm$ 到转轴的**垂直距离**。

### 3.2 决定转动惯量的三个因素

| 因素 | 影响 |
|------|------|
| **总质量 $M$** | $M$ 越大，$J$ 越大（质量越大越难转动）|
| **质量分布** | 质量离轴越远，$J$ 越大（$\because r^2$ 因子）|
| **转轴位置** | 同一物体，不同轴 → 不同 $J$ |

> 🔑 **$r^2$ 效应**：转动惯量对质量远离"惩罚"很重——因为 $r$ 是平方关系。质量放在 $2R$ 处，贡献是放 $R$ 处的 4 倍。

### 3.3 积分法计算转动惯量（手把手）

<details>
<summary><b>📐 例 1：均质细杆（长 $L$，质量 $M$）——展开看推导</b></summary>

取线密度 $\lambda = M/L$，$dm = \lambda\, dx$

**(a) 绕中心垂直轴：**

$$J_C = \int_{-L/2}^{L/2} x^2 \cdot \lambda\, dx = \lambda \left[\frac{x^3}{3}\right]_{-L/2}^{L/2} = \frac{\lambda L^3}{12} = \boxed{\frac{1}{12}ML^2}$$

**(b) 绕一端垂直轴：**

$$J_{\text{端}} = \int_{0}^{L} x^2 \cdot \lambda\, dx = \lambda \left[\frac{x^3}{3}\right]_0^L = \frac{\lambda L^3}{3} = \boxed{\frac{1}{3}ML^2}$$

</details>

<details>
<summary><b>📐 例 2：均质圆盘（半径 $R$，质量 $M$）——展开看推导</b></summary>

取微元：半径 $r$、宽度 $dr$ 的圆环。面密度 $\sigma = M/\pi R^2$

$$dm = \sigma \cdot 2\pi r\,dr$$

$$J = \int_0^R r^2 \cdot (\sigma \cdot 2\pi r\,dr) = 2\pi\sigma \int_0^R r^3\,dr = 2\pi\sigma \cdot \frac{R^4}{4} = \frac{\pi\sigma R^4}{2}$$

代入 $\sigma = M/\pi R^2$，得：

$$J = \boxed{\frac{1}{2}MR^2}$$

</details>

**例 3：均质圆环（半径 $R$，质量 $M$）**

所有质量都在 $r=R$ 处 → $J = MR^2$（不需要积分！）

$$J = \boxed{MR^2}$$

### 3.4 常见刚体转动惯量速查表 ⭐

| 刚体 | 转轴 | 转动惯量 $J$ | 助记 |
|------|------|-------------|------|
| **细杆**（长 $L$） | 过中心 $\perp$ 杆 | $\boxed{\frac{1}{12}ML^2}$ | "杆中十二分之一" |
| **细杆**（长 $L$） | 过端点 $\perp$ 杆 | $\boxed{\frac{1}{3}ML^2}$ | "杆端三分之一" |
| **圆环**（半径 $R$） | 过中心 $\perp$ 环面 | $\boxed{MR^2}$ | 全质量在 $R$，$J=MR^2$ |
| **圆盘/圆柱**（半径 $R$） | 过中心 $\perp$ 盘面 | $\boxed{\frac{1}{2}MR^2}$ | "盘半"（盘 = 一半的 $MR^2$） |
| **实心球**（半径 $R$） | 直径 | $\boxed{\frac{2}{5}MR^2}$ | "球五分之二" |
| **薄球壳**（半径 $R$） | 直径 | $\boxed{\frac{2}{3}MR^2}$ | "壳三分之二" > 球（壳质在外） |
| **薄圆盘**（半径 $R$） | 直径 | $\frac{1}{4}MR^2$ | 垂直轴定理推得 |

> 🔑 比较：球壳 $J$ > 实心球 $J$（同样的 $M,R$）——因为球壳质量都在外表，离轴"平均更远"。

### 3.5 平行轴定理

$$\boxed{J = J_C + Md^2}$$

- $J_C$ = 绕**质心轴**的转动惯量
- $d$ = 两平行轴之间的**垂直距离**
- **条件**：两轴必须平行，且其中一根必须过质心

> 🎯 **直觉**：把转动轴从质心平移距离 $d$，就相当于在原来 $J_C$ 的基础上，再"挂"了一个距离 $d$ 处的质点的 $J$（$Md^2$）。

**举例验证**——细杆从中心移到端点：

$J_C = \frac{1}{12}ML^2$，$d=L/2$

$J_{\text{端}} = \frac{1}{12}ML^2 + M\left(\frac{L}{2}\right)^2 = \frac{1}{12}ML^2 + \frac{1}{4}ML^2 = \boxed{\frac{1}{3}ML^2}$ ✓

### 3.6 垂直轴定理（仅适用于**薄板**）

$$\boxed{J_z = J_x + J_y}$$

- $x,y$ 轴在板面内互相垂直
- $z$ 轴垂直于板面
- 仅适用于**厚度可忽略的薄板**

**应用**：均匀圆盘绕直径的转动惯量
- 已知 $J_z = \frac{1}{2}MR^2$（中心轴）
- 由对称性 $J_x = J_y$
- $\therefore J_x = J_y = \frac{1}{4}MR^2$

> ⚠️ **常见错误**：把垂直轴定理用在非薄板物体上。例如球体——$J_z \neq J_x + J_y$（球体的 $J_z = J_x = J_y = \frac{2}{5}MR^2$，$\frac{2}{5} \neq \frac{4}{5}$）。垂直轴定理要求物体厚度可忽略，质量必须分布在 $xy$ 平面内。

## 四、转动定律 $M=J\alpha$

### 4.1 力矩的定义

$$\boxed{\vec{M} = \vec{r} \times \vec{F}}$$

| 量 | 大小 | 方向 |
|----|------|------|
| 力矩 $M$ | $M = rF\sin\theta = Fd$（$d$ 为力臂） | 右手定则（$\vec{r}$ 转向 $\vec{F}$，拇指方向） |

> 🎯 **直觉**：力大不一定力矩大——还要看**力臂**（力到转轴的垂直距离）。用扳手拧螺丝，手握在扳手末端比靠近螺丝更省力——就是力矩的力臂效应。

### 4.2 转动定律（核心公式）

$$\boxed{\vec{M} = J\vec{\alpha}}$$

**合外力矩 = 转动惯量 × 角加速度**

> 🎯 这就是旋转世界的 $F=ma$！把所有物理量换成对应的"旋转版"，公式结构完全一致。

### 4.3 ⭐ 质点 vs 刚体：公式类比表

| | **质点（平动）** | **刚体（转动）** |
|---|---|---|
| 惯性量度 | 质量 $m$ | 转动惯量 $J$ |
| 位移 | $x$ | 角位移 $\theta$ |
| 速度 | $\vec{v}$ | 角速度 $\vec{\omega}$ |
| 加速度 | $\vec{a}$ | 角加速度 $\vec{\alpha}$ |
| 力的作用 | 力 $\vec{F}$ | 力矩 $\vec{M} = \vec{r}\times\vec{F}$ |
| 动力学方程 | $\boxed{F = ma}$ | $\boxed{M = J\alpha}$ |
| 动量 | $\vec{p} = m\vec{v}$ | 角动量 $\vec{L} = J\vec{\omega}$ |
| 动量定理 | $\vec{F} = \dfrac{d\vec{p}}{dt}$ | $\vec{M} = \dfrac{d\vec{L}}{dt}$ |
| 守恒条件 | $\sum\vec{F}=0$ → $\vec{p}$ 守恒 | $\sum\vec{M}=0$ → $\vec{L}$ 守恒 |
| 动能 | $\frac{1}{2}mv^2$ | $\frac{1}{2}J\omega^2$ |
| 功 | $A = \int F\,dx$ | $A = \int M\,d\theta$ |
| 功率 | $P = Fv$ | $P = M\omega$ |
| 动能定理 | $A = \Delta(\frac{1}{2}mv^2)$ | $A = \Delta(\frac{1}{2}J\omega^2)$ |
| 冲量/冲量矩 | $\int F\,dt = \Delta\vec{p}$ | $\int M\,dt = \Delta\vec{L}$ |

> 🧠 **记住这张表 = 学会两套力学。** 实际上，转动力学不是"新"东西，而是质点力学在旋转坐标下的自然推广。

## 五、角动量定理与角动量守恒

### 5.1 角动量的定义

| 对象 | 角动量 |
|------|--------|
| 质点 | $\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$ |
| 刚体 | $\boxed{\vec{L} = J\vec{\omega}}$ |

### 5.2 角动量定理

$$\boxed{\vec{M} = \frac{d\vec{L}}{dt}}$$

**积分形式**：$\displaystyle \int_{t_1}^{t_2} \vec{M}\,dt = \vec{L}_2 - \vec{L}_1$

左端叫**冲量矩**（力矩对时间的累积效应），类比平动的冲量 $I = \int F\,dt$。

### 5.3 角动量守恒定律 ⭐

$$\boxed{\text{当 } \sum\vec{M}=0 \text{ 时，} \vec{L} = J\vec{\omega} = \text{常数}}$$

> 🎯 **直觉类比**：花样滑冰运动员张开双臂（$J$ 大）→ 转得慢；把双臂收拢贴近身体（$J$ 小）→ 转得快。整个过程 $L=J\omega$ 不变，$J$ 变小 → $\omega$ 自动变大。**物理の魔法：不需要额外用力，只改变姿态就能调速。**

**应用实例**：
- 🧊 花样滑冰收臂加速
- 🚁 直升机尾桨：抵消主旋翼产生的角动量，防止机身反旋
- 🌏 地球自转周期稳定（角动量守恒）
- 🪐 行星近日点速度快于远日点

> ⚠️ **守恒条件**：$\sum\vec{M}=0$（合外力矩为零），不是合力为零！

## 六、功能关系与机械能守恒

### 6.1 力矩的功

$$\boxed{A = \int_{\theta_1}^{\theta_2} M\,d\theta}$$

- 恒力矩：$A = M(\theta_2 - \theta_1) = M\Delta\theta$
- 变力矩：需要积分

### 6.2 转动动能

$$\boxed{E_k = \frac{1}{2}J\omega^2}$$

**推导**：$A = \int M\,d\theta = \int J\alpha\,d\theta = J\int \frac{d\omega}{dt}\cdot\omega\,dt = J\int \omega\,d\omega = \frac{1}{2}J(\omega_2^2 - \omega_1^2)$

### 6.3 刚体的动能定理

$$\boxed{A_{\text{外}} = \frac{1}{2}J\omega_2^2 - \frac{1}{2}J\omega_1^2}$$

### 6.4 刚体的重力势能

刚体的重力势能 = 全部质量集中在质心时的势能：

$$\boxed{E_p = mgh_C}$$

$h_C$ 是质心的高度（相对零势面）。

### 6.5 机械能守恒定律

当只有**重力**或**弹力**做功时：

$$\boxed{\frac{1}{2}J\omega^2 + mgh_C = \text{常数}}$$

> ⚠️ 如果刚体同时做平动+转动（如纯滚动），总动能 = 平动动能 + 转动动能：
> $$E_k = \frac{1}{2}Mv_C^2 + \frac{1}{2}J_C\,\omega^2$$

## 七、核心例题（手把手）⭐

### 例题 1：阿特伍德机（有质量滑轮）🔥

> # ⚠️ 滑轮有质量时 $\mathbf{T_1 \neq T_2}$！
> # 绳子两端张力不再相等！张力差产生净力矩使滑轮加速转动。
>
> **这是大学物理与高中物理的关键区别。高中物理默认滑轮轻质 → $T_1=T_2$。大学物理滑轮有质量 → 必须用转动定律！**

**题目**：质量为 $M_1$ 和 $M_2$ 的物体通过轻绳跨过滑轮，滑轮质量 $m$、半径 $R$。设 $M_1 > M_2$，求加速度和绳中张力。

**步骤 1：隔离受力分析**

- $M_1$：重力 $M_1g$↓，绳张力 $T_1$↑ → $M_1$ 向下加速
- $M_2$：重力 $M_2g$↓，绳张力 $T_2$↑ → $M_2$ 向上加速
- 滑轮：$T_1$ 在右端产生逆时针力矩，$T_2$ 在左端产生顺时针力矩 → 净力矩 = $(T_1-T_2)R$

**步骤 2：列方程**

$M_1$（向下加速）：$\quad M_1g - T_1 = M_1a \quad\cdots\text{(1)}$

$M_2$（向上加速）：$\quad T_2 - M_2g = M_2a \quad\cdots\text{(2)}$

滑轮（转动定律）：$\quad T_1R - T_2R = J\alpha = \frac{1}{2}mR^2 \cdot \alpha \quad\cdots\text{(3)}$

约束关系：$\quad a = \alpha R \quad\cdots\text{(4)}$

**步骤 3：化简求解**

将 (4) 代入 (3)：$T_1 - T_2 = \frac{1}{2}ma$

(1) $-$ (2)：$(M_1 - M_2)g - (T_1 - T_2) = (M_1 + M_2)a$

代入 $T_1 - T_2 = \frac{1}{2}ma$：

$$(M_1 - M_2)g = \left(M_1 + M_2 + \frac{m}{2}\right)a$$

$$\boxed{a = \frac{(M_1 - M_2)g}{M_1 + M_2 + \dfrac{m}{2}}}$$

**步骤 4：求张力**

由 (1)：$T_1 = M_1(g - a)$

由 (2)：$T_2 = M_2(g + a)$

易看出 $T_1 > T_2$（因为滑轮需力矩加速）。

**验证**：当滑轮质量 $m \to 0$ 时，$a = \dfrac{(M_1-M_2)g}{M_1+M_2}$，$T_1 = T_2$，退化到高中物理结果 ✓

> 🔑 滑轮质量 $m$ 出现在分母，$m$ 越大 → $a$ 越小（滑轮越重越难转）

### 例题 2：圆柱体纯滚动下斜面 🔥

**题目**：匀质圆柱体（质量 $M$，半径 $R$）从倾角 $\theta$ 的斜面顶端**无滑动**滚下，求质心加速度。

> 🎯 **纯滚动条件**：$v_C = \omega R$，且接触点**瞬时静止**（无相对滑动）。这意味着接触点受到的是静摩擦力，不做功。

**步骤 1：受力分析**

- 重力 $Mg$（竖直向下）
- 斜面支持力 $N$（垂直斜面向上）
- **静摩擦力** $f$（沿斜面向上，阻止滑动）

**步骤 2：列方程**

平动（沿斜面）：$\quad Mg\sin\theta - f = Ma \quad\cdots\text{(1)}$

垂直斜面：$\quad N - Mg\cos\theta = 0 \quad\cdots\text{(2)}$

转动（绕质心）：$\quad fR = J_C\alpha = \frac{1}{2}MR^2 \cdot \alpha \quad\cdots\text{(3)}$

纯滚动条件：$\quad a = \alpha R \quad\cdots\text{(4)}$

**步骤 3：求解**

由 (3)(4)：$fR = \frac{1}{2}MR^2 \cdot \frac{a}{R} \;\rightarrow\; f = \frac{1}{2}Ma$

代入 (1)：$Mg\sin\theta - \frac{1}{2}Ma = Ma$

$$Mg\sin\theta = \frac{3}{2}Ma \quad\Rightarrow\quad \boxed{a = \frac{2}{3}g\sin\theta}$$

> 📊 对比：若物体无摩擦**滑动**（非滚动），$a = g\sin\theta$。纯滚动的加速度只有滑动的 $\frac{2}{3}$ —— 因为一部分能量转为转动动能了。

**推广**（任意转动惯量 $J_C$）：

$$\boxed{a = \frac{g\sin\theta}{1 + \dfrac{J_C}{MR^2}}}$$

| 物体 | $J_C$ | $a$（纯滚） | 排名 |
|------|-------|------------|------|
| 均质圆环 | $MR^2$ | $\frac{1}{2}g\sin\theta$ | 🐌 最慢 |
| 均质圆盘 | $\frac{1}{2}MR^2$ | $\frac{2}{3}g\sin\theta$ | 中 |
| 均质球体 | $\frac{2}{5}MR^2$ | $\frac{5}{7}g\sin\theta$ | 较快 |
| 质点（无转动） | $0$ | $g\sin\theta$ | 🚀 最快 |

> 🔑 **结论**：转动惯量越大的物体，纯滚动越慢（因为更多能量要分配给转动）。

### 例题 3：杆剪切问题（刚体瞬时运动）🔥

**题目**：均质细杆长 $L$、质量 $M$，一端铰接悬挂。用水平绳拉另一端使杆保持水平静止。突然剪断绳子，求剪断**瞬间**杆的角加速度。

> 🎯 **核心思想**：剪断瞬间 $\omega = 0$（静止），但 $\alpha \neq 0$（角速度的变化率不为零！）
> **速度为零 ≠ 速度变化率为零**——就像你把球向上抛到最高点，$v=0$ 但 $a=g$。

**分析**：

杆绕悬挂端（一端）转动，直接用转动定律 $M = J\alpha$：

- 绕端点转动惯量：$J = \frac{1}{3}ML^2$
- 重力作用在质心（杆中点），力臂 = $L/2$：$M = Mg \cdot \frac{L}{2}$

$$\alpha = \frac{M}{J} = \frac{Mg \cdot L/2}{\frac{1}{3}ML^2} = \boxed{\frac{3g}{2L}}$$

**为什么不用逐点分析？**

杆上各点到转轴距离不同 → 加速度不同。逐点分析太复杂。但用转动定律，只需**一个方程**就能得到整个杆的角加速度。这就是刚体模型的威力。

### 例题 4：变阻力矩减速问题

**题目**：圆盘转动惯量 $J$，初始角速度 $\omega_0$。空气阻力矩 $M_f = -k\omega$（与瞬时角速度成正比）。求：(1) $\omega(t)$；(2) 停止前的总圈数。

**解**：

由转动定律：$-k\omega = J\dfrac{d\omega}{dt}$

分离变量：$\dfrac{d\omega}{\omega} = -\dfrac{k}{J}dt$

> 📐 **分离变量法**：把含 $\omega$ 的项移到左边、含 $t$ 的项移到右边——这是一种解微分方程的基本技巧。原理：两边分别对各自变量积分，$\displaystyle\int \dfrac{d\omega}{\omega} = -\dfrac{k}{J}\displaystyle\int dt$，左边积出 $\ln\omega$，右边积出 $t$。

积分：$\ln\dfrac{\omega}{\omega_0} = -\dfrac{k}{J}t$

$$\boxed{\omega(t) = \omega_0\, e^{-\frac{k}{J}t}}$$

总转角：$\displaystyle \theta = \int_0^\infty \omega_0 e^{-\frac{k}{J}t}\,dt = \frac{J\omega_0}{k}$

$$\boxed{n = \frac{\theta}{2\pi} = \frac{J\omega_0}{2\pi k}}$$

## ⚠️ 十、常见错误 Top 10

| # | 错误 | 正确认知 |
|---|------|---------|
| 1 | **滑轮有质量时 $T_1 = T_2$** | 张力差 $(T_1-T_2)R = J\alpha$，$T_1 \neq T_2$！这是大学与高中物理的核心分界线 |
| 2 | **把垂直轴定理用在球体/柱体上** | $J_z = J_x + J_y$ 仅适用**薄板**（$z$ 垂直板面）|
| 3 | **混淆平行轴定理条件** | 新轴必须与**过质心轴**平行。$d$ 是两轴**垂直距离** |
| 4 | **积分算 $J$ 时把 $r$ 当成常数** | $r$ 是积分变量，从 $0$ 到 $R$（或从 $-L/2$ 到 $L/2$），写 $J=MR^2$ 算一切会翻车 |
| 5 | **$\omega=0$ 推出 $\alpha=0$** | 杆剪切瞬间 $\omega=0$ 但 $\alpha \neq 0$ —— 速度为零 ≠ 变化率为零 |
| 6 | **角动量守恒 vs 动量守恒条件混淆** | 角动量守恒条件是 $\sum M=0$（合力矩为零），不是合力为零 |
| 7 | **纯滚动时认为摩擦力做功** | 静摩擦力在纯滚动中**不做功**（接触点瞬时静止，位移为零），能量转换通过静摩擦力"传递"而非"消耗" |
| 8 | **转动动能忘了加平动动能** | 刚体既有平动又有转动时：$E_k = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2$ |
| 9 | **忽略纯滚动条件 $v=\omega R$** | 纯滚动时 $v=\omega R$ 是约束方程，必须联立使用 |
| 10 | **重力势能用 $mgR$ 而非 $mgh_C$** | 刚体重力势能应取**质心**高度 $h_C$，不是物体最底端或最顶端 |

## 📋 十一、公式速查

### 基本公式

| 类别 | 公式 | 说明 |
|------|------|------|
| 转动惯量 | $\displaystyle J = \int r^2\,dm$ | 定义式 |
| 角量-线量 | $v = r\omega,\; a_t = r\alpha,\; a_n = \omega^2 r$ | 基本关系 |
| 转动定律 | $\boxed{M = J\alpha}$ | 核心动力学方程 |
| 角动量 | $\vec{L} = J\vec{\omega}$ | 刚体角动量 |
| 角动量定理 | $\displaystyle \vec{M} = \frac{d\vec{L}}{dt}$ | 冲量矩 $\int M\,dt = \Delta L$ |
| 角动量守恒 | $\sum\vec{M}=0 \Rightarrow L=\text{常数}$ | 守恒条件 |
| 转动动能 | $E_k = \frac{1}{2}J\omega^2$ | 转动能量 |
| 平转总动能 | $E_k = \frac{1}{2}Mv_C^2 + \frac{1}{2}J_C\omega^2$ | 平动 + 转动 |
| 重力势能 | $E_p = mgh_C$ | 质心高度 |
| 力矩的功 | $\displaystyle A = \int M\,d\theta$ | 恒力矩时 $A=M\Delta\theta$ |
| 功率 | $P = M\omega$ | 旋转功率 |

### 定理

| 定理 | 公式 | 条件 |
|------|------|------|
| 平行轴定理 | $\boxed{J = J_C + Md^2}$ | 新轴 $\parallel$ 过质心轴 |
| 垂直轴定理 | $\boxed{J_z = J_x + J_y}$ | 仅薄板，$z\perp$ 板面 |
