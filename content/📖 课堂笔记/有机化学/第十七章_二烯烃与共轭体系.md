# 第十七章 二烯烃与共轭体系 (Dienes and Conjugated Systems)

---

## 17.1 二烯烃的分类

二烯烃按双键的相对位置分为三类：

| 类型 | 特征 | 稳定性 |
|------|------|:---:|
| **累积二烯** (Cumulated) | $\ce{C=C=C}$，双键相邻（累积） | 最不稳定 |
| **共轭二烯** (Conjugated) | $\ce{C=C-C=C}$，单双键交替 | **最稳定** |
| **隔离二烯** (Isolated) | $\ce{C=C-(CH2)_{n}-C=C}$，双键被 $n$ 个饱和碳隔开 | 中等 |

```smiles
# 累积二烯 — 丙二烯 (Allene)
C(=C)=C
# 累积二烯 — 1,2-丁二烯
CC=C=C
# 累积二烯 — 3-甲基-1,2-丁二烯
CC(=C=C)C
# 累积二烯 — 2,3-戊二烯
CC=C=CC

# 共轭二烯 — 1,3-戊二烯
CC=CC=C
# 共轭二烯 — 异戊二烯 (2-甲基-1,3-丁二烯)
CC(=C)C=C

# 隔离二烯 — 1,4-戊二烯
C=CCC=C
```

| 结构式 | 名称 | 类型 |
|--------|------|:---:|
| $\ce{CH2=C=CH-CH2CH3}$ | 1,2-戊二烯 | 累积 |
| $\ce{CH2=C=C(CH3)2}$ | 3-甲基-1,2-丁二烯 | 累积 |
| $\ce{CH3-CH=C=CH-CH3}$ | 2,3-戊二烯 | 累积 |
| $\ce{CH2=CH-CH=CH-CH3}$ | 1,3-戊二烯 | **共轭** |
| $\ce{CH2=C(CH3)-CH=CH2}$ | 异戊二烯（2-甲基-1,3-丁二烯） | **共轭** |
| $\ce{CH2=CH-CH2CH=CH2}$ | 1,4-戊二烯 | 隔离 |

---

## 17.2 累积二烯——丙二烯的结构

> 丙二烯（Allene）是最简单的累积二烯：$\ce{CH2=C=CH2}$

**结构特征**：

- 中心碳为 **$sp$ 杂化**，两端碳为 **$sp^2$ 杂化**
- 中心碳的 **两个未参与杂化的 $p$ 轨道互相垂直**
- 两端碳的 $p$ 轨道分别与中心碳的两个垂直 $p$ 轨道肩并肩重叠
- 结果：**两个 $\pi$ 键互相垂直**

```smiles
# 丙二烯 — 中心碳sp杂化，两个π键互相垂直
C(=C)=C
```

> **丙二烯不稳定**，容易转化为更稳定的异构体。

## 17.3 共轭二烯的结构特征

以 1,3-丁二烯为例：$\ce{CH2=CH-CH=CH2}$

### 17.3.1 实验事实

**(a) 键长数据**

| 键 | 类型 | 典型键长 | 1,3-丁二烯实测值 |
|----|------|:---:|:---:|
| $\ce{C1=C2}$ | 双键 | 134 pm | **> 134 pm** |
| $\ce{C2-C3}$ | 单键 | 154 pm | **< 154 pm** |
| $\ce{C3=C4}$ | 双键 | 134 pm | **> 134 pm** |

> ★ **键长趋于平均化**：双键变长、单键变短，说明 $\ce{C2-C3}$ 具有**部分双键性质**。

**(b) 氢化热**

$$\ce{CH3CH=CHCH=CH2 + 2H2 -> 正戊烷} \qquad \Delta H = -226\ \mathrm{kJ/mol}$$
$$\ce{CH2=CHCH2CH=CH2 + 2H2 -> 正戊烷} \qquad \Delta H = -254\ \mathrm{kJ/mol}$$

> **共轭二烯的氢化热比非共轭二烯低 28 kJ/mol**——共轭二烯更稳定。

**(c) 醇脱水实验**

$$\ce{CH2=CH-CH2-CHOH-CH3 ->[Al2O3] CH2=CH-CH=CH-CH3}$$

> 产物以共轭二烯为主，而非隔离二烯——共轭体系更稳定。

### 17.3.2 结构特征总结

| 特征 | 说明 |
|------|------|
| **键长趋于平均化** | 单双键键长差值减小 |
| **四个双键碳共平面** | 所有碳原子在同一平面 |
| **体系能量降低** | 共轭体系比隔离体系更稳定 |

### 17.3.3 价键理论 (VB) 解释

- 每个碳原子均为 **$sp^2$ 杂化**
- 形成 3 个 $\ce{C-C}\ \sigma$ 键和 6 个 $\ce{C-H}\ \sigma$ 键，同一平面，夹角 $\sim 120^\circ$
- 四个 $p$ 轨道平行，形成 **$\Pi_4^4$ 大 $\pi$ 键**（4 中心 4 电子）
- **$\pi$ 电子离域**：$\pi$ 电子不固定在某两个碳原子之间，而是分布在共轭体系中的几个原子上

```smiles
# 1,3-丁二烯 — 共轭体系，键长平均化
C=CC=C
```

> **电子离域 (Electron Delocalization)**：$\pi$ 电子不是固定在两个双键碳原子之间，而是分布在共轭体系中的几个原子上。

### 17.3.4 分子轨道 (MO) 处理

1,3-丁二烯的四个 $p$ 轨道组合成四个 $\pi$ 分子轨道：

| 轨道 | 能级 | 节点数 | 填充 |
|------|:---:|:---:|:---:|
| $\psi_1$ (成键) | 最低 | 0 | $\uparrow\downarrow$ |
| $\psi_2$ (成键) | HOMO | 1 | $\uparrow\downarrow$ |
| $\psi_3$ (反键) | LUMO | 2 | — |
| $\psi_4$ (反键) | 最高 | 3 | — |

> HOMO-LUMO 能隙较小 → 共轭体系容易发生电子跃迁。

## 17.4 共轭体系与共轭效应

### 17.4.1 共轭体系的定义

> **共轭体系**：不饱和键与单键交替存在的体系。

#### $\pi$-$\pi$ 共轭体系

单双键交替排列：

$$\ce{CH2=CH-CH=CH2} \qquad \ce{CH2=CH-CH=CH-CH=CH2} \qquad \ce{CH2=CH-C#CH}$$

```smiles
# π-π共轭：1,3-丁二烯
C=CC=C
# π-π共轭：1,3,5-己三烯
C=CC=CC=C
# π-π共轭：乙烯基乙炔
C=CC#C
```

#### $p$-$\pi$ 共轭体系

> 广义共轭体系：凡是与不饱和键相邻的原子上有 $p$ 轨道的体系。

$p$ 轨道来源：

| 类型 | 示例 | $p$ 轨道特征 |
|------|------|------|
| 碳正离子 | $\ce{CH2=CH-CH2+}$ | 空 $p$ 轨道 |
| 碳自由基 | $\ce{CH2=CH-\cdot CH2}$ | 单电子 $p$ 轨道 |
| 杂原子 | $\ce{CH2=CH-Cl}$ | 孤对电子在 $p$ 轨道 |

```smiles
# p-π共轭：烯丙基碳正离子 (空p轨道)
[CH2]=[CH]-[CH2+]
# p-π共轭：氯乙烯 (Cl孤对电子)
C=CCl
```

---

### 17.4.2 共轭体系的特点

| 特点 | 含义 |
|------|------|
| **各中心原子共平面** | 共轭原子在同一平面，$p$ 轨道才能有效重叠 |
| **键长趋于平均化** | 电子离域使键级平均化 |
| **能量降低** | 离域使体系更稳定（离域能） |

### 17.4.3 离域能 (Delocalization Energy)

| 化合物 | 氢化热 (kJ/mol) | 预期值 | 离域能 |
|--------|:---:|:---:|:---:|
| $\ce{CH2=CH-CH2-CH3}$ (1-丁烯) | 127 | — | — |
| $\ce{CH2=CH-CH=CH2}$ (1,3-丁二烯) | 239 | $2 \times 127 = 254$ | **15 kJ/mol** |
| $\ce{CH2=C=CHCH2CH3}$ (1,2-戊二烯) | 297 | $2 \times 127 = 254$ | —（不稳定） |
| $\ce{CH2=CHCH2CH=CH2}$ (1,4-戊二烯) | 254 | $2 \times 127 = 254$ | 0 |

> **离域能** $= 2 \times 127 - 239 = \boxed{15\ \mathrm{kJ/mol}}$（1,3-丁二烯）
>
> 累积二烯氢化热 > 预期值（不稳定），隔离二烯氢化热 = 预期值。

---

### 17.4.4 共轭效应 ($C$ 效应)

> **共轭效应 (Conjugative Effect)**：共轭体系中，由于原子间的相互影响而使体系内 $\pi$ 电子或 $p$ 电子分布发生变化的效应。

#### 共轭效应的特点

1. **前提**：必须存在共轭体系
2. **方向性**：有一定的方向
3. **核心**：电子离域 → 共轭链上**正负电荷极性交替**
4. **远程效应**：受外电场的影响沿共轭链传递**不减弱**

#### 共轭效应的表示

箭头 $\ce{->}$ 表示电子离域方向：

- 起于**双键**，止于与双键相连的原子（或单键）
- 起于**未共用电子对**，止于单键

```
CH₂ = CH — Cl     ←   π 电子云向 Cl 偏移
CH₂ = CH — CHO    ←   π 电子云向羰基偏移
```

#### 共轭效应的类型

```
共轭效应
├── π-π 共轭效应
├── p-π 共轭效应
├── σ-π 超共轭效应
└── σ-p 超共轭效应
```

#### 吸电子共轭 ($-C$)

使体系中 $\pi$ 电子云密度降低：

| 规律 | 比较 |
|------|------|
| 带正电荷更强 | $\ce{=N+R2 > =NR}$ |
| 同周期随电负性增大而愈强 | $\ce{=O > =NR > =CR2}$ |
| 同主族 | $\ce{=O > =S}$ |

$$\ce{CH2=CH-CHO}\quad （\ce{-CHO} 为 $-C$ 取代基，吸电子共轭）$$

#### 供电子共轭 ($+C$)

使体系中 $\pi$ 电子云密度增大：

| 规律 | 比较 |
|------|------|
| 带负电荷更强 | $\ce{-O- > -OR > -O+R2}$ |
| 同周期随原子序数增大而减弱 | $\ce{-NR2 > -OR > -F}$ |
| 同主族 | $\ce{-OR > -SR}$ |
| 同族随周期增大而减弱 | $\ce{-F > -Cl > -Br > -I}$ |

$$\ce{CH2=CH-Cl}\quad （\ce{-Cl} 为 $+C$ 取代基，供电子共轭）$$

---

### 17.4.5 极性交替 (Polarity Alternation)

共轭体系中由于电子离域产生正负电荷交替分布：

```
δ⊕     δ⊖     δ⊕
H₂C = CH — CH₂⁺    (p-π 共轭)

δ⊖     δ⊕     δ⊖
H₂C = CH — Cl      (+C > -I，净供电子)

δ⊕     δ⊖     δ⊕
H₂C = CH — CHO     (-C 吸电子共轭)
```

> 共轭链上正负电荷**交替分布**，是共轭效应的核心特征。

#### 练习：分析电子效应

| 化合物 | 取代基 | 电子效应 |
|--------|--------|------|
| $\ce{CH2=CH-CH=CH-CHO}$ | $\ce{-CHO}$ | $-I$、$-C$ |
| $\ce{CH2=CH-CH=CH-NH2}$ | $\ce{-NH2}$ | $-I$、$+C$ |

> $\ce{-NH2}$：N 电负性 > C → $-I$（吸电子诱导）；N 有孤对电子 → $+C$（供电子共轭）

---

## 17.5 超共轭效应 (Hyperconjugation)

> **定义**：与含 $p$ 轨道的原子相邻的 $\ce{C-H}\ \sigma$ 键与 $p$ 轨道平行时，$\sigma$ 键上的电子和相邻 $p$ 轨道的离域。

### 17.5.1 $\sigma$-$\pi$ 超共轭

甲基中 $\ce{C-H}\ \sigma$ 轨道与 $\pi$ 键的 $p$ 轨道侧面交盖，$\sigma$ 电子偏离原来轨道产生电子离域。

> 比 $\pi$-$\pi$ 共轭效应**弱**，但不可忽略。

**参与超共轭的 $\ce{C-H}$ 键越多，效应越大。**

```smiles
# 超共轭越多越稳定
CC=C      # 丙烯 — 3个C-H σ键参与σ-π
CC=CC     # 2-丁烯 — 6个C-H σ键参与σ-π
CC(=C)C   # 异丁烯
```

#### 烯烃稳定性排序

$$\ce{(CH3)2C=C(CH3)2 > (CH3)2C=CHCH3 > CH3CH=CHCH3 > CH3CH=CH2}$$

> 双键碳上连接的烷基数越多 → $\sigma$-$\pi$ 超共轭越多 → 烯烃越稳定。

#### 对 Markovnikov 规则的解释

除 $+I$ 效应外，还有 $\sigma$-$\pi$ 超共轭的作用（供电子性）：

$$\ce{CH2=CH-CH3}\quad （\ce{-CH3}\ 对双键有 $\sigma$-$\pi$ 超共轭的供电作用）$$

---

### 17.5.2 $\sigma$-$p$ 超共轭

$\sigma$ 轨道与空 $p$ 轨道（或带有一个电子的 $p$ 轨道）有交盖，产生电子离域。

> 适用于碳自由基和碳正离子的稳定化。

#### 碳正离子/自由基稳定性

> **参与超共轭的 $\sigma$ 键越多，碳正离子/自由基越稳定**

| 离子/自由基 | 可参与 $\sigma$-$p$ 的 $\ce{C-H}$ 数 | 稳定性 |
|-------------|:---:|:---:|
| $\ce{(CH3)3C+}$ | 9 | **最稳定** |
| $\ce{(CH3)2CH+}$ | 6 | ↑ |
| $\ce{CH3CH2+}$ | 3 | ↑ |
| $\ce{CH3+}$ | 0 | 最不稳定 |

```smiles
# 叔丁基碳正离子 — 9个C-H σ键参与σ-p超共轭，最稳定
[C+](C)(C)C
# 异丙基碳正离子 — 6个
C[C+](C)
# 乙基碳正离子 — 3个
C[C+]
# 甲基碳正离子 — 0个，最不稳定
[C+]
```

**稳定性顺序**：

$$(CH_3)_3C^+ > (CH_3)_2CH^+ > CH_3CH_2^+ > CH_3^+$$

---

### 17.5.3 共轭体系类型总结

| 共轭类型 | 示例 | 轨道 |
|----------|------|------|
| $\pi$-$\pi$ 共轭 | $\ce{CH2=CH-CH=CH2}$ | $\pi$ 与 $\pi$ |
| $p$-$\pi$ 共轭 | $\ce{CH2=CH-CH2+}$ | 空 $p$ 与 $\pi$ |
| $p$-$\pi$ 共轭 | $\ce{CH2=CH-\cdot CH2}$（烯丙基自由基） | 单电子 $p$ 与 $\pi$ |
| $p$-$\pi$ 共轭 | $\ce{CH2=CH-Cl}$ | 孤对电子 $p$ 与 $\pi$ |
| $\sigma$-$\pi$ 超共轭 | $\ce{CH3-CH=CH2}$ | $\ce{C-H}\ \sigma$ 与 $\pi$ |
| $\sigma$-$p$ 超共轭 | $\ce{(CH3)3C+}$ | $\ce{C-H}\ \sigma$ 与空 $p$ |

## 17.6 共轭二烯烃的化学性质

共轭二烯烃兼具烯烃的一般性质，但由于共轭效应具有**特征反应**：

| 反应类型 | 特点 |
|----------|------|
| **亲电加成** | 1,2-加成 + 1,4-加成（特征） |
| **双烯合成** | Diels-Alder 反应 |
| **聚合反应** | 合成橡胶等 |

---

### 17.6.1 1,2-加成与 1,4-加成

$$\ce{CH2=CH-CH=CH2 + HBr -> CH3CHBrCH=CH2 (1,2-加成) + CH3CH=CHCH2Br (1,4-加成)}$$

> 共轭二烯亲电加成可产生 **1,2-加成**和 **1,4-加成**两种产物。

#### 反应条件的影响

以 1,3-丁二烯与 $\ce{HBr}$ 加成为例：

| 温度 | 1,2-加成 | 1,4-加成 | 主产物 |
|------|:---:|:---:|------|
| **-80°C**（低温） | 80% | 20% | 1,2-加成 |
| **40°C**（高温） | 15% | 85% | 1,4-加成 |

> ★ **低温有利于 1,2-加成（动力学控制），高温有利于 1,4-加成（热力学控制）**

---

### 17.6.2 1,4-加成的机理

**速度决定步骤**：生成碳正离子（亲电加成第一步）。

#### 反应历程

$$\ce{CH2=CH-CH=CH2 ->[H+] CH3-\overset{\oplus}{C}H-CH=CH2 + CH2=CH-\overset{\oplus}{C}H-CH3}$$

> $\ce{H+}$ 优先进攻 **C1** 而非 C2（生成的碳正离子通过 $p$-$\pi$ 共轭更稳定）。

```
δ⊕      δ⊖     δ⊕
H₂C = CH — CH = CH₂    (亲电试剂优先进攻C1)
 1      2      3      4
```

**关键：碳正离子中间体的稳定性**

| 碳正离子 | 共轭方式 | 稳定性 |
|----------|------|:---:|
| $\ce{CH3-\overset{\oplus}{C}H-CH=CH2}$ | $2^\circ$ 碳正离子 + $p$-$\pi$ 共轭 | **较稳定** |
| $\ce{CH2=CH-\overset{\oplus}{C}H-CH3}$ | $2^\circ$ 碳正离子，无 $p$-$\pi$ 共轭 | 不稳定 |

> 经 $p$-$\pi$ 共轭稳定的烯丙基型碳正离子 → 正电荷分布于 C2 和 C4 → $\ce{Br-}$ 可进攻 C2（1,2-加成）或 C4（1,4-加成）。

```smiles
# 1,3-丁二烯亲电加成 — 烯丙基型碳正离子中间体
C=CC=C
```

---

### 17.6.3 双烯合成（Diels-Alder 反应）

> 共轭二烯烃及其衍生物与具有碳碳双键或三键的化合物进行 1,4-加成反应，生成环状化合物。1950 年获**诺贝尔化学奖**。

```
Diene (双烯体)  +  Dienophile (亲双烯体)  →  环己烯衍生物
```

$$\ce{CH2=CH-CH=CH2 + CH2=CH2 ->[\Delta]}$$

```smiles
# Diels-Alder: 丁二烯 + 乙烯 → 环己烯
C=CC=C
C=C
C1CC=CCC1
```

#### 常见的亲双烯体 (Dienophiles)

| 化合物 | 结构 | 特性 |
|--------|------|------|
| **顺丁烯二酸酐**（顺酐，马来酸酐） | — | **最常用**，鉴别共轭二烯 |
| 丙烯醛 | $\ce{CH2=CH-CHO}$ | $\ce{-CHO}$ 吸电子 |
| 丙烯酸甲酯 | $\ce{CH2=CH-COOCH3}$ | $\ce{-COOCH3}$ 吸电子 |
| 丙烯腈 | $\ce{CH2=CH-CN}$ | $\ce{-CN}$ 吸电子 |
| 对苯醌 | — | 环状亲双烯体 |
| 丁炔二酸二甲酯 | $\ce{CH3OOC-C#C-COOCH3}$ | 炔基亲双烯体 |

```smiles
# 顺丁烯二酸酐 — 最常用亲双烯体
O=C1OC(=O)C=C1
# 丙烯醛
C=CC=O
# 丙烯酸甲酯
C=CC(=O)OC
# 丙烯腈
C=CC#N
```

#### 反应条件的影响

> **亲双烯体含吸电基有利，二烯体含供电基有利。**

| 反应 | 温度 | 产率 |
|------|:---:|:---:|
| 丁二烯 + 乙烯 | 200°C | 20% |
| 丁二烯 + 丙烯醛 | 100°C | **100%** |

> 丙烯醛上 $\ce{-CHO}$ 的 $-C$ 效应使反应极易进行。

---

### 17.6.4 Diels-Alder 反应的应用

#### 共轭二烯烃的鉴别

$$共轭二烯 + 顺丁烯二酸酐 \rightarrow 白色结晶沉淀$$

> 这是**鉴别共轭二烯烃**的常用方法。隔离二烯不发生此反应。

#### 合成环状化合物

Diels-Alder 反应是合成六元环化合物的**核心方法**之一：

$$\ce{CH2=CH-CH=CH2 + CH3OOC-C#C-COOCH3 ->[\Delta]}$$


## 本章核心框架

```
二烯烃分类
├── 累积二烯 (C=C=C) — 丙二烯，sp+sp²，两个π键⊥，不稳定
├── 共轭二烯 (C=C-C=C) — 单双键交替，最稳定 ⭐
└── 隔离二烯 (C=C-(CH₂)ₙ-C=C) — 性质类似单烯烃
      ↓
共轭二烯结构特征
├── 键长平均化（双键>134pm，单键<154pm）
├── 4中心4电子 Π₄⁴ 大π键 (VB)
├── MO: ψ₁~ψ₄，HOMO-LUMO gap小
└── 离域能：15 kJ/mol (氢化热法)
      ↓
共轭体系与共轭效应
├── π-π共轭：单双键交替
├── p-π共轭：C⁺/C·/孤对电子与π键
├── 共轭效应 (C effect)
│   ├── -C (吸电子共轭)：=O > =NR > =CR₂
│   └── +C (供电子共轭)：-NR₂ > -OR > -F
├── 极性交替 (δ⊕/δ⊖/δ⊕)
└── 远程效应：沿共轭链传递不减弱
      ↓
超共轭效应
├── σ-π超共轭：C-H σ与π键 → 解释烯烃稳定性 + Markovnikov规则
├── σ-p超共轭：C-H σ与p轨道 → 解释R₃C⁺/R₃C·稳定性
└── 稳定性：3° > 2° > 1° > CH₃
      ↓
共轭二烯化学性质
├── 1,2-加成 (低温，动力学控制) vs 1,4-加成 (高温，热力学控制)
│   — H⁺进攻C1 → p-π共轭稳定烯丙基碳正离子
├── Diels-Alder 反应 (双烯合成, 1950 Nobel)
│   — 亲双烯体含吸电基有利 (O=C-O-C=O > CHO > COOCH₃ > CN)
│   — 二烯体含供电基有利
│   — 应用：鉴别共轭二烯 (马来酸酐→白色结晶)
└── 聚合反应 → 合成橡胶
```
