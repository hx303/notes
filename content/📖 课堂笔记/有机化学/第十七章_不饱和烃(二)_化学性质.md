# 第十七章 不饱和烃（二）：烯烃与炔烃的化学性质

---

## 17B.1 烯烃物理性质

反式烯烃沸点低于顺式：$\ce{反-2-丁烯 < 顺-2-丁烯}$

---

## 17B.2 烯烃化学性质总述

> 反应**均与 $\pi$ 键有关**。$\pi$ 电子云松散，易受**亲电试剂**（缺电子试剂）进攻。
>
> 加成反应中碳 $sp^2 \to sp^3$。

| 反应类型 | 地位 |
|----------|:---:|
| 1. 加成反应 (Addition) | ⭐⭐⭐ 特征 |
| 2. 氧化反应 (Oxidation) | ⭐⭐ |
| 3. 聚合反应 (Polymerization) | ⭐（自学） |
| 4. $\alpha$-氢的反应 | ⭐ |

---

## 17B.3 催化加氢

$$\ce{R-CH=CH-R' + H2 ->[Pt/Pd/Ni/Raney\ Ni] RCH2CH2R'}\quad（可逆，放热）$$

- **顺式加成**（syn addition）
- 氢化速率：乙烯 > 一取代 > 二取代 > 三取代 > 四取代

### ★ 氢化热与稳定性

> **氢化热越大 → 位能越高 → 越不稳定**

**稳定性规律**：

1. 同碳数：**反式 > 顺式**
2. 双键碳上烷基越多越稳定：

$$\ce{R2C=CR2 > R2C=CHR > RCH=CHR > RCH=CH2 > CH2=CH2}$$

```smiles
# 四取代乙烯 — 双键碳上烷基最多，最稳定
CC(=C(C)C)C
```

---

## 17B.4 亲电加成 (Electrophilic Addition)

> **亲电试剂**：$\ce{H+, HX, X2}$… 等缺电子试剂。

---

### 17B.4.1 与卤素加成 ($\ce{X2}$)

活性：$\ce{F2 > Cl2 > Br2 > I2}$（$\ce{Br2}$ 最常用）

**应用**：$\ce{Br2/CCl4}$ **褪色** → 定性检测烯、炔；制备邻二卤代烷。

#### 溴加成的实验事实

1. 需极性条件（有离子生成）
2. 至少两步反应（产物含 $\ce{Br/Cl/OH}$）
3. **反式加成** (anti addition)

#### 历程：溴鎓离子机理

**(1) 速决步骤**：$\pi$ 电子进攻 $\ce{Br2}$ → 环状**溴鎓离子 (Bromonium ion)**：

$$\ce{C=C + Br2 ->[slow] >C(-\overset{+}{Br}-)C<}$$

**(2) 快步骤**：$\ce{Br-}$ 从溴鎓离子**背面**进攻 → **反式加成**。

> 适用于 $\ce{Br2, HOCl, HOBr, ICl}$ 等 → 均为反式加成。

**烯烃加成活性**：双键碳上烷基越多 → 越活泼

$$\ce{(CH3)2C=C(CH3)2 > (CH3)2C=CHCH3 > (CH3)2C=CH2 > CH3CH=CH2 > CH2=CH2}$$

---

### 17B.4.2 与卤化氢加成 ($\ce{HX}$)

活性：$\ce{HI > HBr > HCl}$

#### 历程：碳正离子机理

**(1) 速决步骤**：$\ce{H+}$ 加到双键碳 → 生成碳正离子：

$$\ce{C=C ->[H+][slow] -C-\overset{+}{C}-}$$

**(2) 快步骤**：$\ce{X-}$ 捕捉碳正离子。

> ★ 可能有**重排产物**。

#### 碳正离子结构

| 特征 | 描述 |
|------|------|
| 构型 | 平面型，中心碳 $sp^2$ 杂化 |
| 外层电子 | 6 电子 |
| 空轨道 | 空 $p$ 轨道 ⊥ 中心碳平面 |

#### Markovnikov 规则（马氏规则）

$$\ce{CH3CH2CH=CH2 + HBr -> CH3CH2CHBrCH3\ (80\%) + CH3CH2CH2CH2Br\ (20\%)}$$

> 不对称烯烃与 $\ce{HX}$ 加成，$\ce{H}$ 加到含 $\ce{H}$ 较多的双键碳上。

**反马氏例外**：

$$\ce{HOOC-CH=CH2 + HCl -> HOOC-CH2CH2Cl}$$
$$\ce{F3C-CH=CH2 + HCl -> F3C-CH2CH2Cl}$$

> 强吸电基（$\ce{-COOH, -CF3}$）使 $\pi$ 电子云反向偏移。

#### 影响加成取向的因素

**因素一：$\pi$ 电子云密度不均**

| 碳位置 | $\pi$ 电荷（$\ce{CH3-CH=CH2}$） |
|:---|:---:|
| $\ce{CH3-CH=}$ | $\delta^-$ 1.043 |
| $\ce{=CH2}$ | $\delta^+$ 0.972 |

> 烷基的 $+I$ 效应 + 超共轭 → 推电子 → 亲电试剂进攻 $\delta^-$。

**因素二：碳正离子稳定性决定反应快慢**

> **碳正离子越稳定 → 活化能越低 → 越容易生成 → 决定反应取向。**

碳正离子稳定性：

$$\ce{(CH3)3C+\ (3^\circ) > (CH3)2CH+\ (2^\circ) > CH3CH2+\ (1^\circ) > CH3+}$$

> 烷基的 $+I$ 效应 + $\sigma$-$p$ 超共轭稳定碳正离子。

```smiles
# 3°碳正离子 — 最稳定
[C+](C)(C)C
# 2°碳正离子
C[CH+]C
# 1°碳正离子
C[C+]
# 甲基碳正离子 — 最不稳定
[C+]
```

#### ★ 诱导效应 ($I$ Effect)

> 极性共价键中因电负性不同，共用电子对偏向，引起邻近共价键电子云偏移。

| 效应 | 条件 | 示例 |
|------|------|:---:|
| **$-I$** (吸电子) | 拉电子能力 > H | $\ce{-NO2, -COOH, -CX3}$ |
| **$+I$** (供电子) | 拉电子能力 < H | $\ce{-R}$（烷基） |

- 杂化轨道电负性：$\ce{C_{sp}(2.75) > C_{sp^2}(2.48) > C_{sp^3}(2.30)}$
- $I$ 效应沿 $\sigma$ 链传递**迅速减弱**（短程效应），有**加合性**

#### ★ Markovnikov 规则（现代表述）

> 碳碳双键的亲电加成中，**主要生成较稳定的碳正离子中间体**。

---

### 17B.4.3 与次卤酸加成 ($\ce{HOX}$)

$$\ce{CH3CH=CH2 + HOCl -> CH3CH(OH)CH2Cl}\quad（91\%）$$

> $\ce{Cl^{\delta+}-OH^{\delta-}}$，$\ce{Cl+}$ 先进攻（电负性 O 3.5 > Cl 3.0），符合马氏。

---

### 17B.4.4 与含氧无机酸及水加成

**(a) 硫酸法（间接水化）**：

$$\ce{CH3CH=CH2 ->[H2SO4] CH3CH(OSO3H)CH3 ->[H2O] CH3CH(OH)CH3}$$

**(b) 直接水化**：

$$\ce{CH3CH=CH2 ->[H2O, H+] CH3CH(OH)CH3}$$
$$\ce{(CH3)2C=CHCH3 ->[H2O, H3PO4] (CH3)2C(OH)CH2CH3}$$

> 除乙醇外，多为**仲醇或叔醇**。伯醇需硼氢化-氧化法。

---

### 17B.4.5 硼氢化-氧化反应 ⭐

> 1979 年 Nobel 化学奖（Brown H. C.）

$$\ce{RCH=CH2 ->[B2H6][H2O2, OH-] RCH2CH2OH}$$

| 特点 | 说明 |
|------|------|
| **反马氏加水** | $\ce{H}$ 加到含 $\ce{H}$ 少的碳 → **伯醇** |
| **顺式加成** | 四中心环状过渡态 |
| 与硫酸法**互补** | 硫酸法 → 仲/叔醇，硼氢化 → 伯醇 |

```smiles
# 硼氢化-氧化：反马氏→伯醇
CC=C
```

---

### 17B.4.6 过氧化物效应（仅 $\ce{HBr}$）

$\ce{HCl}$ 和 $\ce{HI}$ **无过氧化物效应**。

| 条件 | 产物 | 机理 |
|------|------|------|
| 无过氧化物 | $\ce{CH3CHBrCH2CH3}$ (90%) | 亲电（马氏） |
| **有过氧化物** | $\ce{BrCH2CH2CH2CH3}$ (95%) | **自由基（反马氏）** |

#### 自由基链式机理

**(1) 链引发**：$\ce{ROOR -> 2 RO\cdot;\quad RO\cdot + HBr -> ROH + Br\cdot}$

**(2) 链增长**：
$$\ce{Br\cdot + CH2=CHCH2CH3 -> \cdot CH2CHBrCH2CH3}$$
$$\ce{\cdot CH2CHBrCH2CH3 + HBr -> CH3CHBrCH2CH3 + Br\cdot}$$

> $\ce{Br\cdot}$ 加到含 $\ce{H}$ 多的碳 → 生成较稳定自由基 → **反马氏**。

**反马氏加成三种情况**：

| 方法 | 条件 |
|------|------|
| 过氧化物效应 | 仅 $\ce{HBr}$，自由基历程 |
| 硼氢化-氧化 | 反马氏加水 |
| $\ce{X \leftarrow C=C}$ | 强吸电基使 $\pi$ 电子云反向 |

## 17B.5 氧化反应

---

### 17B.5.1 $\ce{KMnO4}$ 氧化

| 条件 | 产物 | 应用 |
|------|------|------|
| **稀冷 $\ce{KMnO4}$，碱性/中性** | 顺式邻二醇 | 紫色 → $\ce{MnO2}$ 褪色 |
| **浓 $\ce{KMnO4, H+}$，加热** | 酮/羧酸/$\ce{CO2}$ | **鉴定不饱和键**；推双键位置 |

| 底物 | $\ce{KMnO4, H+}$ 产物 |
|------|------|
| $\ce{RCH=CH2}$ | $\ce{RCOOH + CO2}$ |
| $\ce{R2C=}$ | $\ce{R2C=O}$（酮） |

---

### 17B.5.2 臭氧化-还原水解

$$\ce{RCH=CH2 + O3 ->[Zn, H2O] RCHO + HCHO}$$

| 底物 | 产物 |
|------|------|
| $\ce{RCH=}$ | $\ce{RCHO}$ |
| $\ce{R2C=}$ | $\ce{R2C=O}$ |
| $\ce{CH2=}$ | $\ce{HCHO}$ |

> 应用：**测定烯烃结构**；制备醛、酮。

---

### 17B.5.3 环氧化 (Epoxidation)

$$\ce{RCH=CH2 + R'CO3H -> RCH(-O-)CH2}\quad（环氧化合物）$$

常用过氧酸：$\ce{CH3CO3H}$（过氧乙酸）、$\ce{C6H5CO3H}$（过氧苯甲酸）

```smiles
# 环氧乙烷
C1OC1
# 环氧丙烷
CC1OC1
```

---

### 17B.5.4 催化氧化

$$\ce{CH2=CH2 ->[Ag, 250^\circ C][O2]} \quad（环氧乙烷，工业上制乙醛）$$

---

## 17B.6 聚合反应

> 自学——烯烃聚合成高分子化合物。

## 17B.7 $\alpha$-氢的反应

> $\alpha$ 位：与官能团相邻的位置。$\ce{C_{sp^2}-C_{sp^3}}$ 极化 → $\alpha$-$\ce{H}$ 活性增强。

### 17B.7.1 $\alpha$-卤代

| 条件 | 产物 | 历程 |
|------|------|------|
| $\ce{Cl2}$，500–600°C | $\ce{ClCH2CH=CH2}$（烯丙基氯） | **自由基取代** |
| $\ce{Cl2}$，250°C | $\ce{CH3CHClCH2Cl}$ | 亲电加成 |

> ★ **NBS** ($N$-溴代丁二酰亚胺) + $h\nu$ → 烯丙位溴代（无水 $\ce{CCl4}$）。

```smiles
# 烯丙基溴 — NBS烯丙位溴代
C=CCBr
# N-溴代丁二酰亚胺
O=C1NC(=O)CC1Br
```

### 17B.7.2 $\alpha$-$\ce{H}$ 氧化

$$\ce{CH2=CHCH3 ->[O2, Cu2O, 350^\circ C] CH2=CHCHO}\quad（丙烯醛）$$
$$\ce{CH2=CHCH3 + NH3 + 1/2 O2 ->[磷钼酸盐, 410^\circ C] CH2=CHCN}\quad（丙烯腈）$$

> 丙烯腈：合成橡胶及纤维原料。

## 17B.8 炔烃化学性质

---

### 17B.8.1 $\ce{C#C}$ 与 $\ce{C=C}$ 结构对比

| 参数 | $\ce{CH2=CH2}$ | $\ce{CH#CH}$ |
|------|:---:|:---:|
| 杂化 | $sp^2$ | $sp$ |
| 构型 | 平面三角形 | **直线型** (180°) |
| $\pi$ 电子云 | 上/下对称 | **圆筒型** |
| $\ce{C-C}$ 键长 | 133.7 pm | 120.7 pm |
| 重键组成 | $\sigma + \pi$ | $\sigma + \pi + \pi$ |

### 17B.8.2 键能对比

| 键 | 总能量 | $\sigma$ | $\pi$ |
|------|:---:|:---:|:---:|
| $\ce{C-C}$ | 347 | 347 | — |
| $\ce{C=C}$ | 611 | 347 | 264 |
| $\ce{C#C}$ | 837 | 347 | 264 + 226 |

> $\ce{C=C}$ 的 $\pi$ 键 (264) ≠ $\ce{C#C}$ 的 $\pi$ 键 (264+226)。炔烃第二 $\pi$ 键较弱。

**杂化电负性**：$\ce{C_{sp} > C_{sp^2} > C_{sp^3}}$（$s$ 成分越多越强）。

---

### 17B.8.3 烯炔反应对比

| 反应 | 烯烃 | 炔烃 |
|------|:---:|:---:|
| 催化加氢 | 容易 | 比烯烃难 |
| 亲电加成 | 容易 | 比烯烃难 |
| **亲核加成** | 难 | **比烯烃易** ⭐ |
| $\alpha$-H 反应 | ✓ | — |
| **炔氢反应** | — | **特有** ⭐ |

---

### 17B.8.4 加成反应

#### (a) 催化加氢

$$\ce{RC#CH ->[H2, cat] RCH=CH2 ->[H2, cat] RCH2CH3}$$

> 分步加成；烯炔共存时 $\ce{C#C}$ 首先被氢化。

选择性还原：

| 条件 | 产物 | 立体 |
|------|------|:---:|
| Lindlar 催化剂 | 顺式烯烃 | **顺式** |
| $\ce{Na, NH3(l), -78^\circ C}$ | 反式烯烃 | **反式** |

#### (b) 与卤素加成（需 $\ce{FeCl3}$ 催化）

$$\ce{HC#CH ->[Cl2, FeCl3] ClCH=CHCl ->[Cl2, FeCl3] CHCl2CHCl2}$$

#### (c) 与 $\ce{HX}$ 加成

活性：$\ce{HI > HBr > HCl > HF}$；$\ce{HCl}$ 需 $\ce{HgCl2}$ 催化。

与 $\ce{HBr}$ 也有过氧化物效应（反马氏）。

#### (d) 加水 — 制备酮

$$\ce{RC#CH + H2O ->[HgSO4/H2SO4] [烯醇] -> RC(=O)CH3}$$

> 催化剂 $\ce{HgSO4-H2SO4}$。烯醇经**互变异构** → 甲基酮。

#### (e) 硼氢化-氧化 — 制备醛

$$\ce{RC#CH ->[B2H6][H2O2, OH-] RCH2CHO}$$

> 端基炔 → 醛（反马氏加水）。

---

### 17B.8.5 亲核加成 ⭐

> **亲核试剂**：$\ce{RO-, RCOO-, NH3, CN-}$ 等负离子或含孤对电子的分子。

$$\ce{RC#CH + H-Nu -> RC(Nu)=CH2}\quad（符合马氏规则）$$

**示例**：

$$\ce{HC#CH + HCN ->[CuCl2, 70^\circ C] CH2=CH-CN}\quad（丙烯腈，→ 聚丙烯腈纤维）$$

**历程**：速决步骤生成 $sp^2$ **碳负离子**。

> $sp^2$ 碳负离子比 $sp^3$ 碳负离子稳定 → 炔烃亲核加成**比烯烃容易**。

**乙烯基化反应**：

$$\ce{RC#CH + ROH ->[RO-] RC(OR)=CH2}$$
$$\ce{RC#CH + RCOOH ->[RCOO-] RC(OOCR)=CH2}$$

---

### 17B.8.6 氧化反应

| 氧化剂 | 产物 |
|------|------|
| $\ce{KMnO4/H+}$ | $\ce{RC# -> RCOOH}$；$\ce{HC# -> CO2 + H2O}$ |
| $\ce{O3, Zn, H2O}$ | 同上 |

> 比烯烃难氧化。

---

### 17B.8.7 链端炔氢的酸性 ⭐

#### 碳氢键酸性对比

$$sp > sp^2 > sp^3$$

| $\ce{HC#C-H}$ | $\ce{CH2=CH-H}$ | $\ce{CH3CH2-H}$ |
|:---:|:---:|:---:|
| $pK_a \approx 25$（弱酸） | ~44 | ~50 |

> $s$ 成分多 → 碳负离子稳定 → 酸性强。
>
> 端炔氢为**弱酸性**（碳质酸），不能使石蕊变红。

#### 金属炔化物生成

$$\ce{HC#CH + Na ->[110^\circ C] HC#CNa}$$

$$\ce{HC#CH + NaNH2 ->[液 NH3] HC#CNa + NH3}$$

#### 应用

**① 增碳反应（制高级炔烃）**：

$$\ce{RC#CNa + R'X ->[液 NH3] RC#CR'}$$

> 最适宜烷基化剂：**伯卤代烷**。

**② 鉴定链端炔烃**：

| 试剂 | 现象 |
|------|------|
| $\ce{Ag(NH3)2+}$ | **白色沉淀** $\ce{RC#CAg \downarrow}$ |
| $\ce{Cu(NH3)2+}$ | **砖红色沉淀** $\ce{RC#CCu \downarrow}$ |

```smiles
# 端炔银沉淀 (鉴定)
C#C[Ag]
```

---

### 17B.8.8 聚合反应

多为低聚，不生成高分子：

$$2\ \ce{HC#CH ->[Cu2Cl2, NH4Cl] CH2=CH-C#CH}\quad（乙烯基乙炔）$$

```smiles
# 乙烯基乙炔
C=CC#C
```

## 烯烃反应全景图

```
          +H₂/cat ──→ 烷烃 (顺式加成)
          │
          +X₂ ────→ 邻二卤代烷 (反式, 溴鎓离子)
          │
  加成 ─── +HX ────→ 卤代烷 (碳正离子, 马氏)
   ⭐      │         例外：-CF₃/-COOH取代 → 反马氏
          │
          +H₂O/H⁺ ─→ 醇 (马氏, 多仲/叔醇)
          │
          +B₂H₆/H₂O₂→ 伯醇 (反马氏, 顺式, Nobel 1979)
          │
          +HBr/ROOR→ 反马氏 (自由基, 仅HBr)
          │
  氧化 ─── KMnO₄ (稀冷→邻二醇; 浓热→酮/羧酸/CO₂)
   ⭐       O₃/Zn ──→ 醛/酮 (测双键位置)
          │ RCO₃H ──→ 环氧化物
          │
   α-H ─── Cl₂/500℃ → 烯丙基氯 (自由基取代)
   ⭐       NBS/hν ──→ 烯丙基溴
          │ O₂/Cu₂O ─→ 丙烯醛 / 丙烯腈
```

## 炔烃特有反应

```
  炔氢酸性 ──→ Na/NaNH₂ → RC≡CNa → +R'X → 高级炔烃(增碳)
   ⭐          Ag⁺ → 白色↓ / Cu⁺ → 砖红↓ → 鉴定端炔

  亲核加成 ──→ +HCN → 丙烯腈; +ROH → 乙烯基醚
   ⭐          sp²碳负离子稳定 → 比烯烃易

  加水 ─── HgSO₄/H₂SO₄ → 烯醇互变 → 甲基酮
```
