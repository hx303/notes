# 第十九章 芳香族烃类化合物

---

## 19.1 芳烃概述

> **芳烃 (Aromatic Hydrocarbons)**：主要指含有苯环的烃类化合物。
>
> 分子组成特点：**高碳氢比**（$\ce{C:H \approx 1:1}$）。

**分类**：

```
芳烃
├── 苯系芳烃
│   ├── 单环芳烃（苯及其衍生物）
│   └── 多环芳烃（联苯、稠环）
└── 非苯芳烃（符合 Hückel 规则的不含苯环化合物）
```

**芳香性 (Aromatic Character)**：

| 特征 | 表现 |
|------|------|
| 组成高度不饱和 | 但**不易加成、不易氧化** |
| **易取代** | 亲电取代是特征反应 |
| 特殊稳定性 | 氢化热/燃烧热低于预期 |

## 19.3 苯的结构 ⭐

### 19.3.1 实验事实

| 事实 | 含义 |
|------|------|
| 分子式 $\ce{C6H6}$ | 高度不饱和 |
| **六个 $\ce{C-C}$ 键完全等长 (0.139 nm)** | 介于 $\ce{C-C}$(0.154) 与 $\ce{C=C}$(0.134) 之间 |
| **邻二取代物只有一种** | Kekulé结构无法解释 |
| 氢化热特别低 (−209.5 kJ/mol) | 预测环己三烯为 −360 kJ/mol → 稳定化能 ~150 kJ/mol |
| 12 个原子**共平面**，键角 **120°** | $sp^2$ 杂化 |

### 19.3.2 Kekulé 结构式 (1865)

> 能解释：原子组成、连接次序、催化加氢得环己烷、一元取代物仅一种
>
> 不能解释：**键长完全等同**、**邻二取代物仅一种**、特殊稳定性

### 19.3.3 现代结构解释

**(I) 价键法 (VB)**：

> 所有碳原子 $sp^2$ 杂化 → 6 个未杂化的 $p$ 轨道形成 **$\Pi_6^6$ 六中心六电子环状闭合共轭大 $\pi$ 键**。

→ 解释：键长等同、邻二取代物唯一、特别稳定

**(II) 共振论 (Pauling, 1931–1933)**：

> 真实结构是多种经典极限式叠加而成的**共振杂化体**。

苯的两个等价 Kekulé 共振式 → 共振稳定化能 ~150 kJ/mol。

### 19.3.4 共振式书写原则

| 原则 | 说明 |
|------|------|
| **1. 原子位置不变** | 只允许 $\pi$ 电子或孤对电子排列不同 |
| **2. 未成对电子数不变** | |
| **3. 较稳定的共振式贡献大** | 共价键多 > 少；无电荷分离 > 有；负电荷在电负性大的原子上；相同电荷远离/相反电荷靠近；完整价电子层；等价共振式多 → 特别稳定 |

> 共振式 "only on paper"，共振杂化体是**单一化合物**，不是混合物。

## 19.4 物理性质

- 无色液体，**特殊芳香气味**，**有毒**（损害造血器官与神经系统）
- 比重 < 1，不溶于水
- 碳氢比高 (1:1)，燃烧有**黑烟**

## 19.5 化学性质总述

> **芳香性**：封闭大 $\pi$ 键，不易破裂 → **易取代，难加成，抗氧化**

| 反应类型 | 特点 |
|----------|------|
| **亲电取代** ⭐⭐⭐ | 芳香性特征反应 |
| 侧链 $\alpha$-H 取代 | 自由基历程（苄位活化） |
| 侧链氧化 | $\alpha$-H 存在则氧化为 $\ce{-COOH}$ |
| 加成反应 | 困难（需高温/催化剂） |

## 19.6 氧化反应

### 19.6.1 苯环氧化（难）

$$\ce{C6H6 + O2 ->[V2O5, 400^\circ C] 顺丁烯二酸酐}$$

### 19.6.2 侧链氧化

> ★ 侧链至少含一个 **$\alpha$-H** 才能被氧化 → 生成**苯甲酸**。

$$\ce{PhCH3 ->[KMnO4] PhCOOH}$$
$$\ce{PhCH2CH3 ->[KMnO4] PhCOOH}$$
$$\ce{PhC(CH3)3 ->[KMnO4] 不反应（无 $\alpha$-H）}$$

常用氧化剂：$\ce{KMnO4, HNO3, K2Cr2O7}$

---

## 19.7 侧链 $\alpha$-H 取代（自由基）

$$\ce{PhCH2CH3 ->[Cl2, h\nu/高温] PhCHClCH3}$$
$$\ce{PhCH2CH3 ->[Br2/NBS, h\nu] PhCHBrCH3}$$

> **历程**：光或过氧化物引发 → 苄基自由基（$p$-$\pi$ 共轭稳定）→ 自由基取代。
>
> **应用**：制备苄基型卤代烃。

```smiles
# 苄基自由基 — 稳定
[CH]c1ccccc1
# 苄基溴
BrCc1ccccc1
```

---

## 19.8 加成反应（难）

苯在高温/催化剂下可加氢：

$$\ce{C6H6 + 3H2 ->[Ni, \Delta] 环己烷}$$

> 不能分步加氢（环己二烯、环己烯产物能量高于苯）。

## 19.9 芳香亲电取代反应 ⭐⭐⭐

> **历程**：加成-消去，速决步骤生成 **$\sigma$ 络合物（苯正离子，arenium ion）**

$$
\ce{PhH + E+ ->[slow] [PhH-E]+ (\sigma络合物) ->[-H+][fast] PhE}
$$

### 19.9.1 卤代 (Halogenation)

$$\ce{PhH + X2 ->[FeX3/Fe][50^\circ C] PhX + HX}$$

活性：$\ce{F2 > Cl2 > Br2 > I2}$

> $\ce{I2}$ 极不活泼，需氧化剂（如 $\ce{HNO3}$）产生 $\ce{I+}$。

**历程**：

1. $\ce{Br2 + FeBr3 -> Br+ + FeBr4-}$（亲电试剂生成）
2. $\ce{PhH + Br+ ->[slow] [PhH-Br]+ (\sigma络合物)}$
3. $\ce{[PhH-Br]+ ->[-H+] PhBr}$

```smiles
# 溴苯
Brc1ccccc1
# 碘苯 (需HNO3氧化)
Ic1ccccc1
```

### 19.9.2 硝化 (Nitration)

$$\ce{PhH + HNO3 ->[H2SO4, 50-55^\circ C] PhNO2 + H2O}$$

> 硝化试剂：**混酸**（浓 $\ce{HNO3}$ : 浓 $\ce{H2SO4}$ = 1:2）

**亲电试剂生成**：

$$\ce{HNO3 + 2H2SO4 -> NO2+ + H3O+ + 2HSO4-}$$

甲苯硝化速度比苯快（甲基活化苯环）。

```smiles
# 硝基苯
O=N(=O)c1ccccc1
# 2,4,6-三硝基甲苯 (TNT)
Cc1c(N(=O)=O)cc(N(=O)=O)cc1N(=O)=O
```

### 19.9.3 磺化 (Sulfonation)

$$\ce{PhH + H2SO4(浓) ->[75^\circ C] PhSO3H + H2O}$$

**特点**：

| 特点 | 意义 |
|------|------|
| **可逆** | 加水/酸加热 → 去磺化 |
| 磺酸基**亲水** | 长链烷基苯磺酸盐是表面活性剂 |
| **立体选择性** | 温度控制邻/对位比例 |
| **临时占位** | 磺化-取代-去磺化实现定位合成 |

```smiles
# 苯磺酸
O=S(=O)(O)c1ccccc1
```

### 19.9.4 傅-克反应 (Friedel-Crafts)

#### (a) 傅-克烷基化 (F-C Alkylation)

$$\ce{PhH + RX ->[AlCl3] PhR + HX}$$

烷基化试剂：卤代烷、烯烃、醇。

**FC 烷基化特点**：

| 特点 | 原因 |
|------|------|
| 强吸电/碱性基团存在时不反应 | $\ce{-NO2, -NH2}$ 毒化催化剂 |
| **多烷基化** | 产物比苯更活泼 |
| **可逆 + 歧化** | |
| **重排** | 碳正离子重排：$\ce{CH3CH2CH2+ -> (CH3)2CH+}$ |

> FC 烷基化不能用于制备**三个碳以上的直链烷基苯**（重排）。

#### (b) 傅-克酰基化 (F-C Acylation)

$$\ce{PhH + RCOX ->[AlCl3] PhCOR + HX}$$

酰基化试剂：酰卤、酸酐、羧酸。

**FC 酰基化特点**：

| 特点 | 原因 |
|------|------|
| **不可逆** | |
| **一取代即停** | 酰基钝化苯环 |
| **不重排** | 酰基正离子稳定 |
| 催化剂用量多 | 酰化剂与催化剂络合 |

**应用**：制芳酮 + Clemmensen 还原 → 直链烷基苯。

$$\ce{PhH ->[CH3CH2COCl, AlCl3] PhCOCH2CH3 ->[Zn-Hg/HCl] PhCH2CH2CH3}$$

```smiles
# 苯乙酮 (Acetophenone)
CC(=O)c1ccccc1
# 二苯甲酮 (Benzophenone)
O=C(c1ccccc1)c2ccccc2
```

### 19.9.5 氯甲基化

$$\ce{PhH + HCHO + HCl ->[ZnCl2] PhCH2Cl}$$

> $\ce{ClCH2+}$ 为弱亲电试剂；吸电基取代苯不反应。

**应用**：$\ce{-CH2Cl}$ 可转化为 $\ce{-CH2OH, -CH2NH2, -CH2CN, -CH2COOH}$ 等。

## 19.10 苯环上的取代定位效应 ⭐⭐⭐

### 19.10.1 两类定位基

| 类型 | 定位 | 对苯环影响 | 示例 |
|------|:---:|:---:|------|
| **第Ⅰ类** | **邻对位** (o/p) | 活化（除卤素） | $\ce{-O-}, \ce{-NR2}, \ce{-OH}, \ce{-OCH3}, \ce{-R}, \ce{-Ph}, \ce{-F}, \ce{-Cl}, \ce{-Br}, \ce{-I}$ |
| **第Ⅱ类** | **间位** (m) | **钝化** | $\ce{-CF3}, \ce{-NR3+}, \ce{-NO2}, \ce{-CN}, \ce{-SO3H}, \ce{-CHO}, \ce{-COR}, \ce{-COOH}$ |

### 19.10.2 电子效应解释

**第Ⅰ类（邻对位定位基）**：

- 推电子基 → 增大环上 $\pi$ 电子云密度（邻对位最高）→ **活化苯环** → 稳定 $\sigma$ 络合物
- 例外：**卤素** ($\ce{-F, -Cl, -Br, -I}$) 有 $ -I > +C$ → 钝化苯环，但 $+C$ 效应使邻对位电子云密度相对较高 → 仍为**邻对位**定位

**第Ⅱ类（间位定位基）**：

- 吸电子基 → 降低环上 $\pi$ 电子云密度（间位相对较高）→ **钝化苯环** → $\sigma$ 络合物更不稳定

### 19.10.3 多取代基定位规则

| 规则 | 内容 |
|------|------|
| **规律一** | 两基**同类**，强基控制位置；两基**异类**，活化基控制位置 |
| **规律二** | 定位能力相近 → 无优势产物 |
| **规律三** | **空间位阻**：大基团或大亲电试剂 → 难邻位取代；基团在间位时中间位难取代 |
| **规律四** | 更多定位基时，可取代位置减少 |

### 19.10.4 合成应用原则

1. 充分考虑**基团引入顺序**
2. 考虑定位基性质和强弱
3. 利用**占位基团**（如磺化→取代→去磺化）

## 19.11 多环芳烃

### 19.11.1 萘 (Naphthalene) ⭐

**结构**：两个苯环稠合，10 个 $\pi$ 电子。

| 位置 | 特点 |
|------|------|
| **$\alpha$-位** (1,4,5,8) | 电子云密度高 → **优先发生亲电取代** |
| **$\beta$-位** (2,3,6,7) | 电子云密度较低 |

> 共振能 255 kJ/mol < 苯的两倍 (150×2=300) → 芳香性比苯弱 → **化学性质比苯活泼**。

**亲电取代**：一取代多为 **$\alpha$ 位**。

| 反应 | 条件/产物 |
|------|------|
| 卤代 | $\ce{X2/CCl4, r.t.}$ → $\alpha$-卤萘 |
| 硝化 | $\ce{HNO3/H2SO4, r.t.}$ → $\alpha$-硝基萘 |
| 磺化 | 60°C → $\alpha$; 165°C → $\beta$（热力学控制） |
| FC 酰基化 | 非极性溶剂($\ce{CS2}$) → $\alpha$; 极性溶剂($\ce{PhNO2}$) → $\beta$（溶剂化体积效应） |

**氧化**：比苯易氧化 → 制**邻苯二甲酸酐**（工业应用）。

**还原**：可分步加氢（1,4-二氢化萘、1,2-二氢化萘）。

**二元取代定位**：

| 已有基团位置 | 新基团进入 |
|------|------|
| 1 位有 Ⅰ 类基 | 同环 4 位 |
| 2 位有 Ⅰ 类基 | 同环 1 位 |
| 有 Ⅱ 类基 | 异环 $\alpha$ 位 |

### 19.11.2 蒽和菲

> 芳香性次序：**苯 > 萘 > 菲 > 蒽**

- 蒽、菲的 9,10-位最活泼（反应后形成两个独立苯环）
- 蒽可发生 9,10-位 Diels-Alder 反应

```smiles
# 蒽醌 (Anthraquinone)
O=C1c2ccccc2C(=O)c3ccccc13
```

### 19.11.3 致癌性

> 3,4-苯并芘 (Benzo[a]pyrene) 氧化酶催化形成致癌物，与 DNA 鸟嘌呤结合。

## 19.12 非苯芳烃与 Hückel 规则 ⭐

### 19.12.1 Hückel 规则 ($4n+2$)

> 单环共轭多烯具备以下特征时具有**芳香性**：
>
> 1. 环原子共平面
> 2. $sp^2$ 杂化原子
> 3. $\pi$ 电子数 = **$4n+2$**（$n = 0, 1, 2, \dots$）

| $\pi$ 电子数 | $4n+2$? | 芳香性 |
|:---:|:---:|:---:|
| 2 | ✅ ($n=0$) | 有 |
| 4 | ❌ | **反芳香性** |
| 6 | ✅ ($n=1$) | 有（苯） |
| 10 | ✅ ($n=2$) | 有（萘） |
| 14 | ✅ ($n=3$) | 有（蒽、菲） |

### 19.12.2 非苯芳烃示例

**$\pi$ 电子数计算**：每个双键贡献 2 个 $\pi$ 电子，碳负离子贡献 2，碳正离子贡献 0。

| 化合物 | $\pi$ 电子数 | 芳香性 |
|------|:---:|:---:|
| 环丙烯正离子 | 2 | ✅ ($n=0$) |
| 环戊二烯负离子 | 6 | ✅ ($n=1$) |
| 环庚三烯正离子 (Tropylium) | 6 | ✅ ($n=1$) |
| 环辛四烯二负离子 | 10 | ✅ ($n=2$) |
| 环丁二烯 | 4 | ❌ 反芳香性 |

```smiles
# 环戊二烯负离子 — 6π电子，芳香性
[cH-]1cccc1
# 环庚三烯正离子 (Tropylium) — 6π电子，芳香性
[cH+]1cccccc1
```

### 19.12.3 轮烯 (Annulenes)

> 单双键交替的大环共轭多烯称为**轮烯**。

| 轮烯 | $\pi$ 电子数 | 芳香性 | 原因 |
|------|:---:|:---:|------|
| [10]轮烯 | 10 | ❌ | 环内 H 排斥 → 不共平面 |
| [14]轮烯 | 14 | ❌ | 同上 |
| **[18]轮烯** | 18 | **✅** | 环足够大，可共平面 |

### 19.12.4 应用：二茂铁 (Ferrocene)

> 环戊二烯负离子 + $\ce{Fe^{2+}}$ → 二茂铁 → 具有芳香性，可发生亲电取代（如 FC 酰基化）。

## 单环芳烃反应全景图

```
芳烃 (Ar-H)
│
├── 氧化
│   ├── 苯环氧化 ──→ 顺酐 (V₂O₅, 400°C) [难]
│   └── 侧链氧化 ──→ Ar-COOH (KMnO₄) [需α-H]
│
├── α-H取代 (自由基)
│   └── Cl₂/hν 或 NBS/hν ──→ 苄基卤
│
├── 加成 [难]
│   └── 3H₂/Ni,Δ ──→ 环己烷
│
└── 亲电取代 ⭐ (加成-消去, σ络合物)
    │
    ├── 卤代 ──→ Ar-X (X₂/FeX₃)
    ├── 硝化 ──→ Ar-NO₂ (混酸)
    ├── 磺化 ──→ Ar-SO₃H (可逆, 占位)
    ├── FC烷基化 ──→ Ar-R (多取代, 重排)
    ├── FC酰基化 ──→ Ar-COR (不可逆, 不重排)
    └── 氯甲基化 ──→ Ar-CH₂Cl
         │
         └── 定位效应
              ├── 第Ⅰ类 (o/p): -OH,-OR,-R,-NH₂,-X
              │    └── 活化 (卤素钝化但o/p)
              └── 第Ⅱ类 (m): -NO₂,-CF₃,-CN,-COOH
                   └── 钝化
```
