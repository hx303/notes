# 第4章 向量空间

## §4.1-4.2 线性相关与线性无关

### 线性组合
$\boldsymbol{\beta} = k_1\boldsymbol{\alpha}_1 + \cdots + k_m\boldsymbol{\alpha}_m$

### 线性相关 / 无关

- **线性相关**：存在不全为零的 $k_i$ 使 $k_1\boldsymbol{\alpha}_1 + \cdots + k_m\boldsymbol{\alpha}_m = 0$
- **线性无关**：仅当 $k_1 = \cdots = k_m = 0$ 时成立

### 充要条件（方阵）
$|A| = 0 \iff$ 列向量线性相关；$|A| \neq 0 \iff$ 线性无关。

## §4.3 极大无关组与秩

- **极大无关组**：从向量组中取出的线性无关子集，且不能再添加组内向量而保持无关
- **秩**：极大无关组所含向量的个数

> 向量组的秩 = 其构成矩阵的秩。

## §4.4 矩阵的秩

### 定义
矩阵中不等于零的子式的**最高阶数**。

### 行秩 = 列秩
矩阵的行秩 = 列秩 = 秩。

### 求法
初等行变换化为阶梯形 → 非零行数 = 秩。

### 秩不等式
| 公式 | 说明 |
|------|------|
| $R(AB) \leq \min(R(A), R(B))$ | 乘积秩≤各因子秩 |
| $R(A+B) \leq R(A) + R(B)$ | 和的秩 |
| $R(A) + R(B) - n \leq R(AB)$ | Sylvester 秩不等式 |

### 满秩与可逆
$A_{n\times n}$ 满秩（$R=n$）$\iff |A| \neq 0 \iff A$ 可逆。

## §4.5 子空间

$\mathbb{R}^n$ 的子集 $W$，若对加法和数乘封闭，且含零向量，则为**子空间**。

### 生成子空间
$\operatorname{span}\{\boldsymbol{\alpha}_1, \dots, \boldsymbol{\alpha}_m\} = \{ \sum k_i \boldsymbol{\alpha}_i \mid k_i \in \mathbb{R} \}$

### 解空间
齐次方程组 $Ax = 0$ 的解集构成子空间（解空间），维数 $= n - R(A)$。

## §4.6 基与维数

- **基**：线性无关且能生成整个空间的向量组
- **维数**：基中向量的个数 = 极大无关组中向量的个数
- 标准基：$\{e_1, \dots, e_n\}$，$\mathbb{R}^n$ 的维数为 $n$

## §4.7 线性方程组解的结构

### 齐次 $Ax = 0$
解空间的维数 $= n - R(A)$。基础解系含 $n - R(A)$ 个线性无关的解。

通解：$X = k_1\boldsymbol{\xi}_1 + \cdots + k_{n-r}\boldsymbol{\xi}_{n-r}$

### 非齐次 $Ax = b$
通解 = **特解** + **齐次通解**：
$$
X = X^* + k_1\boldsymbol{\xi}_1 + \cdots + k_{n-r}\boldsymbol{\xi}_{n-r}
$$

### 参考答案

| 题号 | 答案 | 提示 |
|:---:|:---:|------|
| 1 | ✓ | 零向量自身构成线性相关组 |
| 2 | ✗ | 是阶梯形中非零行的行数，不是原矩阵 |
| 3 | ✓ | 自由变量个数 = $n - R(A)$ |
| 4 | B | $\boldsymbol{\alpha}_2 = 2\boldsymbol{\alpha}_1$，线性相关，秩为 1 |
| 5 | A | $n - R(A) = 3 - 2 = 1$ |
| 6 | 相关 | $\boldsymbol{\alpha}_3 = \boldsymbol{\alpha}_1 + \boldsymbol{\alpha}_2$ |
| 7 | $R(A)=3$，$\|A\|=-18$ | 满秩，可逆 |
| 8 | $\boldsymbol{\xi}_1 = (0,1,0,-1)^T$，$\boldsymbol{\xi}_2 = (-1,0,1,0)^T$ | RREF 后 $x_2,x_4$ 为自由变量 |
| 9 | 矩阵秩 $≤ n$，故 $n+1$ 列向量必线性相关 | 列数 > 行数 |
| 10 | 非齐次不是子空间（不含零），差量为齐次解 | 所有解 = 任一特解 + 齐次解空间平移 |
