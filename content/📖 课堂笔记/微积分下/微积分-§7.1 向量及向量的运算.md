# §7.1 向量及向量的运算

> 第七章 空间解析几何与向量代数

---

## 一、向量的概念

### 1.1 向量的定义

**向量**是既有大小又有方向的量。

- **表示方法**：在坐标系中用**有向线段**表示向量
  - 有向线段的**长度**表示向量的大小
  - 有向线段的**方向**表示向量的方向

$$
\vec{a},\ \vec{b},\ \vec{c},\ \cdots\quad\text{或}\quad \overrightarrow{AB},\ \overrightarrow{CD},\ \cdots
$$

- **起点** $A$，**终点** $B$：向量记为 $\overrightarrow{AB}$ 或 $\vec{a}$

### 1.2 向量的模

**向量的模**即向量的大小（长度），记为 $|\vec{a}|$，$|\overrightarrow{AB}|$。

$$
|\vec{a}| \geq 0,\quad |\vec{a}| = 0 \iff \vec{a} = \vec{0}
$$

### 1.3 特殊向量

#### （1）相等向量（自由向量）

若两个向量 $\vec{a}$ 和 $\vec{b}$ 的**大小相等，且方向相同**，则称两向量相等，记为 $\vec{a} = \vec{b}$。

这样的向量称为**自由向量**——一个自由向量经平行移动后与原向量相等。

> 例：平行四边形 $ABCD$ 中，$\overrightarrow{AB} = \overrightarrow{DC}$，$\overrightarrow{AD} = \overrightarrow{BC}$

#### （2）负向量

若两个向量 $\vec{a}$ 和 $\vec{b}$ 的**大小相等，方向相反**，则称 $\vec{b}$ 为 $\vec{a}$ 的**负向量**，记为 $\vec{b} = -\vec{a}$（或 $\vec{a} = -\vec{b}$）。

> 例：平行四边形 $ABCD$ 中，$\overrightarrow{AB} = -\overrightarrow{CD}$，$\overrightarrow{CD} = -\overrightarrow{AB}$

#### （3）零向量

长度为**零**的向量称为**零向量**，记为 $\vec{0}$。

- 零向量无一定方向，也可看成是任意方向的向量
- $|\vec{0}| = 0$

#### （4）单位向量

长度为 1（模为 1）的向量称为**单位向量**。

**注意**：单位向量不唯一，任何方向的单位向量都存在。

**向量的单位化**：设 $\vec{a} \neq \vec{0}$，则与 $\vec{a}$ 同方向的单位向量为：

$$
\vec{a}^{\,0} = \frac{\vec{a}}{|\vec{a}|}
$$

从而有：

$$
\vec{a} = |\vec{a}| \cdot \vec{a}^{\,0}
$$

> **重要推论**：任一非零向量除以它的模即为该向量的单位向量；任一非零向量等于它的模乘以其单位向量。

> **推论**：若向量 $\vec{a}$，$\vec{b}$ 同向，且 $|\vec{a}| = |\vec{b}|$，则 $\vec{a} = \vec{b}$。

## 二、向量的线性运算

### 2.1 向量的加法

#### 三角形法则

设有两个向量 $\vec{a}$ 和 $\vec{b}$，任取一点 $A$，作 $\overrightarrow{AB} = \vec{a}$，再以 $B$ 为起点作 $\overrightarrow{BC} = \vec{b}$，连接 $AC$，则向量 $\overrightarrow{AC}$ 称为 $\vec{a}$ 与 $\vec{b}$ 的**和**：

$$
\vec{c} = \vec{a} + \vec{b} = \overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC}
$$

> **口诀**：首尾相接，从起点指向终点。

#### 封闭多边形法则

设有向量 $\vec{a}, \vec{b}, \vec{c}, \vec{d}$，将它们**首尾相连**，则从 $\vec{a}$ 的起点到 $\vec{d}$ 的终点的向量即为：

$$
\vec{a} + \vec{b} + \vec{c} + \vec{d}
$$

> 坐标系可以是二维或三维。

### 2.2 向量的减法

两个向量 $\vec{a}$ 与 $\vec{b}$ 的差规定为：

$$
\vec{a} - \vec{b} = \vec{a} + (-\vec{b})
$$

**几何意义**：从 $\vec{b}$ 的终点向 $\vec{a}$ 的终点所引向量即为 $\vec{a} - \vec{b}$。

> **负向量**：设 $\vec{a}$ 为一向量，与 $\vec{a}$ 的模相等而方向相反的向量称为 $\vec{a}$ 的**负向量**，记作 $-\vec{a}$。

### 2.3 向量加法的运算规律

| 规律 | 表达式 | 说明 |
|------|--------|------|
| **(1)** 互逆性 | 若 $\vec{a} + \vec{b} = \vec{0}$，则 $\vec{b} = -\vec{a}$ 或 $\vec{a} = -\vec{b}$ | 和为 $\vec{0}$ 的两个向量互为负向量 |
| **(2)** 零向量 | $\vec{a} + \vec{0} = \vec{a}$ | 零向量是加法单位元 |
| **(3)** 交换律 | $\vec{a} + \vec{b} = \vec{b} + \vec{a}$ | |
| **(4)** 结合律 | $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$ | |
| **(5)** 消去律 | 若 $\vec{a} + \vec{b} = \vec{a} + \vec{c}$，则 $\vec{b} = \vec{c}$ | |

> 其中 (5) 的几何含义：$\vec{b}$ 的起点与 $\vec{a}$ 的终点重合，$\vec{b}$ 的终点与 $\vec{a}$ 的起点重合 → 构成封闭回路 → $\vec{b} = \vec{c}$

## 三、数乘运算

### 3.1 定义

实数 $k$ 与向量 $\vec{a}$ 相乘称为**数乘运算**，结果仍是一个向量，记为 $k\vec{a}$。

- **模**：$|k\vec{a}| = |k| \cdot |\vec{a}|$
- **方向**：
  - $k > 0$：与 $\vec{a}$ 同向
  - $k < 0$：与 $\vec{a}$ 反向

向量的加法、减法与数乘运算统称为向量的**线性运算**。

### 3.2 数乘运算的运算规律

| 规律 | 表达式 |
|------|--------|
| **(1)** 结合律 | $k(l\vec{a}) = (kl)\vec{a}$ |
| **(2)** 分配律 | $(k + l)\vec{a} = k\vec{a} + l\vec{a}$ |
| **(3)** 零因子律 | 若 $k\vec{a} = \vec{0}$，则 $k = 0$ 或 $\vec{a} = \vec{0}$ |

## 四、向量的夹角与位置关系

### 4.1 向量的夹角

设有两个非零向量 $\vec{a}$，$\vec{b}$，任取空间一点 $O$，作 $\overrightarrow{OA} = \vec{a}$，$\overrightarrow{OB} = \vec{b}$，规定不超过 $\pi$ 的 $\angle AOB$ 称为向量 $\vec{a}$ 与 $\vec{b}$ 的**夹角**，记作：

$$
(\widehat{\vec{a}, \vec{b}}) \quad\text{或}\quad (\widehat{\vec{b}, \vec{a}})
$$

- $(\widehat{\vec{a}, \vec{b}}) = 0$：$\vec{a}$ 与 $\vec{b}$ **同向**
- $(\widehat{\vec{a}, \vec{b}}) = \pi$：$\vec{a}$ 与 $\vec{b}$ **反向**
- $(\widehat{\vec{a}, \vec{b}}) = 0$ 或 $\pi$：$\vec{a}$ 与 $\vec{b}$ **平行（共线）**，记作 $\vec{a} \parallel \vec{b}$
- $(\widehat{\vec{a}, \vec{b}}) = \dfrac{\pi}{2}$：$\vec{a}$ 与 $\vec{b}$ **垂直**，记作 $\vec{a} \perp \vec{b}$

> 注：零向量与任意向量的关系比较特殊——零向量既可以认为与任意向量平行，也可以认为与任意向量垂直。

### 4.2 向量共面

**定义**：$k$（$k \geq 3$）个向量与同一个平面平行，则称这些向量**共面**。

从几何上看：把它们的起点固定在同一点时，$k$ 个终点和公共起点在同一个平面上。

**常用判别法**：三个向量与同一非零向量垂直 $\implies$ 三向量共面。

## 五、共线与共面定理

### 5.1 共线定理

**定理 1**：设 $\vec{a} \neq \vec{0}$，则 $\vec{a}$ 与 $\vec{b}$ 共线的**充要条件**是存在**唯一**的数 $k$，使得 $\vec{b} = k\vec{a}$。

> 这是向量坐标表示的理论依据。

**定理 1 的等价表述（推论）**：向量 $\vec{a}$ 与 $\vec{b}$ 共线的充要条件是存在不全为零的数 $k_1, k_2$，使得 $k_1\vec{a} + k_2\vec{b} = \vec{0}$。

**证明**：

*必要性*：当 $\vec{a} = \vec{0}$ 或 $\vec{b} = \vec{0}$ 时，结论显然成立。

当 $\vec{a}, \vec{b}$ 均不为零时，由 $\vec{a}$ 与 $\vec{b}$ 平行，存在实数 $l$ 使 $\vec{a} = l\vec{b}$，移项得 $\vec{a} - l\vec{b} = \vec{0}$。取 $k_1 = 1$，$k_2 = -l$，即存在不全为零的 $k_1, k_2$ 使 $k_1\vec{a} + k_2\vec{b} = \vec{0}$。

*充分性*：若存在不全为零的数 $k_1, k_2$ 使 $k_1\vec{a} + k_2\vec{b} = \vec{0}$。不妨设 $k_2 \neq 0$，则：

$$
\vec{b} = -\frac{k_1}{k_2}\vec{a}
$$

由定理 1 知 $\vec{a}$ 与 $\vec{b}$ 共线。$\square$

### 5.2 共面定理

**定理 2**：若向量 $\vec{a}, \vec{b}, \vec{c}$ 满足 $\vec{c} = k_1\vec{a} + k_2\vec{b}$（即 $\vec{c}$ 可由 $\vec{a}, \vec{b}$ 线性表出），则 $\vec{a}, \vec{b}, \vec{c}$ **共面**。

**几何理解**：
- 以 $O$ 为起点，作 $\overrightarrow{OM_1} = k_1\vec{a}$，$\overrightarrow{OM_2} = k_2\vec{b}$
- 以 $OM_1$ 和 $OM_2$ 为邻边作平行四边形，对角线即为 $\vec{c}$
- $\vec{a}, \vec{b}, \vec{c}$ 在同一平面内

**推论**：三个向量 $\vec{a}, \vec{b}, \vec{c}$ 共面的充要条件是存在**不全为零**的数 $k_1, k_2, k_3$，使得：

$$
k_1\vec{a} + k_2\vec{b} + k_3\vec{c} = \vec{0}
$$

## 六、例题精讲

### 例题 1：平行四边形对角线的中点表示

> 在平行四边形 $ABCD$ 中，设 $\overrightarrow{AB} = \vec{a}$，$\overrightarrow{AD} = \vec{b}$。试用 $\vec{a}$ 和 $\vec{b}$ 表示向量 $\overrightarrow{MA}$ 和 $\overrightarrow{MC}$，这里 $M$ 是平行四边形对角线的交点。

<div style="text-align:center">

```
        D ─────────── C
        │ \         / │
        │   \  M  /   │
        │     \/      │
        │     /\      │
        │   /    \    │
        │ /        \  │
        A ─────────── B
              a→
```

</div>

**解**：

**第一步**：找到关键向量关系。

由于 $M$ 是对角线交点，也是两条对角线的中点，因此：

$$
\overrightarrow{AM} = \overrightarrow{MC},\quad \overrightarrow{BM} = \overrightarrow{MD}
$$

**第二步**：求 $\overrightarrow{AC}$（对角线）。

由平行四边形法则：

$$
\overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{AD} = \vec{a} + \vec{b}
$$

**第三步**：求 $\overrightarrow{AM}$。

因为 $M$ 是 $AC$ 的中点：

$$
\overrightarrow{AM} = \frac{1}{2}\overrightarrow{AC} = \frac{1}{2}(\vec{a} + \vec{b})
$$

**第四步**：求 $\overrightarrow{MA}$。

$$
\overrightarrow{MA} = -\overrightarrow{AM} = -\frac{1}{2}(\vec{a} + \vec{b})
$$

**第五步**：求 $\overrightarrow{MC}$。

$$
\overrightarrow{MC} = \overrightarrow{AM} = \frac{1}{2}(\vec{a} + \vec{b})
$$

**答案**：

$$
\boxed{\overrightarrow{MA} = -\frac{1}{2}(\vec{a} + \vec{b}),\quad \overrightarrow{MC} = \frac{1}{2}(\vec{a} + \vec{b})}
$$

> **验证**：$\overrightarrow{MA} + \overrightarrow{MC} = -\frac{1}{2}(\vec{a} + \vec{b}) + \frac{1}{2}(\vec{a} + \vec{b}) = \vec{0}$，符合 $M$ 是中点的性质（$\overrightarrow{MA}$ 与 $\overrightarrow{MC}$ 互为负向量）。$\checkmark$

### 例题 2：用向量方法证明平行四边形

> 试用向量方法证明：**对角线互相平分的四边形必是平行四边形**。

<div style="text-align:center">

```
        D ─────────── C
          \         /
           \   M  /
            \    /
             \  /
              A ─ B
```

</div>

**证明**：

**第一步**：设四边形 $ABCD$ 的对角线交点为 $M$。

由条件"对角线互相平分"可知：

$$
\overrightarrow{AM} = \overrightarrow{MC},\quad \overrightarrow{BM} = \overrightarrow{MD}
$$

**第二步**：考察边向量 $\overrightarrow{AD}$。

利用向量加法的三角形法则：

$$
\overrightarrow{AD} = \overrightarrow{AM} + \overrightarrow{MD}
$$

**第三步**：代入中点条件。

由 $\overrightarrow{AM} = \overrightarrow{MC}$ 且 $\overrightarrow{MD} = \overrightarrow{BM}$：

$$
\begin{aligned}
\overrightarrow{AD} &= \overrightarrow{AM} + \overrightarrow{MD} \\
&= \overrightarrow{MC} + \overrightarrow{BM} \\
&= \overrightarrow{BM} + \overrightarrow{MC} \quad\text{(交换律)} \\
&= \overrightarrow{BC}
\end{aligned}
$$

**第四步**：得出结论。

由 $\overrightarrow{AD} = \overrightarrow{BC}$ 可知 $AD$ 与 $BC$ 平行且相等。

同理可证 $\overrightarrow{AB} = \overrightarrow{DC}$。

因此四边形 $ABCD$ 是平行四边形。$\blacksquare$

> **思路回顾**：关键技巧是"连接中点 → 利用中点条件替换 → 利用向量加法合并"，本质上是用向量语言翻译"对角线互相平分"这一几何条件。

## 七、本节小结

| 知识点 | 关键内容 |
|--------|----------|
| **向量的模** | $\|\vec{a}\|$，非负实数 |
| **零向量** | 长度为0，无方向（或任意方向） |
| **单位向量** | $\vec{a}^{\,0} = \dfrac{\vec{a}}{\|\vec{a}\|}$ |
| **自由向量** | 平移不变，只关心大小和方向 |
| **加法** | 三角形法则、平行四边形法则、多边形法则 |
| **减法** | $\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$ |
| **数乘** | $\|k\vec{a}\| = \|k\| \cdot \|\vec{a}\|$，$k>0$同向，$k<0$反向 |
| **共线条件** | $k_1\vec{a} + k_2\vec{b} = \vec{0}$ 且 $k_1,k_2$ 不全为零 |
| **共面条件** | $k_1\vec{a} + k_2\vec{b} + k_3\vec{c} = \vec{0}$ 且 $k_1,k_2,k_3$ 不全为零 |
