# §8.10 多元函数的极值与最值

> 无条件极值（$AC-B^2$ 判别法）→ 最值（封闭区域）→ 条件极值（拉格朗日乘数法）

---

## §8.10.1 多元函数的（无条件）极值

### 定义

$z=f(x,y)$ 在 $P_0(x_0,y_0)$ 的某邻域内，若对邻域内所有点 $(x,y)$：

- $f(x,y) \le f(x_0,y_0)$ → **极大值**
- $f(x,y) \ge f(x_0,y_0)$ → **极小值**

> 极值是**局部**概念。

**直观例子**：

| 函数 | $(0,0)$ 处 |
|------|:---:|
| $z=x^2+y^2$ | 极小值（抛物线碗） |
| $z=-x^2-y^2$ | 极大值（倒碗） |
| $z=xy$ | **无极值**（马鞍面） |

---

### 必要条件（定理 1）

若 $f$ 在 $(x_0,y_0)$ 有偏导数且取得极值，则：

$$
\boxed{f_x'(x_0,y_0) = 0,\quad f_y'(x_0,y_0) = 0}
$$

称满足此条件的点为**驻点**。

> ⚠️ 驻点不一定是极值点！如 $z=xy$ 在 $(0,0)$ 是驻点但非极值（马鞍面）。

---

### 充分条件（定理 2）— $AC-B^2$ 判别法 ⭐

设 $f_x'=f_y'=0$，记：

$$
A = f_{xx}''(x_0,y_0),\quad B = f_{xy}''(x_0,y_0),\quad C = f_{yy}''(x_0,y_0)
$$

| 判别式 | 结论 |
|:--:|------|
| $AC-B^2 > 0$ 且 $A>0$ | **极小值** |
| $AC-B^2 > 0$ 且 $A<0$ | **极大值** |
| $AC-B^2 < 0$ | **无极值**（鞍点） |
| $AC-B^2 = 0$ | **不能确定**，另行讨论 |

> 🧠 **记忆**：$AC-B^2 = \det\begin{pmatrix}A&B\\B&C\end{pmatrix}$，矩阵正定 → 极小；负定 → 极大；不定 → 鞍点。

---

### 求极值的三步走

```
Step 1: 令 f_x'=0, f_y'=0 → 解出所有驻点
Step 2: 求 A=f_xx'', B=f_xy'', C=f_yy''
Step 3: 在每个驻点计算 AC-B²，判定
```

---

**例 1（考研）**：由方程 $x^2+y^2+z^2+2x-6y+4z+10=0$ 确定的 $z=f(x,y)$ 的极值。

**Step 1**：隐函数求驻点。方程两边对 $x,y$ 求偏导：

$2x+2zz_x'+2+4z_x'=0$ ⇒ $z_x' = -\frac{x+1}{z+2}$

$2y+2zz_y'-6+4z_y'=0$ ⇒ $z_y' = -\frac{y-3}{z+2}$

令 $z_x'=z_y'=0$ ⇒ $x=-1,\; y=3$。代入原方程：$1+9+z^2-2-18+4z+10=0$ ⇒ $z^2+4z=0$ ⇒ $z=0$ 或 $z=-4$。

两个驻点：$P_1(-1,3,0)$，$P_2(-1,3,-4)$。

**Step 2**：求二阶偏导（在驻点处）。

$z_{xx}'' = -\frac{(z+2) - (x+1)z_x'}{(z+2)^2}$，代入 $x=-1$：$z_{xx}'' = -\frac{1}{z+2}$

同理 $z_{yy}'' = -\frac{1}{z+2}$，$z_{xy}''=0$

**Step 3**：判别。

$P_1(z=0)$：$A=C=-\frac12$，$B=0$，$AC-B^2=\frac14>0$，$A<0$ → **极大值** $z(0)=0$

$P_2(z=-4)$：$A=C=\frac12$，$B=0$，$AC-B^2=\frac14>0$，$A>0$ → **极小值** $z(-4)=-4$

---

**例 2（考研）**：已知 $\lim_{(x,y)\to(0,0)}\frac{f(x,y)-1}{3x-y^2+e^{x}}-1=0$，证明 $(0,0)$ 是 $f$ 的极小值点。

由极限 = 1，知 $f(0,0)=1$（否则分母→0 分式→∞）。重写为：

$f(x,y)-1 = 3x-y^2+e^{x}-1 + o(\rho) = 3x-y^2+x+\frac{x^2}{2}+o(\rho)$

对于充分小的 $(x,y)$，分析 $f(x,y)-f(0,0)$ 的符号 → $f(x,y)\ge f(0,0)$ → 极小值。

## §8.10.2 二元函数的最值

### 方法

$$
\boxed{\text{最值} = \max\!\big(\{\text{区域内驻点值}\} \cup \{\text{边界上最值}\}\big)}
$$

**特殊情况**：若由背景知最值在内部取得，且内部只有一个驻点，则该驻点就是最值点。

---

**例 3（应用）**：制作体积为 $2m^3$ 的有盖长方体水箱，用料最省时尺寸？

设长 $x$、宽 $y$，高 $=2/(xy)$。表面积：

$S = 2(xy + x\cdot\frac{2}{xy} + y\cdot\frac{2}{xy}) = 2(xy + \frac{2}{y} + \frac{2}{x})$

令 $\frac{\partial S}{\partial x} = 2(y-\frac{2}{x^2}) = 0$，$\frac{\partial S}{\partial y} = 2(x-\frac{2}{y^2}) = 0$

⇒ $x=\sqrt[3]{2},\; y=\sqrt[3]{2}$，高 $=\sqrt[3]{2}$

> 📌 唯一驻点 + 问题本身有最小值 → 这就是最优点。

## §8.10.3 条件极值 — 拉格朗日乘数法 ⭐

### Why 条件极值？

无条件：$z=x^2+y^2$ 的极值 → $(0,0)$

有条件：$z=x^2+y^2$ **且** $x+y=1$ 的极值 → 不同！

消元法（$y=1-x$ 代入）可以处理简单情况，但复杂约束无法消元 → **拉格朗日乘数法**。

---

### 情形 1：一个约束 + 二元

**问题**：求 $z=f(x,y)$ 在约束 $\varphi(x,y)=0$ 下的极值。

**步骤**：

1. 构造**拉格朗日函数**：
   $$
   \boxed{L(x,y,\lambda) = f(x,y) + \lambda\varphi(x,y)}
   $$

2. 令所有偏导为零：
   $$
   \begin{cases}
   L_x' = f_x' + \lambda\varphi_x' = 0 \\
   L_y' = f_y' + \lambda\varphi_y' = 0 \\
   L_\lambda' = \varphi(x,y) = 0
   \end{cases}
   $$

3. 解出所有 $(x,y,\lambda)$ → 可疑极值点。

4. 根据实际问题背景判断极值类型。

---

### 情形 2：一个约束 + 三元

问题：求 $f(x,y,z)$ 在 $\varphi(x,y,z)=0$ 下的极值。

$L(x,y,z,\lambda) = f(x,y,z) + \lambda\varphi(x,y,z)$

求解：
$$
\begin{cases}
L_x' = f_x' + \lambda\varphi_x' = 0 \\
L_y' = f_y' + \lambda\varphi_y' = 0 \\
L_z' = f_z' + \lambda\varphi_z' = 0 \\
L_\lambda' = \varphi = 0
\end{cases}
$$

---

### 情形 3：两个约束 + 三元

问题：$f(x,y,z)$ 在 $\varphi=0$ 且 $\psi=0$ 下的极值。

$L = f + \lambda\varphi + \mu\psi$，解五个方程即可。

---

### 经典应用例题

**例 4**：求曲面 $z=x^2+y^2$ 与平面 $x+y-2z=2$ 之间的最短距离。

等价于：求 $d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2 + (z_1-z_2)^2}$ 在约束下的最小值。

或转化为：求 $f = (x_1-x_2)^2+(y_1-y_2)^2+(z_1-z_2)^2$ 在曲面上取点 $(x_1,y_1,z_1)$ 和 $(x_2,y_2,z_2)$ 时……

更简单：求点 $(x,y,z)$ 到平面 $x+y-2z-2=0$ 的距离的极小值，其中 $(x,y,z)$ 在曲面 $z=x^2+y^2$ 上。

目标：$d = \frac{|x+y-2z-2|}{\sqrt{1^2+1^2+(-2)^2}} = \frac{|x+y-2z-2|}{\sqrt{6}}$（平面到点的距离公式）

求 $d^2$ 极值等价于求 $f = (x+y-2z-2)^2$ 在 $z=x^2+y^2$ 下的极值。使用拉格朗日乘数法解。（详见PPT）

---

**例 5**（习题）：求椭球面 $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ 在第一卦限内的切平面，使与三坐标面围成的四面体体积最小。

**思路**：切平面方程 → 截距 → 体积 $V=\frac{(a^2/x_0)(b^2/y_0)(c^2/z_0)}{6}$ → 约束 $\frac{x_0^2}{a^2}+\frac{y_0^2}{b^2}+\frac{z_0^2}{c^2}=1$ → 拉格朗日乘数法。

## 核心公式速查

| 概念 | 公式/方法 |
|------|------|
| 必要条件 | $\nabla f=0$（$f_x'=f_y'=0$） |
| $AC-B^2>0$ | 极值（$A<0$ 极大，$A>0$ 极小） |
| $AC-B^2<0$ | 非极值（鞍点） |
| $AC-B^2=0$ | 不能确定 |
| $z=xy$ (0,0) | $B^2-AC=1>0$，非极值 ✓ |
| 拉格朗日 | $L=f+\lambda\varphi$，解 $\nabla L=0$ |
| 多约束 | $L=f+\lambda\varphi+\mu\psi$ |
| 距离平方 | $d^2$ 代替 $d$ 简化计算 |
