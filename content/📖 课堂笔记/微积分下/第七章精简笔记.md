### 7.1.4 混合积（三重积）
**Why**：混合积把"面积"和"投影"组合——先叉积得面积向量，再点积投影到垂直方向——所以得到的是**体积**。
$$
\boxed{[\vec{a}\;\vec{b}\;\vec{c}] = (\vec{a} \times \vec{b}) \cdot \vec{c}}
$$
**几何意义**：以 $\vec{a},\vec{b},\vec{c}$ 为棱的**平行六面体体积**的绝对值。
> 四面体（tetrahedron）恰为平行六面体的 $\frac16$：
> $\boxed{V_{\text{四面体}} = \dfrac16\big|[\vec{a}\;\vec{b}\;\vec{c}]\big|}$
**性质**：
- 轮换不变：$[\vec{a}\;\vec{b}\;\vec{c}] = [\vec{b}\;\vec{c}\;\vec{a}] = [\vec{c}\;\vec{a}\;\vec{b}]$
　　> 例：无论哪两个先叉积再点积第三个，值都一样。
- 对调两向量变号：$[\vec{a}\;\vec{c}\;\vec{b}] = -[\vec{a}\;\vec{b}\;\vec{c}]$
> ⚠️ **最重要判定**：$\vec{a},\vec{b},\vec{c}$ **共面** $\iff [\vec{a}\;\vec{b}\;\vec{c}] = 0$（体积为 0）。

## §7.2 坐标系与向量的坐标
### 七类运算的坐标式
设 $\vec{a}=(a_1,a_2,a_3),\ \vec{b}=(b_1,b_2,b_3)$：
| 运算 | 坐标公式 | 直觉 |
|------|----------|------|
| 模 | $\|\vec{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2}$ | 勾股定理的三维推广 |
| 两点距离 | $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$ | 由模公式直接推 |
| 加法 | $\vec{a}+\vec{b} = (a_1+b_1,\; a_2+b_2,\; a_3+b_3)$ | 对应分量相加 |
| 数乘 | $\lambda\vec{a} = (\lambda a_1,\; \lambda a_2,\; \lambda a_3)$ | 每个分量乘 $\lambda$ |
| 点积 | $\vec{a}\cdot\vec{b} = a_1b_1 + a_2b_2 + a_3b_3$ | 对应分量相乘再求和 |
| 叉积 | $\vec{a}\times\vec{b} = \begin{vmatrix}\vec{i}&\vec{j}&\vec{k}\\a_1&a_2&a_3\\b_1&b_2&b_3\end{vmatrix}$ | 三阶行列式 |
| 混合积 | $[\vec{a}\;\vec{b}\;\vec{c}] = \begin{vmatrix}a_1&a_2&a_3\\b_1&b_2&b_3\\c_1&c_2&c_3\end{vmatrix}$ | 三阶行列式的值 |
### 方向角与方向余弦
向量 $\vec{a}$ 与三根坐标轴的夹角记作 $\alpha,\beta,\gamma$（范围 $[0,\pi]$）：
$$
\cos\alpha = \frac{a_1}{|\vec{a}|},\quad \cos\beta = \frac{a_2}{|\vec{a}|},\quad \cos\gamma = \frac{a_3}{|\vec{a}|}
$$
**核心恒等式**：$\boxed{\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1}$
> 🧠 **直觉验证**：单位向量的模 = 1，而它的三个分量恰好是 $\cos\alpha,\cos\beta,\cos\gamma$。所以勾股定理自然给出 $\cos^2\alpha + \cos^2\beta + \cos^2\gamma=1$。
**重要结论**：向量的**单位化 = 除模**，结果的分量就是方向余弦：
$$
\frac{\vec{a}}{|\vec{a}|} = (\cos\alpha,\;\cos\beta,\;\cos\gamma)
$$

## §7.3 平面与直线
> 学完本节你能：从点和法向量写平面；从点和方向写直线；求各种距离和交点；判断平行、垂直、共面。
> 🧠 **为什么要把几何对象写成方程？** 因为一旦写成 $F(x,y,z)=0$，你就可以用代数方法（解方程、联立、消元）回答几何问题——"两平面有交线吗？""直线穿过平面在哪里？"这比画图硬想可靠得多。
### 平面方程
| 形式 | 方程 | **何时用** |
|------|------|------------|
| 点法式 | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ | 🅰 已知**一点** + **法向量** |
| 一般式 | $Ax+By+Cz+D=0$ | 🅱 化简后的标准形式，$\vec{n}=(A,B,C)$ |
| 截距式 | $\dfrac{x}{a}+\dfrac{y}{b}+\dfrac{z}{c}=1$ | 🅲 已知三轴**截距** $a,b,c$ |
| 平面束 | $(\Pi_1) + \lambda(\Pi_2) = 0$ | 🅳 已知该平面过**两已知平面的交线** |
**一般式系数与位置速判**：
| 条件 | 含义 |
|------|------|
| $D=0$ | 平面过原点 |
| $A=0$ | 平面平行于 $x$ 轴 |
| $A=D=0$ | 平面**过** $x$ 轴 |
| $A=B=0$ | 平面平行于 $xOy$ 面（即水平面 $z=\text{const}$） |
### 直线方程
| 形式 | 方程 | **何时用** |
|------|------|------------|
| 点向式 | $\dfrac{x-x_0}{m}=\dfrac{y-y_0}{n}=\dfrac{z-z_0}{p}$ | 🅰 已知**一点** + **方向向量** $(m,n,p)$ |
| 参数式 | $\begin{cases}x=x_0+mt\\y=y_0+nt\\z=z_0+pt\end{cases}$ | 🅱 适合代入运算（求交点） |
| 两点式 | $\dfrac{x-x_1}{x_2-x_1}=\dfrac{y-y_1}{y_2-y_1}=\dfrac{z-z_1}{z_2-z_1}$ | 🅲 已知**两点** |
| 交面式 | $\begin{cases}A_1x+B_1y+C_1z+D_1=0\\A_2x+B_2y+C_2z+D_2=0\end{cases}$ | 🅳 直线作为**两平面交线** |
> ⚠️ 点向式中分母为 0 **不表示无意义**。例：$\dfrac{x-1}{0}=\dfrac{y}{1}=\dfrac{z}{2}$ 表示 $x \equiv 1$（恒定），$y$ 和 $z$ 随参数变化。
### 位置关系速查
| 关系 | 条件 | 直觉 |
|------|------|------|
| 两平面 $\parallel$ | $\dfrac{A_1}{A_2}=\dfrac{B_1}{B_2}=\dfrac{C_1}{C_2}\neq\dfrac{D_1}{D_2}$ | 法向量同方向，但不重合 |
| 两平面 $\perp$ | $A_1A_2+B_1B_2+C_1C_2=0$ | 法向量点积 = 0 |
| 两直线 $\parallel$ | $\vec{s}_1\times\vec{s}_2=\vec{0}$ | 方向向量平行 |
| 两直线 $\perp$ | $\vec{s}_1\cdot\vec{s}_2=0$ | 方向向量垂直 |
| 直线 $\parallel$ 平面 | $\vec{s}\cdot\vec{n}=0$ 且点不在面上 | 方向垂直于法向量 |
| 直线 $\perp$ 平面 | $\vec{s}\parallel\vec{n}$（分量成比例） | 方向沿法向量 |
| 共面 / 异面 | $[\vec{s}_1\;\vec{s}_2\;\overrightarrow{M_1M_2}]=0$ ⇔ 共面 | 混合积 = 0 则三向量共面 |
### 距离公式
| 求什么距离 | 公式 |
|------------|------|
| 点到平面 | $d = \dfrac{\|Ax_0+By_0+Cz_0+D\|}{\sqrt{A^2+B^2+C^2}}$ |
| 平行平面间 | $d = \dfrac{\|D_1-D_2\|}{\sqrt{A^2+B^2+C^2}}$（前提：法向量系数成比例） |
| 点到直线 | $d = \dfrac{\|\overrightarrow{M_0P} \times \vec{s}\|}{\|\vec{s}\|}$ |
| 异面直线 | $d = \dfrac{\big\|[\vec{s}_1\;\vec{s}_2\;\overrightarrow{M_1M_2}]\big\|}{\|\vec{s}_1 \times \vec{s}_2\|}$ |
> 🧠 **点到直线距离公式怎么记？** 分子是 $M_0P$ 和方向的叉积模（= 平行四边形面积），分母是方向的模（= 底边长），面积÷底 = 高 = 距离。
### 夹角公式
| 求什么夹角 | 公式 |
|------------|------|
| 两平面之间 | $\cos\theta = \dfrac{\|\vec{n}_1\cdot\vec{n}_2\|}{\|\vec{n}_1\|\|\vec{n}_2\|}$ |
| 两直线之间 | $\cos\theta = \dfrac{\|\vec{s}_1\cdot\vec{s}_2\|}{\|\vec{s}_1\|\|\vec{s}_2\|}$ |
| 直线与平面 | $\sin\varphi = \dfrac{\|\vec{s}\cdot\vec{n}\|}{\|\vec{s}\|\|\vec{n}\|}$ |
> ⚠️ 线面夹角用 **$\sin$**，不是 $\cos$！因为直线方向和法向量垂直时直线才在面内（夹角 0），此时 $\sin 0 = |\vec{s}\cdot\vec{n}|/(|\vec{s}||\vec{n}|)$。记忆诀窍：法向量和方向越"接近平行" → 直线越"接近垂直"平面 → 角越大。

## §7.4 曲面与曲线
> 学完本节你能：从母线曲线写旋转曲面方程；判断柱面和锥面；从交面式消元求投影。
> 🧠 **空间想象**：曲面是二维的面在三维空间里的形状。你想像一个橡皮膜绷在骨架上——旋转曲面是把一条线绕着轴转一圈扫出来的面（像陶轮上的泥巴）。
### 旋转曲面 ⭐
$yOz$ 面上曲线 $F(y,z)=0$ 绕 $z$ 轴旋转，得到：
$$
\boxed{F(\pm\sqrt{x^2+y^2},\; z) = 0}
$$
> 📌 **口诀**：绕哪根轴，**那个轴的坐标不变**，另一个坐标换为 $\pm\sqrt{\text{其余两坐标平方和}}$。
>
> 为什么是 $\pm\sqrt{}$？因为旋转时上半平面和下半平面的点都扫到了——需要 ± 覆盖。
| 旋转曲面 | 方程 | 空间想象 |
|----------|------|----------|
| 圆锥面 | $z^2 = k^2(x^2+y^2)$ | 冰淇淋筒，尖嘴朝原点 |
| 旋转抛物面 | $z = a(x^2+y^2)$ | 卫星天线锅，开口向上 |
| 旋转椭球面 | $\dfrac{x^2+y^2}{a^2}+\dfrac{z^2}{c^2}=1$ | 被压扁的篮球（橄榄球形） |
### 柱面
**判定口诀**：方程中**缺少哪个变量**，母线就平行于哪根轴。
> 🧠 **空间想象**：$F(x,y)=0$ 在平面里是一条曲线（比如圆）。把所有平行于 $z$ 轴的直线穿过这条曲线，就形成一根"管子"——这就是柱面。
> ⚠️ **顶级易错**：**$x^2+y^2=R^2$ 在空间是圆柱面，不是圆！** 圆在平面上且 $z=0$ 固定；圆柱面延伸到所有 $z$。
常见柱面：$x^2+y^2=R^2$（圆柱面）、$y=x^2$（抛物柱面，像一堵抛物线形状的墙竖直延伸）。
### 锥面
**判定方法**：方程满足 $F(tx,ty,tz)=t^nF(x,y,z)$（齐次方程）⇔ 以原点为顶点的**锥面**。
> 🧠 直观验证：$x^2+y^2=z^2$，把 $(x,y,z)$ 都放大 $t$ 倍：$(tx)^2+(ty)^2=(tz)^2$ → 等式两边都多出 $t^2$，但不改变等式成立性——说明所有从原点射出的射线都在曲面上，这正是锥的特征。
### 曲线方程
- **交面式**（最常见）：$\begin{cases}F(x,y,z)=0\\G(x,y,z)=0\end{cases}$ — 两曲面交线
- **参数式**：$\begin{cases}x=x(t)\\y=y(t)\\z=z(t)\end{cases}$ — 如圆柱螺旋线 $\begin{cases}x=a\cos t\\y=a\sin t\\z=bt\end{cases}$
### 投影曲线 ⭐
从一个变量消去 = 把空间曲线"按扁"到坐标面上。
| 投影到 | 操作 | 结果 |
|:---:|------|------|
| $xOy$ | **消 $z$** | $\begin{cases}H(x,y)=0\\z=0\end{cases}$ |
| $zOx$ | **消 $y$** | $\begin{cases}R(x,z)=0\\y=0\end{cases}$ |
| $yOz$ | **消 $x$** | $\begin{cases}S(y,z)=0\\x=0\end{cases}$ |
> 🧠 消 $z$ 的几何意义：把 $z$ 去掉相当于做一个"太阳在头顶"的投影——只有影子（柱面）留在地面（$xOy$ 面）。

## §7.5 二次曲面的标准型
> 学完本节你能：从方程一眼认出椭球面/单叶双曲面/双叶双曲面/椭圆锥面/椭圆抛物面/双曲抛物面；用截痕法解释曲面形状。
**研究方法**：
- **截痕法**：用平面 $z=t$（或 $x=t,\ y=t$）去"切"曲面，观察截面形状随高度的变化——就像看 CT 扫描图
- **伸缩法**：从熟悉的旋转曲面（如圆锥、旋转椭球）沿某坐标轴方向压缩或拉伸
### 六种标准二次曲面
| # | 名称 | 标准方程 | 空间想象 | 识别特征 |
|:--:|------|----------|----------|----------|
| 1 | **椭球面** | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ | 压扁的篮球 / 橄榄球 | 三项全正 + |
| 2 | **单叶双曲面** | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ | 沙漏 / 冷却塔形状，$z=0$ 处最细 | 两正一负 |
| 3 | **双叶双曲面** | $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ | 两顶对扣的碗，间隔一段距离 | 一正两负 |
| 4 | **椭圆锥面** | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=z^2$ | 两个冰淇淋筒尖对尖 | 齐次（= $z^2$） |
| 5 | **椭圆抛物面** | $z=\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}$ | 汤勺 / 卫星锅，开口向上 | $z$ 一次，同号 |
| 6 | **双曲抛物面** | $z=\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}$ | 马鞍：沿 $x$ 向上弯，沿 $y$ 向下弯 | $z$ 一次，异号 |
> 📌 **记忆口诀**：全正椭球、一负单叶、两负双叶、齐次为锥、$z$ 一次抛物面（同号椭圆、异号马鞍）。

# 第三部分：🧪 自测题
## A 组：基础判断题（每题 1 分钟）
**A1.** 零向量的方向是任意的。
**A2.** $\vec{a}\times\vec{b}=\vec{0}$ 是 $\vec{a}\parallel\vec{b}$ 的充要条件。
**A3.** $(\vec{a}\times\vec{b})\cdot\vec{c} = \vec{a}\cdot(\vec{b}\times\vec{c})$。
**A4.** 若 $\vec{a}\cdot\vec{b}=\vec{a}\cdot\vec{c}$ 且 $\vec{a}\neq\vec{0}$，则 $\vec{b}=\vec{c}$。
**A5.** 空间中 $x^2+y^2=4$ 表示半径为 2 的圆。
