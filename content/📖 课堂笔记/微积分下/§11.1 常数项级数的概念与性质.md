# §11.1 常数项级数的概念与性质

## 基本定义

**芝诺悖论**（引子）：一个人从 0 走到 1。先走一半（$\frac{1}{2}$），再走剩下的一半（$\frac{1}{4}$），再剩下的一半（$\frac{1}{8}$）……每步走 $\frac{1}{2^n}$。

前 $n$ 步共走了多少？求部分和：

$$S_n = \frac{1}{2} + \frac{1}{4} + \cdots + \frac{1}{2^n} \xlongequal{\text{等比求和}} \frac{\frac{1}{2}(1-\frac{1}{2^n})}{1-\frac{1}{2}} = 1 - \frac{1}{2^n}$$

当 $n\to\infty$，$S_n \to 1$。这就是"无穷多项相加等于有限数"——**不是真的加无穷次，而是前 $n$ 项和的极限。**

这就是级数的核心定义 ⬇

**常数项级数**：$\displaystyle \sum_{n=1}^{\infty} u_n = u_1 + u_2 + \cdots + u_n + \cdots$

**部分和**：$S_n = \sum_{k=1}^n u_k$。级数的**和** $= \lim S_n$。

| 概念 | 定义 |
|:--|:--|
| **收敛** | $\lim S_n = S$（有限数），$S$ 为和 |
| **发散** | $\{S_n\}$ 无有限极限 |
| **余项** | $r_n = S - S_n = \sum_{k=n+1}^\infty u_k$ |

> 🎯 **级数问题 = 部分和数列极限问题。** 比如数列 $a_n = \frac{n}{n+1}$，构造级数：首项 $a_1=\frac{1}{2}$，$n\ge 2$ 时 $u_n = a_n-a_{n-1} = \frac{1}{n(n+1)}$，则 $\sum u_n$ 的部分和正好 $=a_n$。级数和数列本质上是一个东西的两种写法。

## 两个必须熟记的级数

| 级数 | 条件 | 结论 | 和 |
|------|:--|:--|:--|
| **等比级数** $\sum_{n=0}^\infty aq^n$ | $\|q\|<1$ | ✅ 收敛 | $\frac{a}{1-q}$ |
| | $\|q\|\ge 1$ | ❌ 发散 | — |
| **调和级数** $\sum_{n=1}^\infty \frac{1}{n}$ | — | ❌ **发散** | — |

> ⚠️ 调和级数：**通项→0但级数发散**——"收敛的必要条件是通项→0"的最重要反例。

## 拆项相消法（定义法核心技巧）

**裂项**让中间项正负相消，部分和只剩首尾：

- $\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$ → $S_n = 1 - \frac{1}{n+1} \to 1$
- **练一练**：$\frac{1}{n(n+2)} = \frac{1}{2}\left(\frac{1}{n} - \frac{1}{n+2}\right)$ → $S_n = \frac{1}{2}(1+\frac{1}{2} - \frac{1}{n+1} - \frac{1}{n+2}) \to \frac{3}{4}$

## 四条基本性质

| 性质 | 内容 |
|:--|:--|
| **线性** | 收敛+收敛=收敛；收敛+发散=**发散**；发散+发散=不一定 |
| **有限项** | 去掉/增加/改变有限项不改变敛散性（和可能变） |
| **加括号** | 收敛级数加括号仍收敛；括号收敛≠原级数收敛（正项级数例外） |
| **必要条件★** | $\sum u_n$ 收敛 ⇒ $\lim u_n = 0$。**逆否**：$\lim u_n \neq 0$ ⇒ 发散！ |

## 手把手例题

> **例**：求 $\displaystyle \sum_{n=1}^{\infty} \frac{2^n+(-1)^n}{8^n}$ 的和。

| 步骤 | 操作 |
|:--|:--|
| ①拆 | $= \sum(1/4)^n + \sum(-1/8)^n$（两个等比级数） |
| ②判 | $q_1=\frac{1}{4}<1$, $q_2=|-\frac{1}{8}|<1$ → 均收敛 |
| ③和 | $= \frac{1/4}{1-1/4} + \frac{-1/8}{1-(-1/8)} = \frac{1}{3} - \frac{1}{9} = \frac{2}{9}$ |

> ✅ **本节检查**：读完后你应该能——
> - [ ] 定义级数收敛（部分和数列有有限极限）
> - [ ] 判断等比级数敛散并求和
> - [ ] 用必要条件（$\lim u_n \neq 0 \Rightarrow$ 发散）快速排除
> - [ ] 用拆项相消法求至少一种级数的精确和
> - [ ] 解释为什么调和级数发散但通项→0

### B组 — 计算题

<div class="quiz-container">
<div class="quiz-question">B1 判断 $\sum_{n=1}^{\infty} \frac{1}{2^n}$ 的敛散性，若收敛求其和。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**解：** 等比级数（几何级数），公比 $q = \frac{1}{2}$。
$\because |q| = \frac{1}{2} < 1$，$\therefore$ 级数收敛。

首项 $a = \frac{1}{2}$，和 $S = \frac{a}{1-q} = \frac{1/2}{1-1/2} = 1$。

**答：** 收敛，和为 $1$。

</div>
</details>

</div>

<div class="quiz-container">
<div class="quiz-question">B2 判断 $\sum_{n=1}^{\infty} \frac{n}{n+1}$ 的敛散性。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**解：** 通项 $u_n = \frac{n}{n+1}$，
$\displaystyle\lim_{n\to\infty} u_n = \lim_{n\to\infty} \frac{n}{n+1} = 1 \neq 0$。

由级数收敛的**必要条件**（通项不趋于零），级数一定发散。

**答：** 发散。

</div>
</details>

<div class="quiz-container">
<div class="quiz-question">B3 判断 $\sum_{n=1}^{\infty} \frac{(-1)^n}{3^n}$ 的敛散性，若收敛求其和。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**解：** 等比级数，公比 $q = -\frac{1}{3}$。
$\because |q| = \frac{1}{3} < 1$，$\therefore$ 级数收敛。

首项 $a = u_1 = -\frac{1}{3}$，
$S = \frac{a}{1-q} = \frac{-1/3}{1-(-1/3)} = -\frac{1}{4}$。

**答：** 收敛，和为 $-\frac{1}{4}$。

<div class="quiz-container">
<div class="quiz-question">B4 用拆项法求 $\sum_{n=1}^{\infty} \frac{1}{(2n-1)(2n+1)}$ 的和。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**解：** 拆项：$\frac{1}{(2n-1)(2n+1)} = \frac{1}{2}\left(\frac{1}{2n-1} - \frac{1}{2n+1}\right)$。

部分和：
$\begin{aligned} S_n &= \sum_{k=1}^{n} \frac{1}{(2k-1)(2k+1)} \\ &= \frac{1}{2}\left[\left(1-\frac{1}{3}\right) + \left(\frac{1}{3}-\frac{1}{5}\right) + \cdots + \left(\frac{1}{2n-1}-\frac{1}{2n+1}\right)\right] \\ &= \frac{1}{2}\left(1 - \frac{1}{2n+1}\right) \end{aligned}$

$\therefore S = \lim_{n\to\infty} S_n = \frac{1}{2}$，级数收敛。

**答：** 收敛，和为 $\frac{1}{2}$。

</div>
</details>

<div class="quiz-container">
<div class="quiz-question">B7 求 $\sum_{n=0}^{\infty} \frac{2^n + 3^n}{6^n}$ 的和。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**答：** 收敛，和为 $\frac{7}{2}$。

### C组 — 综合题

<div class="quiz-container">
<div class="quiz-question">C1 ⭐ 用定义证明 $\sum_{n=1}^{\infty} \frac{1}{\sqrt{n}}$ 发散。（提示：部分和下界估计）</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**证：** 部分和 $S_n = \sum_{k=1}^{n} \frac{1}{\sqrt{k}}$。

下界估计：$\frac{1}{\sqrt{k}} \ge \frac{1}{\sqrt{n}}$（$k \le n$），
$\therefore S_n \ge n \cdot \frac{1}{\sqrt{n}} = \sqrt{n} \to \infty$，级数发散。$\square$

</div>
</details>

<div class="quiz-container">
<div class="quiz-question">C2 ⭐⭐ 讨论 $\sum_{n=1}^{\infty} \frac{1}{n(n+1)(n+2)}$ 的敛散性并求和。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**解：** 拆项：$\frac{1}{n(n+1)(n+2)} = \frac{1}{2}\left[\frac{1}{n(n+1)} - \frac{1}{(n+1)(n+2)}\right]$。

部分和：
$S_n = \frac{1}{2}\Bigg[\Big(\frac{1}{1\cdot2} - \frac{1}{2\cdot3}\Big) + \Big(\frac{1}{2\cdot3} - \frac{1}{3\cdot4}\Big) + \cdots + \Big(\frac{1}{n(n+1)} - \frac{1}{(n+1)(n+2)}\Big)\Bigg]$

$= \frac{1}{2}\left[\frac{1}{2} - \frac{1}{(n+1)(n+2)}\right] \to \frac{1}{2} \cdot \frac{1}{2} = \frac{1}{4}$。

**答：** 收敛，和为 $\frac{1}{4}$。

</div>
</details>

<div class="quiz-question">C3 ⭐⭐ 已知 $\sum u_n$ 收敛，问 $\sum u_n^2$ 是否一定收敛？给出理由或反例。</div>
<details class="quiz-check">
<summary>查看答案</summary>
<div class="quiz-answer">

**解：** 不一定收敛。反例：

取 $u_n = \frac{(-1)^n}{\sqrt{n}}$，则 $\sum u_n$ 由莱布尼茨判别法收敛。

但 $u_n^2 = \frac{1}{n}$，$\sum \frac{1}{n}$（调和级数）**发散**。

$\therefore$ $\sum u_n$ 收敛 $\nRightarrow$ $\sum u_n^2$ 收敛。
