# 第一部分：知识整合

## §7.1 向量及其运算

### 7.1.1 向量概念与线性运算

**向量** = 大小 + 方向。$|\vec{a}|$ 为模。模为 1 → 单位向量；模为 0 → 零向量 $\vec{0}$（方向任意）。

**加减法**：三角形法则 / 平行四边形法则。$\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$。

**数乘**：$\lambda\vec{a}$ 与 $\vec{a}$ 平行，$|\lambda\vec{a}| = |\lambda||\vec{a}|$。$\lambda>0$ 同向、$\lambda<0$ 反向。

> **定理 1**：$\vec{a} \parallel \vec{b} \iff \exists!\,\lambda: \vec{b} = \lambda\vec{a}$（$\vec{a} \neq \vec{0}$）
> **定理 2**：$\vec{a},\vec{b},\vec{c}$ 共面 $\iff \exists\lambda,\mu: \vec{c} = \lambda\vec{a} + \mu\vec{b}$（$\vec{a} \nparallel \vec{b}$）
> **推论**：任意 $\vec{r}$ 可由三不共面向量唯一线性表出：$\vec{r} = x\vec{a} + y\vec{b} + z\vec{c}$

### 7.1.2 数量积（点积）

$$
\boxed{\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta}
$$

**几何意义**：$= |\vec{a}| \cdot \text{Prj}_{\vec{a}}\vec{b}$（模 × 投影）。

**性质**：交换律、分配律、数乘结合律均成立。

> **重要判定**：$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0$。

### 7.1.3 向量积（叉积）

$$
\boxed{\vec{a} \times \vec{b} = |\vec{a}||\vec{b}|\sin\theta \cdot \vec{n}^\circ}
$$

$\vec{n}^\circ$ 方向由**右手法则**确定。

**几何意义**：$|\vec{a} \times \vec{b}| = \vec{a},\vec{b}$ 为邻边的平行四边形面积。

$S_{\triangle ABC} = \frac12|\overrightarrow{AB} \times \overrightarrow{AC}|$。

**性质**：反交换律 $(\vec{a}\times\vec{b} = -\vec{b}\times\vec{a})$；分配律。

> **重要判定**：$\vec{a} \parallel \vec{b} \iff \vec{a} \times \vec{b} = \vec{0}$。

### 7.1.4 混合积

$$
\boxed{[\vec{a}\;\vec{b}\;\vec{c}] = (\vec{a} \times \vec{b}) \cdot \vec{c}}
$$

**几何意义**：以 $\vec{a},\vec{b},\vec{c}$ 为棱的平行六面体体积的绝对值。

$V_{\text{tetra}} = \frac16\big|[\vec{a}\;\vec{b}\;\vec{c}]\big|$。

**性质**：轮换不变、两向量对调变号。

> **重要判定**：$\vec{a},\vec{b},\vec{c}$ 共面 $\iff [\vec{a}\;\vec{b}\;\vec{c}] = 0$。

## §7.2 坐标系与向量的坐标

### 空间直角系

三根互相垂直的坐标轴（右手系）→ $xOy, yOz, zOx$ 三个坐标面 → **八个卦限**。

点的向径：$\overrightarrow{OM} = x\vec{i} + y\vec{j} + z\vec{k}$。

### 七类运算坐标式（$\vec{a}=(a_1,a_2,a_3),\ \vec{b}=(b_1,b_2,b_3)$）

| 运算 | 坐标公式 |
|------|----------|
| 模 | $\|\vec{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2}$ |
| 两点距离 | $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$ |
| 加法 | $\vec{a}+\vec{b} = (a_1+b_1, a_2+b_2, a_3+b_3)$ |
| 数乘 | $\lambda\vec{a} = (\lambda a_1, \lambda a_2, \lambda a_3)$ |
| 点积 | $\vec{a}\cdot\vec{b} = a_1b_1 + a_2b_2 + a_3b_3$ |
| 叉积 | $\vec{a}\times\vec{b} = \begin{vmatrix}\vec{i}&\vec{j}&\vec{k}\\a_1&a_2&a_3\\b_1&b_2&b_3\end{vmatrix}$ |
| 混合积 | $[\vec{a}\;\vec{b}\;\vec{c}] = \begin{vmatrix}a_1&a_2&a_3\\b_1&b_2&b_3\\c_1&c_2&c_3\end{vmatrix}$ |

**平行条件**：$\dfrac{a_1}{b_1} = \dfrac{a_2}{b_2} = \dfrac{a_3}{b_3}$（分母为 0 时分子也须为 0）。

### 方向角与方向余弦

设 $\vec{a}$ 与坐标轴夹角为 $\alpha,\beta,\gamma$（$0 \leq \alpha,\beta,\gamma \leq \pi$）：

$$
\cos\alpha = \frac{a_1}{|\vec{a}|},\quad \cos\beta = \frac{a_2}{|\vec{a}|},\quad \cos\gamma = \frac{a_3}{|\vec{a}|}
$$

**关键恒等式**：$\boxed{\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1}$

**重要结论**：单位向量 $= (\cos\alpha,\cos\beta,\cos\gamma)$。

## §7.3 平面与直线

### 平面方程

| 形式 | 方程 | 条件 |
|------|------|------|
| 点法式 | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ | 定点 + 法向量 |
| 一般式 | $Ax+By+Cz+D=0$ | 法向量 $\vec{n}=(A,B,C)$ |
| 截距式 | $\frac{x}{a}+\frac{y}{b}+\frac{z}{c}=1$ | $a,b,c$ 为截距 |
| 平面束 | $(\Pi_1) + \lambda(\Pi_2) = 0$ | 过两平面交线 |

**一般式系数与位置**：$D=0$ 过原点；$A=0$ 平行于 $x$ 轴；$A=D=0$ 过 $x$ 轴；$A=B=0$ 平行于 $xOy$ 面。

### 直线方程

| 形式 | 方程 |
|------|------|
| 点向式 | $\dfrac{x-x_0}{m}=\dfrac{y-y_0}{n}=\dfrac{z-z_0}{p}$ |
| 参数式 | $\begin{cases}x=x_0+mt\\y=y_0+nt\\z=z_0+pt\end{cases}$ |
| 两点式 | $\dfrac{x-x_1}{x_2-x_1}=\dfrac{y-y_1}{y_2-y_1}=\dfrac{z-z_1}{z_2-z_1}$ |
| 交面式 | $\begin{cases}A_1x+B_1y+C_1z+D_1=0\\A_2x+B_2y+C_2z+D_2=0\end{cases}$ |

### 位置关系速查

| 关系 | 条件 |
|------|------|
| 两平面 $\parallel$ | $\dfrac{A_1}{A_2}=\dfrac{B_1}{B_2}=\dfrac{C_1}{C_2}\neq\dfrac{D_1}{D_2}$ |
| 两平面 $\perp$ | $A_1A_2+B_1B_2+C_1C_2=0$ |
| 两直线 $\parallel$ | $\vec{s}_1\times\vec{s}_2=\vec{0}$ |
| 两直线 $\perp$ | $\vec{s}_1\cdot\vec{s}_2=0$ |
| 直线 $\parallel$ 平面 | $\vec{s}\cdot\vec{n}=0$ 且点不在面上 |
| 直线 $\perp$ 平面 | $\vec{s}\parallel\vec{n}$（分量成比例） |
| 共面/异面 | $[\vec{s}_1\;\vec{s}_2\;\overrightarrow{M_1M_2}] = 0$ ⇔ 共面 |

### 三大距离公式

| 距离 | 公式 |
|------|------|
| 点到平面 | $d = \dfrac{\|Ax_0+By_0+Cz_0+D\|}{\sqrt{A^2+B^2+C^2}}$ |
| 平行平面间 | $d = \dfrac{\|D_1-D_2\|}{\sqrt{A^2+B^2+C^2}}$ |
| 点到直线 | $d = \dfrac{\|\overrightarrow{M_0P} \times \vec{s}\|}{\|\vec{s}\|}$ |
| 异面直线 | $d = \dfrac{\big\|[\vec{s}_1\;\vec{s}_2\;\overrightarrow{M_1M_2}]\big\|}{\|\vec{s}_1 \times \vec{s}_2\|}$ |

### 三种夹角

| 夹角 | 公式 |
|------|------|
| 两平面 | $\cos\theta = \dfrac{\|\vec{n}_1\cdot\vec{n}_2\|}{\|\vec{n}_1\|\|\vec{n}_2\|}$ |
| 两直线 | $\cos\theta = \dfrac{\|\vec{s}_1\cdot\vec{s}_2\|}{\|\vec{s}_1\|\|\vec{s}_2\|}$ |
| 线面 | $\sin\varphi = \dfrac{\|\vec{s}\cdot\vec{n}\|}{\|\vec{s}\|\|\vec{n}\|}$ |

## §7.4 曲面与曲线

### 旋转曲面 ⭐

$yOz$ 面曲线 $F(y,z)=0$ 绕 $z$ 轴旋转：

$$
\boxed{F(\pm\sqrt{x^2+y^2},\; z) = 0}
$$

> **口诀**：绕哪根轴，哪个坐标不变；另一坐标换为 $\pm\sqrt{\text{其余两坐标平方和}}$。

| 旋转曲面 | 方程 |
|----------|------|
| 圆锥面 | $z^2 = k^2(x^2+y^2)$ |
| 旋转抛物面 | $z = a(x^2+y^2)$ |
| 旋转椭球面 | $\frac{x^2+y^2}{a^2}+\frac{z^2}{c^2}=1$ |

### 柱面

**口诀**：方程中缺少哪个变量，母线就平行于哪根轴。

$F(x,y)=0$（缺 $z$）→ 母线 $\parallel z$ 轴。$x^2+y^2=R^2$ 是圆柱面，$y=x^2$ 是抛物柱面。

### 锥面

**齐次方程** $F(tx,ty,tz)=t^nF(x,y,z)$ ⇔ 以原点为顶点的锥面。

例如 $x^2+y^2=z^2$。

### 曲线方程

- **交面式**：$\begin{cases}F(x,y,z)=0\\G(x,y,z)=0\end{cases}$
- **参数式**：$\begin{cases}x=x(t)\\y=y(t)\\z=z(t)\end{cases}$（螺旋线等运动轨道）

### 投影曲线 ⭐

| 投影面 | 操作 | 结果 |
|:---:|------|------|
| $xOy$ | 消 $z$ | $\begin{cases}H(x,y)=0\\z=0\end{cases}$ |
| $zOx$ | 消 $y$ | $\begin{cases}R(x,z)=0\\y=0\end{cases}$ |
| $yOz$ | 消 $x$ | $\begin{cases}S(y,z)=0\\x=0\end{cases}$ |

## §7.5 二次曲面的标准型

**两种研究方法**：截痕法（平面截曲面看截痕变化）、伸缩法（从旋转曲面向坐标轴方向伸缩）。

### 六种标准二次曲面

| # | 名称 | 标准方程 | 特征 |
|:--:|------|----------|------|
| 1 | 椭球面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ | 全正，闭曲面 |
| 2 | 单叶双曲面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ | 一负，连通 |
| 3 | 双叶双曲面 | $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ | 两负，两片 |
| 4 | 椭圆锥面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=z^2$ | 齐次，截面∝｜z｜ |
| 5 | 椭圆抛物面 | $z=\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}$ | $z$一次，开口上 |
| 6 | 双曲抛物面 | $z=\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}$ | 马鞍，$z=0$两直线 |

> **口诀**：全正椭球、一负单叶、两负双叶、齐次为锥、$z$ 一次抛物面。

## A 组：基础判断题（每题 1 分钟）

**A1.** 零向量的方向是任意的。

**A2.** $\vec{a}\times\vec{b}=\vec{0}$ 是 $\vec{a}\parallel\vec{b}$ 的充要条件。

**A3.** $(\vec{a}\times\vec{b})\cdot\vec{c} = \vec{a}\cdot(\vec{b}\times\vec{c})$。

**A4.** 若 $\vec{a}\cdot\vec{b}=\vec{a}\cdot\vec{c}$ 且 $\vec{a}\neq\vec{0}$，则 $\vec{b}=\vec{c}$。

**A5.** 空间中 $x^2+y^2=4$ 表示半径为 2 的圆。

**A6.** $z=xy$ 表示马鞍面。

**A7.** 方程缺 $z$ 的曲面是母线平行于 $z$ 轴的柱面。

**A8.** $\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1$ 始终成立。
