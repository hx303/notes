# Sec.10.6 高斯公式

> **又名**：Gauss 定理、散度定理（Divergence Theorem）。是 **Green 公式**从二维到三维的推广。把**第二类闭曲面积分**化为**三重积分**。



## 🏔️ 直觉地图

| 维度 | Green (Sec.9.3) | Gauss (Sec.10.6) |
|:--|:--|:--|
| 区域 | 平面闭区域 $D$ | 空间闭区域 $\Omega$ |
| 边界 | 闭曲线 $L$（正向） | 闭曲面 $\Sigma$（外侧） |
| 积分转化 | $\oint_L$ → $\iint_D$ | $\oiint_\Sigma$ → $\iiint_\Omega$ |
| 核心量 | $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$ | $\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}$ |

**为什么学这一章？** Sec.10.5 中球面外侧算得那么辛苦（分上下半球、分别定号），有了 Gauss 公式——**直接化为三重积分，秒杀**。



## 一、Gauss 定理

### 1.1 定理陈述

设空间闭区域 $\Omega$ 由分片光滑的闭曲面 $\Sigma$ 围成，函数 $P, Q, R$ 在 $\Omega$ 上有一阶连续偏导数。**$\Sigma$ 取外侧**，则：

$$\boxed{\oiint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iiint_\Omega \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right) dxdydz}$$

> 🎯 **一句口诀**：闭曲面外侧第二类 → 散度三重积分

### 1.2 内侧怎么办？

$$\oiint_{\Sigma_{\text{内侧}}} = -\iiint_\Omega \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right) dxdydz$$

> 和 Green 公式中反向曲线取负完全一致。

### 1.3 分量形式

$$\oiint_\Sigma P\,dydz = \iiint_\Omega \frac{\partial P}{\partial x}\,dxdydz$$

$$\oiint_\Sigma Q\,dzdx = \iiint_\Omega \frac{\partial Q}{\partial y}\,dxdydz$$

$$\oiint_\Sigma R\,dxdy = \iiint_\Omega \frac{\partial R}{\partial z}\,dxdydz$$



## 二、使用 Gauss 公式的关键技巧

### 2.1 曲面不闭合？→ 补面

这是 Gauss 公式最核心的应用技巧：

$$\oiint_{\Sigma + \Sigma_1} = \iiint_\Omega \quad\implies\quad \iint_\Sigma = \iiint_\Omega - \iint_{\Sigma_1}$$

| 步骤 | 操作 |
|:--|:--|
| ① | 补一个辅助曲面 $\Sigma_1$，使 $\Sigma + \Sigma_1$ 构成**闭曲面** |
| ② | 定好 $\Sigma_1$ 的侧（使闭曲面取**外侧/内侧**） |
| ③ | 用 Gauss 公式算闭曲面上的积分 |
| ④ | 减去辅助面上的积分（辅助面通常是平面，直接算很简单） |

> ⚠️ **辅助面的侧要一致**：$\Sigma$ 是上侧 → 补底面 $\Sigma_1$ 应取下侧，使总体构成"外侧"。

### 2.2 有奇点？→ 挖洞（积分曲面特殊化）

和 Green 公式中挖去奇点完全一样。若 $P, Q, R$ 在 $\Omega$ 内部某点不可偏导，则：

- 以奇点为中心作小球面 $\Sigma_\varepsilon$
- $\oiint_{\Sigma_{\text{外}}} = \oiint_{\Sigma_{\text{内小曲面}}}$（当散度为零时）
- 将积分曲面"特殊化"为小球面，用两类积分转化法计算

> 这对应 PPT 注3："函数在 Ω 内有奇点，处理方程与格林公式一样——积分曲面特殊化"

### 2.3 被积函数不可偏导？→ 放弃 Gauss

若曲面方程是 $z=z(x,y)$ 但被积函数没有偏导数 → 只能用**合一投影法**，不能套 Gauss。



## 三、典型例题

### 例1（引例）：非闭曲面 → 补面

> $I = \iint_\Sigma (x^3z + x)\,dydz + yz\,dzdx - x^2z\,dxdy$，$\Sigma: z=2-x^2-y^2,\; 1\leq z\leq 2$ 取上侧。

**分析**：$\Sigma$ 是开口向下的抛物面（碗状），不闭合。

**解法**：补底面 $\Sigma_1: z=1, x^2+y^2 \leq 1$，取下侧。记 $\Sigma+\Sigma_1$ 围成区域 $\Omega$。

\$\$
\begin{aligned}
P = x^3z+x,\quad Q = yz,\quad R = -x^2z
\end{aligned}$$

$$\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} = (3x^2z+1) + z + (-x^2) = 3x^2z + z + 1 - x^2$$

由 Gauss 公式（闭曲面外侧）：

$$\oiint_{\Sigma+\Sigma_1} = \iiint_\Omega (3x^2z + z + 1 - x^2)\,dxdydz$$

然后减去 $\Sigma_1$ 上的积分（$\Sigma_1$ 是平面，直接用公式法）即可。

### 例2（经典）：锥面下侧 + Gauss

> $I = \iint_\Sigma (x^2\cos\alpha + y^2\cos\beta + z^2\cos\gamma)\,dS$，$\Sigma: x^2+y^2=z^2,\; 0\leq z\leq h$ 取下侧。

**分析**：锥面的下侧 ≠ 外侧。先转化为第二类积分：

$I = \iint_\Sigma x^2\,dydz + y^2\,dzdx + z^2\,dxdy$。

**补面**：$\Sigma_1: z=h, x^2+y^2 \leq h^2$，取上侧。

$\Sigma+\Sigma_1$ 构成闭曲面，Gauss 公式：

\$\$
\begin{aligned}
\oiint_{\Sigma+\Sigma_1} &= \iiint_\Omega (2x+2y+2z)\,dxdydz \\
&= 2\iiint_\Omega (x+y+z)\,dxdydz
\end{aligned}$$

由对称性（$\Omega$ 关于 $z$ 轴旋转对称），$\iiint x\,dxdydz = \iiint y\,dxdydz = 0$。

$\iiint z\,dxdydz = \int_0^h z \cdot \pi z^2\,dz = \pi\int_0^h z^3\,dz = \frac{\pi h^4}{4}$。

所以 $\oiint_{\Sigma+\Sigma_1} = 2 \cdot \frac{\pi h^4}{4} = \frac{\pi h^4}{2}$。

再算辅助面：$\iint_{\Sigma_1} z^2\,dxdy = \iint_{D: x^2+y^2\leq h^2} h^2\,dxdy = h^2 \cdot \pi h^2 = \pi h^4$。

（$x^2\,dydz$ 和 $y^2\,dzdx$ 在平面 $z=h$ 上正交性为 0）

所以 $I = \frac{\pi h^4}{2} - \pi h^4 = -\frac{\pi h^4}{2}$。

### 例3（考研）：补面 + 柱坐标

> $I = \iint_\Sigma (x-1)^3\,dydz + (y-1)^3\,dzdx + (z-1)^3\,dxdy$，$\Sigma: 2z=x^2+y^2,\; z\leq 1$ 取上侧。

**补面**：$\Sigma_1: z=1, x^2+y^2 \leq 2$，取下侧。

\$\$
\begin{aligned}
\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} &= 3(x-1)^2 + 3(y-1)^2 + 3(z-1)^2 \\
&= 3[(x-1)^2 + (y-1)^2 + (z-1)^2]
\end{aligned}$$

$$\oiint_{\Sigma+\Sigma_1} = \iiint_\Omega 3[(x-1)^2+(y-1)^2+(z-1)^2]\,dxdydz$$

展开：$(x-1)^2+(y-1)^2 = x^2+y^2 - 2(x+y) + 2$。

转化为柱坐标 $x=r\cos\theta, y=r\sin\theta$，逐项积分。

$$\iiint_\Omega 3(x^2+y^2+z^2-2x-2y-2z+3)\,dxdydz$$

由对称性，$-6\iiint x\,dxdydz = -6\iiint y\,dxdydz = 0$。计算得闭曲面部分 $= -4\pi$。

辅助面 $\Sigma_1$（下侧，即取下侧＝负号）：$\iint_{\Sigma_1} (z-1)^3\,dxdy = -\iint_D 0\,dxdy = 0$。

（在 $z=1$ 处 $(z-1)^3=0$）

所以 $I = -4\pi$。



## 四、Sec.10.6.2 通量与散度

### 4.1 通量（流量）

向量场 $\vec{A} = (P, Q, R)$ 穿过有向曲面 $\Sigma$ 的**通量**：

$$\boxed{\Phi = \iint_\Sigma \vec{A} \cdot \vec{n}^0\,dS = \iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy}$$

> 通量 = 流量 = 第二类曲面积分。

### 4.2 散度

向量场 $\vec{A}$ 在点 $(x,y,z)$ 处的**散度**：

$$\boxed{\operatorname{div} \vec{A} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}}$$

### 4.3 Gauss 公式的向量形式

$$\boxed{\oiint_\Sigma \vec{A} \cdot \vec{n}^0\,dS = \iiint_\Omega \operatorname{div} \vec{A}\; dV}$$

> 🎯 **一句话**：穿过闭曲面的**通量** = 内部**散度的体积分**。

### 4.4 散度计算示例

> 求 $\operatorname{div}(\operatorname{grad}(x^2+y^2+z^2))$。

$\operatorname{grad}(x^2+y^2+z^2) = (2x, 2y, 2z)$

$\operatorname{div}(2x, 2y, 2z) = \frac{\partial}{\partial x}(2x) + \frac{\partial}{\partial y}(2y) + \frac{\partial}{\partial z}(2z) = 2+2+2 = 6$。

> 这就是物理中的 **Laplace 算子**：$\nabla^2 f = \operatorname{div}(\operatorname{grad} f)$。



## 五、方法选择决策树

```
遇到第二类曲面积分
  │
  ├── Σ 是闭曲面？
  │     ├── 是 → 直接用 Gauss！（外侧为正，内侧为负）
  │     └── 否 → 能补面变闭曲面？
  │           ├── 是 → 补面 + Gauss - 辅助面积分
  │           └── 否 ↓
  │
  ├── 有奇点？
  │     ├── 是 → 挖洞 + 积分曲面特殊化
  │     └── 否 ↓
  │
  ├── 法向量明显（球面等）？
  │     └── 是 → 两类积分转化法
  │
  └── 只能投影？
        ├── z=z(x,y) 且 P,Q,R 可偏导 → 合一投影法
        └── 分项分别投 → 公式法（一投二代三定号）
```



## 六、知识链全景

| 章节 | 公式 | 本质 |
|:--|:--|:--|
| Sec.9.3 Green | $\oint_L Pdx+Qdy = \iint_D (\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y})dxdy$ | 线→面 |
| Sec.10.6 **Gauss** | $\oiint_\Sigma Pdydz+Qdzdx+Rdxdy = \iiint_\Omega (\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z})dV$ | 面→体 |
| Sec.10.7 Stokes | $\oint_L Pdx+Qdy+Rdz = \iint_\Sigma (\cdots)dS$（预告） | 空间线→面 |

> Green 是平面版，Gauss 是空间版，Stokes 是空间曲线版——三个公式构成微积分基本定理的推广链。



## 📇 闪卡速记



### 定理本身

<details class="flashcard">
<summary>Gauss 公式的表达式是什么？</summary>

$\oiint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \iiint_\Omega (\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z})dxdydz$。闭曲面外侧第二类 → 散度三重积分。
</details>

<details class="flashcard">
<summary>Gauss 公式的条件是什么？</summary>

① $\Sigma$ 是**分片光滑的闭曲面**；② $P,Q,R$ 在 $\Omega$ 上**一阶连续偏导**；③ $\Sigma$ 取**外侧**。
</details>

<details class="flashcard">
<summary>内侧的情况怎么处理？</summary>

加负号。$\oiint_{\Sigma_{\text{内}}} = -\iiint_\Omega \operatorname{div}\vec{A}\,dV$。
</details>

### 核心技巧

<details class="flashcard">
<summary>曲面不闭合怎么办？</summary>

**补辅助面**。$\iint_\Sigma = \oiint_{\Sigma+\Sigma_1} - \iint_{\Sigma_1}$。辅助面通常是平面（$z=0$ 或 $z=h$），辅助面上的积分直接用公式法算。
</details>

<details class="flashcard">
<summary>辅助面的侧怎么选？</summary>

使 $\Sigma+\Sigma_1$ 构成**外侧闭曲面**。$\Sigma$ 上侧 → $\Sigma_1$（底面）下侧；$\Sigma$ 下侧 → $\Sigma_1$（顶面）上侧。
</details>

### 通量与散度

<details class="flashcard">
<summary>散度的定义是什么？</summary>

$\operatorname{div}\vec{A} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}$。就是 Gauss 公式中被积函数。
</details>

<details class="flashcard">
<summary>Gauss 公式的向量形式？</summary>

$\oiint_\Sigma \vec{A}\cdot\vec{n}^0\,dS = \iiint_\Omega \operatorname{div}\vec{A}\,dV$。通量 = 散度的体积分。
</details>

### 特殊处理

<details class="flashcard">
<summary>有奇点怎么办？</summary>

**积分曲面特殊化**（挖洞）。以奇点为中心作小球面，利用散度为零的特性，把原曲面积分转化为小球面上的积分。与 Green 公式处理奇点的方法完全一样。
</details>
