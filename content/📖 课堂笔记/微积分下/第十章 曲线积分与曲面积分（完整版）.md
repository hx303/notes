## 🔗 四大公式的统一视角

| 公式 | 积分关系 | 维度 | 对应算子 |
|------|------|:--:|------|
| 格林公式 | 闭曲线 ↔ 平面区域 | 2D | $\partial Q/\partial x - \partial P/\partial y$（旋度的 $z$ 分量） |
| 高斯公式 | 闭曲面 ↔ 空间体 | 3D | $\partial P/\partial x + \partial Q/\partial y + \partial R/\partial z$（散度） |
| 斯托克斯公式 | 空间闭曲线 ↔ 曲面 | 3D | $\mathbf{rot}\,\vec{A}$（旋度） |
| 牛顿-莱布尼茨 | 区间端点 ↔ 区间 | 1D | $f'(x)$ |

> 🔗 **统一本质**：$\int_{\partial M} \omega = \int_M d\omega$ — 边界上的积分 = 内部微分的积分（广义斯托克斯公式）。

# §10.1 对弧长的曲线积分（第一类）

## 概念

$$\boxed{\int_L f(x,y)ds = \lim_{\lambda\to 0}\sum_{k=1}^n f(\xi_k,\eta_k)\Delta s_k}$$

- **物理原型**：曲线型构件质量 $m=\int_L \mu(x,y)ds$
- **被积函数实质一元**：$(x,y)$ 被曲线方程约束 → $f(x,y)$ 在 $L$ 上是一元函数
- **经典陷阱**：$\oint_{x^2+y^2=R^2} (x^2+y^2)ds = R^2\cdot 2\pi R$，不要当二重积分！
- **闭曲线**记为 $\oint_L$；空间曲线推广：$\int_\Gamma f(x,y,z)ds$

## 计算口诀：一投二代三换

| 曲线形式 | $ds$ 公式 |
|:--|:--|
| $y=y(x)$, $a\le x\le b$ | $ds = \sqrt{1+[y'(x)]^2}dx$，下限 < 上限 |
| 参数方程 $x=\varphi(t),y=\psi(t)$ | $ds = \sqrt{[\varphi']^2+[\psi']^2}dt$ |
| 极坐标 $r=\rho(\theta)$ | $ds = \sqrt{\rho^2+(\rho')^2}d\theta$ |
| 空间曲线 $x,y,z=\varphi,\psi,\omega$ | $ds = \sqrt{[\varphi']^2+[\psi']^2+[\omega']^2}dt$ |

## 对称性

| 类型 | 规则 |
|:--|:--|
| 曲线关于 $x$ 轴对称 | 看 $y$ 奇偶：奇函数→0，偶函数→$2\int_{L_1}$ |
| 关于 $y=x$ 对称（轮换） | $\int_L f(x,y)ds = \int_L f(y,x)ds$ |
| 空间曲线轮换 $x=y=z$ | $\oint_\Gamma x^2 ds = \frac{1}{3}\oint_\Gamma (x^2+y^2+z^2)ds$ |

## 手把手例题

> **例**：计算 $\int_L y\,ds$，$L$ 为 $y=x^2$ 上从 $(0,0)$ 到 $(1,1)$ 的弧段。

| 步骤 | 操作 |
|:--|:--|
| ①一投 | $x\in[0,1]$ |
| ②二代 | $y=x^2,\; y'=2x$ |
| ③三换 | $ds = \sqrt{1+(2x)^2}dx = \sqrt{1+4x^2}\,dx$ |
| ④计算 | $I = \int_0^1 x^2\sqrt{1+4x^2}dx$，令 $u=1+4x^2$ → $I = \dfrac{1}{192}(5\sqrt{5}-1)$ |

# §10.2 对坐标的曲线积分（第二类）

## 概念

$$\boxed{\int_L Pdx + Qdy = \lim_{\lambda\to 0}\sum [P(\xi_k,\eta_k)\Delta x_k + Q(\xi_k,\eta_k)\Delta y_k]}$$

- **物理原型**：变力 $\vec{F}=(P,Q)$ 沿曲线 $\widehat{AB}$ 做功
- **扩展**：空间曲线 $\int_\Gamma Pdx+Qdy+Rdz$

## 第一类 vs 第二类

| | 第一类（对弧长） | 第二类（对坐标） |
|:--|:--|:--|
| 被积表达式 | $f(x,y)ds$ | $Pdx + Qdy$ |
| 积分区域 | 无向曲线 $L$ | **有向曲线** $\widehat{AB}$ |
| 方向影响 | ❌ 无关，下限<上限 | ✅ 反向=负号，下限=起点 |
| 正交性 | 无 | $L\perp x$ 轴→$\int Pdx=0$ |

## 计算（有方向！）

参数方程 $x=\varphi(t),y=\psi(t),t:\alpha\to\beta$：
$$\boxed{\int_{\widehat{AB}} Pdx+Qdy = \int_\alpha^\beta [P\varphi'(t) + Q\psi'(t)]dt}$$

> ⚠️ $\alpha$=起点参数，$\beta$=终点参数（$\alpha>\beta$ 也行）

## 两类联系

$$\boxed{\int_L Pdx+Qdy = \int_L (P\cos\alpha+Q\cos\beta)ds}$$

其中 $(\cos\alpha,\cos\beta)$ 为**切向量**方向余弦。向量形式：$\int_\Gamma \vec{F}\cdot d\vec{r} = \int_\Gamma \vec{F}\cdot\vec{\tau}\,ds$

## 手把手例题

> **例**：计算 $\int_L x\,dy$，$L$ 为 $y=x^2$ 从 $A(1,-1)$ 到 $O(0,0)$。

| 步骤 | 操作 |
|:--|:--|
| ①一投 | 起点 $x=1$，终点 $x=0$ → $x:1\to 0$（注意方向！） |
| ②二代 | $y=x^2$, $dy=2x\,dx$；$P=0,\;Q=x$ |
| ③三换 | $I = \int_1^0 x\cdot 2x\,dx = 2\int_1^0 x^2 dx$ |
| ④计算 | $I = 2[\frac{x^3}{3}]_1^0 = 2(0-\frac{1}{3}) = -\frac{2}{3}$ |

> **例**：计算 $\int_L xy^2dx + x^2ydy$，$L$ 为 $y=x$ 从 $(0,0)$ 到 $(1,1)$。

| 步骤 | 操作 |
|:--|:--|
| ①一投 | $x:0\to 1$ |
| ②二代 | $y=x$, $dy=dx$ → 被积 = $x\cdot x^2\,dx + x^2\cdot x\,dx = 2x^3\,dx$ |
| ③三换 | $I = \int_0^1 2x^3dx$ |
| ④计算 | $I = [\frac{x^4}{2}]_0^1 = \frac{1}{2}$ |

> 💡 此题还可用全微分：$xy^2dx+x^2ydy = \frac{1}{2}d(x^2y^2)$ → $I = \frac{1}{2}[1^2\cdot1^2-0]=\frac{1}{2}$（路径无关预告！）

# §10.3 格林公式

## 格林公式本身

$\boxed{\oint_L Pdx + Qdy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dxdy}$

- **条件**：$L$ 闭 + $P,Q$ 一阶连续偏导 + $L$ 正向（沿 $L$ 走，$D$ 在左手边）
- **记忆口诀**：Q_x − P_y（字母顺序）

## 三大策略

| 情况 | 策略 |
|:--|:--|
| $L$ 闭 + 无奇点 | ✅ 直接套 |
| $L$ 不封闭 | ➕ 加辅助线围成闭区域，算完后减去辅助线 |
| 区域内有奇点 | 🔪 挖奇点，积分路径特殊化为绕奇点的小圆 |

> $\oint \frac{-ydx+xdy}{x^2+y^2}$ 绕原点任意闭曲线 $= 2\pi$（考研高频结论）

## 路径无关条件（四条等价）

设 $P,Q$ 在**单连通区域** $D$ 内有一阶连续偏导，则以下等价：

| (1) | $\int_L Pdx+Qdy$ 与路径无关 |
| (2) | $\oint_L Pdx+Qdy = 0$（沿 $D$ 内任意闭曲线） |
| (3) | $Pdx+Qdy$ 是某函数 $u$ 的全微分 |
| (4) | $\boxed{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}$ 恒成立 |

**原函数求法**（折线积分）：$u(x,y) = \int_{x_0}^x P(t,y_0)dt + \int_{y_0}^y Q(x,s)ds$

**全微分方程**：$Pdx+Qdy=0$ 且 $\partial P/\partial y = \partial Q/\partial x$ → 通解 $u(x,y)=C$

## 手把手例题

> **例1**：用 Green 计算 $\oint_L (x-y)dx+(x+y)dy$，$L: x^2+y^2=a^2$ 逆时针。

| 步骤 | 操作 |
|:--|:--|
| ①识 | $P=x-y$, $Q=x+y$ |
| ②算 | $Q_x = 1$, $P_y = -1$ → $Q_x-P_y = 2$ |
| ③套 | $\oint_L = \iint_D 2\,dxdy = 2\cdot\pi a^2 = 2\pi a^2$ |

> **例2（不封闭→补线）**：计算 $\int_L (x^2-y)dx-(x+\sin^2y)dy$，$L$ 为上半圆 $y=\sqrt{2x-x^2}$ 从 $(2,0)$ 到 $(0,0)$。

$P=x^2-y$, $Q=-(x+\sin^2y)$。$Q_x = -1$, $P_y = -1$ → $Q_x-P_y = 0$（在区域内路径无关！）。

补 $x$ 轴线段从 $(0,0)$ 回到 $(2,0)$（$y=0$）：$\int_{补} = \int_0^2 x^2 dx = \frac{8}{3}$。

由闭曲线积分为 0：$\int_L + \int_{补} = 0$ → $\int_L = -\frac{8}{3}$。

# §10.4 对面积的曲面积分（第一类）

## 概念

$$\boxed{\iint_\Sigma f(x,y,z)dS}$$

- **物理原型**：曲面型构件质量 $M = \iint_\Sigma \mu(x,y,z)dS$
- **实质**：被积函数含三个变量，但在曲面上被约束为**二元函数**，最终化为**二重积分**

## 计算口诀：一投二代三换

$$\boxed{\iint_\Sigma f(x,y,z)dS = \iint_{D_{xy}} f(x,y,z(x,y)) \sqrt{1 + z_x'^2 + z_y'^2}\; dxdy}$$

| 曲面 | $dS$ 公式（投影到 $Oxy$） |
|:--|:--|
| 一般曲面 $z=z(x,y)$ | $dS = \sqrt{1+z_x'^2+z_y'^2}\,dxdy$ |
| 球面 $x^2+y^2+z^2=R^2$ | $dS = \frac{R}{\sqrt{R^2-x^2-y^2}}dxdy$ |
| 圆锥面 $z=\sqrt{x^2+y^2}$ | $dS = \sqrt{2}\,dxdy$ |

> 圆柱面投影到 $Oxy$ 是圆（一维），应投到 $Oyz$ 或 $Ozx$ 面。

## 手把手例题

> **例**：计算 $\iint_\Sigma z^2 dS$，$\Sigma: x^2+y^2+z^2=R^2$。

| 步骤 | 操作 |
|:--|:--|
| ①一投 | 球面在 $Oxy$ 投影 $D: x^2+y^2 \leq R^2$ |
| ②二代 | 上半球 $z=\sqrt{R^2-x^2-y^2}$ → $z^2 = R^2-x^2-y^2$ |
| ③三换 | $dS = \frac{R}{\sqrt{R^2-x^2-y^2}}dxdy$ |
| ④积分 | $\iint_{上半} = R\iint_D \sqrt{R^2-x^2-y^2}dxdy$，极坐标：$R\int_0^{2\pi}\int_0^R r\sqrt{R^2-r^2}dr = \frac{2}{3}\pi R^4$ |
| ⑤乘2 | 下半球相同 → $\times 2$ → $\frac{4}{3}\pi R^4$ |

> 💡 更快法（轮换对称）：$\iint z^2 dS = \frac{1}{3}\iint (x^2+y^2+z^2)dS = \frac{R^2}{3}\cdot 4\pi R^2 = \frac{4}{3}\pi R^4$。两行！

## 对称性

| 类型 | 规则 | 
|:--|:--|
| 面对称（$\Sigma$ 关于 $Oyz$ 面对称→看 $x$ 奇偶） | 奇函数→0，偶函数→$2\int_{\Sigma_1}$ |
| 球面轮换对称 | $\iint x^2 dS = \iint y^2 dS = \iint z^2 dS = \frac{4}{3}\pi R^4$ |

# §10.5 对坐标的曲面积分（第二类）

## 概念

$$\boxed{\iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy}$$

- **物理原型**：流体穿过有向曲面的**流量** $\Phi = \iint_\Sigma \vec{v} \cdot \vec{n}^0 dS$
- **核心特性**：换侧变号 $\iint_{-\Sigma} = -\iint_\Sigma$（与第一类最大区别）

## 计算口诀：一投二代**三定号**

$$\boxed{\iint_\Sigma R(x,y,z)dxdy = \pm \iint_{D_{xy}} R(x,y,z(x,y))dxdy}$$

| 侧 | 符号 |
|:--|:--|
| 上侧（$\cos\gamma > 0$） | $+$ |
| 下侧（$\cos\gamma < 0$） | $-$ |

> $P$→$Oyz$（前/后），$Q$→$Ozx$（右/左），$R$→$Oxy$（上/下），各算各的。

## 对称性（⚠️ 与第一类相反！）

**奇倍偶零**（第一类是"奇零偶倍"）——因为对侧的有向投影符号相反。

> **例**：$\Sigma$ 关于 $Oxy$ 面对称，$R=z^2$（关于 $z$ 的偶函数）：
> - 第一类：$\iint_\Sigma z^2 dS = 2\iint_{\Sigma_\text{上}} z^2 dS$（"偶倍"）
> - 第二类：$\iint_\Sigma z^2 dxdy = 0$（"偶零"，上下侧投影一正一负互相抵消）

## 两类联系

$$\boxed{\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy = \iint_\Sigma (P\cos\alpha+Q\cos\beta+R\cos\gamma)dS}$$

## 合一投影法

$\Sigma: z=z(x,y)$ 投影到 $Oxy$，三个分项合并：

$$\boxed{\iint_\Sigma = \pm \iint_{D_{xy}} \big[P\cdot(-z_x') + Q\cdot(-z_y') + R\big]dxdy}$$

上侧取正，下侧取负。**含抽象函数 $f$ 时特别有效！**

> ⚠️ **§10.4 vs §10.5 口诀辨析**：
> - 第一类（对面积）：一投二代**三换** → $dS = \sqrt{1+z_x'^2+z_y'^2}\cdot dxdy$（$dS$ 永正，无正负号）
> - 第二类（对坐标）：一投二代**三定号** → 直接 $dxdy$，但前面加 $\pm$（上/前/右→正，下/后/左→负）
> 
> **原因**：第一类 $dS$ 是正的曲面面积微元；第二类 $dxdy$ 是**有向投影**，可正可负。

## 手把手例题

> **例**：计算 $\oiint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$，$\Sigma: x^2+y^2+z^2=R^2$ 外侧。

| 步骤 | 操作 |
|:--|:--|
| ①识 | 闭曲面外侧 → 可用 Gauss，但这里演示两类转化法 |
| ②法向量 | 外侧 $\vec{n}^0 = (\frac{x}{R},\frac{y}{R},\frac{z}{R})$ |
| ③转化 | $\oiint = \iint (x\cdot\frac{x}{R}+y\cdot\frac{y}{R}+z\cdot\frac{z}{R})dS = \frac{1}{R}\iint (x^2+y^2+z^2)dS$ |
| ④化简 | 球面上 $x^2+y^2+z^2=R^2$ → $= \frac{R^2}{R}\iint dS = R\cdot 4\pi R^2 = 4\pi R^3$ |

> 对比硬算法（分上下半球投影）：至少多花 5 分钟。用 Gauss 公式（§10.6）：散度=3 → $\iiint 3dV = 4\pi R^3$，一行！

# §10.6 高斯公式（Gauss 定理）

## 定理

$$\boxed{\oiint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iiint_\Omega \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right) dxdydz}$$

- **条件**：$\Sigma$ 闭 + $P,Q,R$ 一阶连续偏导 + $\Sigma$ 取**外侧**
- 内侧加负号

## 核心技巧

| 情况 | 策略 |
|:--|:--|
| 曲面不闭合 | ➕ 补辅助面（通常为平面 $z=h$）→Gauss → 减去辅助面 |
| 有奇点 | 🔪 挖奇点 + 积分曲面特殊化（与 Green 公式同理） |

## 散度与通量

$$\boxed{\operatorname{div} \vec{A} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}}$$

向量形式：$\boxed{\oiint_\Sigma \vec{A} \cdot \vec{n}^0\,dS = \iiint_\Omega \operatorname{div} \vec{A}\; dV}$

> "穿过闭曲面的通量 = 内部散度的体积分"

## 手把手例题

> **例**：用 Gauss 计算 $\oiint_\Sigma x\,dydz+y\,dzdx+z\,dxdy$，$\Sigma: x^2+y^2+z^2=R^2$ 外侧。

| 步骤 | 操作 |
|:--|:--|
| ①识 | $P=x$, $Q=y$, $R=z$ |
| ②算散度 | $\operatorname{div} = 1+1+1 = 3$ |
| ③套 Gauss | $\oiint_\Sigma = \iiint_\Omega 3\,dV = 3\cdot\frac{4}{3}\pi R^3 = 4\pi R^3$ |

> ⏱️ 对比 §10.5 硬算法：分上下半球→分别投影→分别定号→加起来。Gauss 一行秒杀！

> **例（不封闭→补面）**：计算 $\iint_\Sigma z\,dxdy$，$\Sigma: z=\sqrt{1-x^2-y^2}$ 上侧。

补底面 $z=0$（下侧），构成闭区域（上半球）。散度 $= 1$。$\oiint = \iiint_\Omega 1\,dV = \frac{2}{3}\pi$。辅助面 $\iint_{底} zdxdy = \iint_D 0\,dxdy = 0$。∴ $I = \frac{2}{3}\pi$。

# §10.7 斯托克斯公式

## 定理

$$\boxed{\oint_{\Gamma} Pdx+Qdy+Rdz = \iint_{\Sigma} \begin{vmatrix}
dydz & dzdx & dxdy \\[2pt]
\frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\[4pt]
P & Q & R
\end{vmatrix} + \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dxdy$$
> 第三行就是依次去掉第一行对应列、取 $2\times 2$ 余子式，注意符号交替。

- $\Gamma$ 为空间闭曲线，$\Sigma$ 是以 $\Gamma$ 为边界的有向曲面
- $\Gamma$ 的正向与 $\Sigma$ 的法向满足**右手法则**
- 当 $\Gamma$ 在 $Oxy$ 平面上 → 退化为格林公式

## 旋度与环流量

$$\boxed{\mathbf{rot}\,\vec{A} = \nabla \times \vec{A} = \begin{vmatrix}
\vec{i} & \vec{j} & \vec{k} \\[4pt]
\frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\[4pt]
P & Q & R
\end{vmatrix}}$$

$$\boxed{\oint_{\Gamma} \vec{A} \cdot d\vec{r} = \iint_{\Sigma} \mathbf{rot}\,\vec{A} \cdot \vec{n}\, dS}$$

## 场论三剑客

| 概念 | 记号 | 输入→输出 | 公式 | 直觉 |
|------|------|:--:|------|------|
| 梯度 | $\nabla u$ | 标量→矢量 | $(u_x, u_y, u_z)$ | 最陡方向 |
| 散度 | $\nabla \cdot \vec{A}$ | 矢量→标量 | $P_x+Q_y+R_z$ | 源强度 |
| 旋度 | $\nabla \times \vec{A}$ | 矢量→矢量 | 行列式 | 旋转趋势 |

**两大恒等式**：
1. $\nabla \times (\nabla u) = \vec{0}$（梯度无旋）
2. $\nabla \cdot (\nabla \times \vec{A}) = 0$（旋度无散）

## 手把手例题

> **例**：计算 $\oint_\Gamma ydx+zdy+xdz$，$\Gamma$ 为平面 $x+y+z=1$ 被三坐标面所截三角形的边界（逆时针）。

| 步骤 | 操作 |
|:--|:--|
| ①选 $\Sigma$ | $\Sigma$ 取该平面三角形区域，上侧 |
| ②套 Stokes | $\oint_\Gamma = \iint_\Sigma \begin{vmatrix}dydz&dzdx&dxdy\\\partial_x&\partial_y&\partial_z\\y&z&x\end{vmatrix}$ |
| ③展开 | $= \iint_\Sigma [(\frac{\partial x}{\partial y}-\frac{\partial z}{\partial z})dydz + (\frac{\partial y}{\partial z}-\frac{\partial x}{\partial x})dzdx + (\frac{\partial z}{\partial x}-\frac{\partial y}{\partial y})dxdy]$ |
| ④化简 | $= \iint_\Sigma (0-1)dydz+(0-1)dzdx+(0-1)dxdy = -\iint_\Sigma (dydz+dzdx+dxdy)$ |
| ⑤合一投影 | 上侧，$z=1-x-y$ → $z_x'=-1, z_y'=-1$ → $= -\iint_D[(-(-1))+(-(-1))+1]dxdy = -3\iint_D dxdy$ |
| ⑥结果 | $D$ 为直角三角形，面积 $=\frac{1}{2}$ → $I = -3\cdot\frac{1}{2} = -\frac{3}{2}$ |
