## 摘要

RayFlare 是一个开源、集成化的光学建模 Python 环境，专注于太阳电池中的复杂光学堆栈模拟。它统一了三种基础光学方法——**射线追踪（Ray-Tracing, RT）**、**传输矩阵法（Transfer-Matrix Method, TMM）** 和 **严格耦合波分析（Rigorous Coupled-Wave Analysis, RCWA）**——并通过 **角再分布矩阵框架（angular redistribution matrix formalism）** 实现方法的灵活组合。RayFlare 可在 CPU 和 GPU 上运行（后者可选），为用户提供了一个完整的工具链来处理从简单平面堆栈到复杂织构太阳电池的全部光学建模需求。

---

## 1. 需求陈述

精确的光学建模对于理解和优化太阳电池的性能至关重要。对于钙钛矿/硅叠层太阳电池等先进光伏器件，光学设计涉及多个尺度的挑战：薄膜干涉效应（纳米级）、周期性衍射光栅（微米级）以及大尺度表面织构（数微米至数十微米的金字塔）。目前学术界和工业界使用的光学模拟工具面临以下限制：

| 工具 | 局限性 |
|:--|:--|
| **OPTOS** | 开源但需用户手动计算各波长的再分布矩阵 |
| **GenPro4** | 不支持光栅结构，闭源 |
| **SunSolve** | 商业软件，许可昂贵 |
| **自编 TMM/RT 脚本** | 碎片化，缺乏统一框架，难以复现 |

RayFlare 的设计目标是填补这一空白：提供一个**完全开源、用户友好、支持多方法自动组合**的统一光学建模平台。特别地，RayFlare 是首个自动为各波长计算角再分布矩阵并同时追踪前后表面层吸收的软件。

## 2. 核心架构

### 2.1 三种基础光学方法

| 方法 | 物理模型 | 适用场景 | 实现 |
|:--|:--|:--|:--|
| **RT（射线追踪）** | 几何光学 | 大尺度织构（特征尺寸 >> λ） | 三角化表面 + Fresnel 方程 / 集成 TMM |
| **TMM（传输矩阵法）** | 波动光学 | 平面薄膜干涉（透明或吸收介质）| 标准 2×2 传输矩阵 |
| **RCWA（严格耦合波分析）** | Maxwell 方程求解 | 周期性衍射光栅 | 调用 **S⁴**（Stanford Stratified Structure Solver）库 |

每种方法都可以独立用于模拟完整结构（分别通过 `rt_structure`、`tmm_structure` 和 `rcwa_structure` 类）。用户定义材料、层厚度、表面织构（RT）或光栅形状（RCWA），RayFlare 计算反射率 R(λ)、透射率 T(λ)、各层吸收率 Aᵢ(λ) 以及（若指定）结构中的吸收剖面。

### 2.2 角再分布矩阵框架（核心创新）

RayFlare 的关键创新在于其**角再分布矩阵框架**的设计和自动化实现。该框架将结构的前表面和背表面解耦：

```
┌─────────────────────────────────────┐
│         入射光（各方向）             │
├─────────────────────────────────────┤
│  前表面再分布矩阵                   │
│  → 反射方向分布                     │
│  → 透射进入体介质的方向分布         │
│  → 前表面层吸收                     │
├─────────────────────────────────────┤
│  体介质（Beer-Lambert 吸收）        │
│  → 传播衰减                         │
├─────────────────────────────────────┤
│  背表面再分布矩阵                   │
│  → 反射回体介质的方向分布           │
│  → 透射逃逸的方向分布               │
│  → 背表面层吸收                     │
└─────────────────────────────────────┘
```

矩阵乘法过程最终输出：
- **R(λ)** — 总（半球）反射率
- **T(λ)** — 总透射率
- **A_surface(λ)** — 前后表面薄层中的吸收
- **A_bulk(λ)** — 体介质中的吸收（Beer-Lambert）
- **吸收剖面 G(z, λ)** — 作为深度的函数（此前无类似工具公开此功能）

**Beer-Lambert 近似的适用条件**：体介质必须足够厚，使得其中的干涉效应可忽略，即显著厚于所考虑的最大入射波长。

### 2.3 再分布矩阵生成方法

| 方法 | 描述 | 适用场景 |
|:--|:--|:--|
| **RT + Fresnel 方程** | 在三角化织构表面使用简单的 Fresnel 反射/透射概率 | 简单织构界面，无表面层 |
| **集成 RT + TMM** | 反射/透射/吸收概率由 TMM 而非 Fresnel 计算 | 大尺度织构 + 一个或多个薄表面层 |
| **纯 TMM** | 平面多层表面 | 平面 ARC 或多层前/后表面 |
| **RCWA** | 周期性光栅（可含多层平面层）| 衍射光栅 |
| **理想/理论参考** | 完美镜面或完美朗伯散射体 | 理论极限研究 |

### 2.4 方法自动选择与组合

RayFlare 的一个重要设计原则是**用户不指定"用什么方法"，而是描述"结构长什么样"**——RayFlare 自动选择最合适的方法组合。例如：

- **平面 ARC 前表面 + 金字塔背表面**：前表面自动用 TMM（极快），仅背表面用射线追踪（较慢）
- **金字塔前表面 + 衍射光栅背表面**：前表面用 RT+TMM，背表面用 RCWA
- **双面金字塔织构**：前后表面均用 RT+TMM

极大地降低了用户的学习曲线和出错概率，同时保留了手动指定方法的灵活性。

## 3. 技术实现

### 3.1 软件栈

RayFlare 主要使用 Python 编写，依赖以下开源生态：

| 组件 | 用途 |
|:--|:--|
| **NumPy / SciPy** | 数值计算核心 |
| **S⁴** (C++/Python 绑定) | RCWA Maxwell 求解 |
| **Numba** | JIT 编译加速（CPU） |
| **CuPy**（可选）| GPU 加速 |
| **matplotlib** | 可视化 |
| **xarray** | 多维数据管理 |

### 3.2 织构定义

织构通过三角化表面定义：用户提供描述表面几何形状的顶点和面的列表，或使用内置函数生成规则金字塔、倒金字塔、正弦光栅等常见织构。

### 3.3 射线追踪算法

RayFlare 使用 **Monte Carlo 射线追踪**。对每条入射射线：

1. 确定与表面三角形的交点
2. 使用 Fresnel 方程（基础模式）或查询预计算的 TMM 概率（集成模式）决定反射/透射
3. 跟踪直至射线被吸收或逃逸
4. 统计平均得到 R(λ)、T(λ)、A(λ)

Phong 散射模型可用于描述真实织构表面的漫反射分量。

### 3.4 角分布与剖面计算

RayFlare 可输出：
- **角分辨反射/透射**（各方向的分布）
- **深度分辨吸收剖面 G(z, λ)** — 对计算太阳电池中的光生载流子分布至关重要
- **各层积分吸收** Aᵢ(λ)

## 4. 与方案A 的直接关联 ⭐⭐⭐

RayFlare 是方案A 模拟工具链的**核心引擎**。以下是逐项对应关系：

### 4.1 方案A 的 RayFlare LUT 构建流程

方案A 需要模拟 **PL 发射光子在不同膜厚、不同织构几何形状的钙钛矿中的传播**，以建立 "PL 观测峰位 ↔ 膜厚" 的查找表（LUT）。RayFlare 提供完成此任务的所有基本功能：

```
步骤 1: (n,k) 光学常数输入
   ↓   ← 来自 P1_08 (Dasgupta/Stranks 2026)
步骤 2: 织构几何定义（金字塔/随机/纳米织构）
   ↓   ← 来自实验 AFM/SEM
步骤 3: RayFlare 模拟
   ↓   → 泵浦光吸收剖面 G_pump(z)
   ↓   → 各向同性 PL 发射源分布 S(z, λ₀)
   ↓   → 射线追踪 → 逃逸光子角/能量分布
   ↓   → 收集方向光谱（共聚焦 NA 滤波）
步骤 4: PL 峰位 vs 膜厚 → LUT
```

### 4.2 各关键功能的方案A 对应

| RayFlare 功能 | 方案A 用途 |
|:--|:--|
| **RT+TMM 集成模式** | 织构钙钛矿 + 传输层（ETL/HTL）的精确光学模拟 |
| **角再分布矩阵** | 各向同性 PL 发射的 4π 方向分布 → 确定收集效率 |
| **G(z, λ_pump) 吸收剖面** | 泵浦激光在钙钛矿中的激发深度 → PL 发射源位置分布 |
| **角分辨输出** | 共聚焦显微镜的 NA 孔径模拟 → 匹配实验收集几何 |
| **Phong 散射模型** | 真实织构表面的非镜面散射 → 散射对 PL 路径的影响 |
| **GPU 加速** | 大量参数扫描（不同膜厚、不同织构）的加速 |

### 4.3 与 Rocha (2025) 论文的方法一致性

Rocha 2025 论文（前述 09 号论文）使用 RayFlare + Phong 散射 + Solcore 进行全织构 PSTSC 的光学模拟。方案A 可以直接复用该论文建立的：
- 钙钛矿光学参数（Cs₀.₁₇FA₀.₈₃Pb(I₀.₈₃Br₀.₁₇)₃，带隙 1.63 eV）
- 金字塔织构几何（θ = 44°, H = 3 μm）
- RayFlare 的完整工作流程

### 4.4 与 P0 论文的互补性

| P0 论文 | 光学方法 | RayFlare 对应模式 |
|:--|:--|:--|
| P0_01 (Callies 2025) | RAYTRACE3D 光线追踪 | RayFlare RT 模式 |
| P0_04 (Bonnín-Ripoll 2019) | MC 光线追踪 + TMM + 载流子输运 | RayFlare RT+TMM 模式 |

RayFlare 统一了这些论文中使用的光学模拟方法，为方案A 提供了一个整合、可复现的软件平台。

## 5. 软件可用性

### 安装

```bash
pip install rayflare
```

或从源码安装获得最新的开发版本：
```bash
git clone https://github.com/qpv-research-group/rayflare
cd rayflare
pip install -e .
```

GPU 加速需要额外安装 CuPy。

### 使用示例

```python
from rayflare import rt_structure, tmm_structure

# 定义平面前表面（TMM）
front = tmm_structure(
    layers=[...],     # ARC 层定义
    incidence=...     # 入射介质
)

# 定义织构背表面（RT）
back = rt_structure(
    textures=[...],   # 织构定义
    materials=[...],  # 各层材料
    widths=[...],     # 各层厚度
    incidence=...     # 入射介质
)

# 计算反射/透射/吸收
result = front.calculate(...)  # 或 back.calculate(...)
```

详细示例见 [rayflare.readthedocs.io](https://rayflare.readthedocs.io) 的 Examples 部分。
