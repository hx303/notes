第四章 向量空间
——知识点整合总结
《线性代数》（四川大学出版社 第三版）
引 言
第四章"向量空间"是线性代数核心章节。本章以向量空间为统一框架，将向量组的线性相关性、极大无关组与向量组的秩、矩阵的秩、子空间、基与维数以及线性方程组解的结构等概念有机地串联起来。下文将按小节顺序逐一梳理知识点，并在每个知识点处即时分析其与前后概念的内在联系、判定性质、做题技巧与意义。
一、§4.1&4.2 向量的相关性

1. 向量空间的定义
    数域 P 上全体 n 维行（列）向量构成的集合，对于向量加法和数乘运算，构成数域 P 上的 n 维向量空间，记作 Pⁿ。当 P = R 时即为 Rⁿ。向量空间具有加法交换律、结合律、零元存在性、负元存在性、数乘结合律、分配律等八条运算律。
2. 线性组合与线性表示
    定义：设向量组 I: α₁,α₂,…,αₙ 及向量 β，若存在数 k₁,k₂,…,kₙ∈P 使得 β = k₁α₁ + k₂α₂ + … + kₙαₙ，则称 β 为 I 的线性组合，或称 β 可由 I 线性表示。
    判断方法：等价于判断向量方程 β = x₁α₁ \+ … \+ xₙαₙ 是否有解。列向量时增广矩阵为 \[α₁ … αₙ \| β\]。
    联系与意义：
    "线性表示"将向量间关系转化为方程组求解。后续非齐次方程组 Ax=β 有解的条件，本质上就是判断 β 能否由 A 的列向量组线性表示。同时它是"生成子空间"的基础：由向量组所有线性组合构成的集合就是它们生成的子空间。若 β 可由向量组线性表示，则 β 在该向量组生成的子空间中。
3. 线性相关与线性无关
    定义：设 α₁,…,αₙ∈Pⁿ。若存在不全为零的 k₁,…,kₙ 使 ∑kᵢαᵢ=0，则称该向量组线性相关；若只有当 k₁=…=kₙ=0 时才成立，则称线性无关。
    重要性质：
    •	单个零向量线性相关；单个非零向量线性无关。
    •	若向量组线性相关，则至少有一个向量可由其余线性表示，反之亦然。
    •	若线性无关，则任意部分组也线性无关；若线性相关，添加向量后仍相关。
    •	含零向量的向量组必线性相关。
    •	n+1 个 n 维向量必线性相关（个数>维数时必然相关）。
    判别方法：
    等价于判断齐次方程组 x₁α₁+…+xₙαₙ=0 是否有非零解。操作：以向量为列构造矩阵 A，化为阶梯形，若 R(A)<n 则相关，R(A)=n 则无关。
    联系与做题技巧：
    线性相关性是本章的出发点。判断方法已指向"矩阵的秩"这一核心工具——做题时直接构造矩阵求秩即可，无需试具体系数。"线性无关"也是后续"基"的前提条件，基中的向量必须线性无关。注意区分给的是行向量还是列向量，统一处理成列向量构造成矩阵再计算。
    二、§4.3 向量组的极大线性无关组和秩
4. 极大线性无关组的定义
    定义：设有向量组 T，若其中存在一个部分组 I: α₁,α₂,…,αₛ 满足：(1) I 线性无关；(2) T 中任意向量都可由 I 线性表示。则称 I 为 T 的一个极大线性无关组（简称极大无关组）。
    意义与内在联系：
    极大无关组是线性相关性的自然延伸。对于一个线性相关的向量组，虽然其中向量之间存在线性关系，但我们总可以从中挑出一个最大的线性无关的部分组，这就是极大无关组。它代表了原向量组的"独立核心"，"极大"意味着再多加一个向量就会变成线性相关。线性无关的向量组，它自己就是自己的极大无关组。
5. 极大无关组的性质
    •	极大无关组不唯一，但各极大无关组所含向量的个数相同。
    •	向量组与其极大无关组等价（可互相线性表示）。
    •	任何向量都可由极大无关组唯一线性表示。
6. 向量组的秩
    定义：极大无关组所含向量的个数 r 称为该向量组的秩，记作 R(α₁,…,αₙ)。极大无关组虽不唯一，但秩是唯一确定的。
7. 极大无关组的求法
    步骤：
    •	以向量组为列构造矩阵 A。
    •	对 A 做初等行变换化为阶梯形。
    •	主元列对应的原矩阵列即为极大无关组。
    •	向量个数 = R(A) = 向量组的秩。
    联系与意义——本节是关键桥梁：
    极大无关组和向量组的秩是"线性相关性"到"矩阵的秩"的过渡。其核心逻辑链为：线性相关性 → 极大无关组（找独立核心）→ 向量组的秩（独立向量个数）→ 矩阵的秩（行秩=列秩=矩阵的秩）。这一节将"向量组"与"矩阵"完美对接，是理解全章的关键枢纽。
    做题技巧与易错点：
    (1) 求极大无关组一定要用"原矩阵的列"，不是变换后的列。初等行变换保持列间线性关系但会改变列本身，所以必须回原矩阵取对应列。(2) 问"某向量能否由其他线性表示"：将该向量加入后看秩是否增加，不增则能表示，增则不能。(3) 极大无关组是向量组的概念（一组向量），而秩是一个数，注意区分。
    三、§4.4 矩阵的秩
8. 子式与矩阵秩的定义
    在 m×n 矩阵 A 中，最高阶非零子式的阶数 r 称为 A 的秩，记作 R(A)。零矩阵的秩为 0。
9. 秩的性质
    •	R(O)=0；R(A)≤min{m,n}；R(Aᵀ)=R(A)；R(kA)=R(A) (k≠0)
    •	方阵可逆⇔ R\(A\)=n ⇔ \|A\|≠0
    •	行秩 = 列秩 = 矩阵的秩——最重要的结论之一
    •	初等变换不改变秩
    求秩的最常用方法：初等行变换化为阶梯形，非零行行数即秩。
    联系与意义——从向量组到矩阵的统一：
    前面 4.3 定义了"向量组的秩"，本节定义了"矩阵的秩"。关键定理"行秩=列秩=矩阵的秩"将两者统一：矩阵的秩 = 其行向量组的秩 = 其列向量组的秩。因此，我们既可以按子式定义求秩，也可以按向量组求极大无关组的方法求秩，两种途径结果一致。
    与 4.1&4.2 的联系：
    向量组线性相关 ⇔ R(A)<n。秩 r = n 则无关，r < n 则相关，r 越小相关程度越高（多余向量的个数越多）。这就是秩作为"相关性定量度量"的含义。做题时判断相关性，直接对矩阵做行变换看秩就行。
    四、§4.5 子空间
10. 子空间的定义
    设 H⊆Rⁿ 非空，满足：(1) 0∈H；(2) 加法封闭；(3) 数乘封闭。则称 H 为子空间。平凡子空间：{0} 和 Rⁿ 本身。
11. 列空间 Col A
    Col A = \{b∈Rᵐ \| ∃x∈Rⁿ\, Ax=b\} ⊆ Rᵐ，即值域。dim\(Col A\)=R\(A\)。
12. 零空间 Nul A
    Nul A = \{x∈Rⁿ \| Ax=0\} ⊆ Rⁿ，即 Ax=0 的解空间。
13. 行空间与生成子空间
    Row A 是 A 的行向量所有线性组合的集合，⊆ Rⁿ，dim(Row A)=R(A)。
    Span{v₁,…,vₖ} = {k₁v₁+…+kₖvₖ} 也是子空间，等价向量组生成相同子空间。
    联系与意义——秩定理将三者统一：
    每一个矩阵 A 定义了三个基本子空间：
    •	dim(Col A) = R(A)
    •	dim(Row A) = R(A)
    •	dim(Nul A) = n - R(A)
    秩定理（核心定理）：rank(A) + dim(Nul A) = n。
    这揭示了列空间与零空间的此消彼长关系：主元越多（秩越大），自由变量越少（零空间维数越小）。
    从映射角度理解（考研常考）：
    A 定义线性映射 Rⁿ→Rᵐ，x↦Ax。Col A 是像（值域），Nul A 是核（kernel）。秩定理即线性代数的"像-核定理"：dim(定义域) = dim(像) + dim(核)。这一视角将矩阵、子空间和线性方程组统一在一起。
    联系 4.1&4.2：
    向量组 v₁,…,vₖ 生成子空间 Span{v₁,…,vₖ}。该子空间维数 = 向量组的秩。若向量组线性无关则维数=向量个数，若相关则维数<向量个数。因此"向量组线性无关"等价于"其生成子空间的维数等于向量个数"。
    五、§4.6 基和维数
14. 基的定义
    设 H⊆Rⁿ 是非零子空间，H 中的一组线性无关的生成集称为 H 的基。等价地，基是子空间 H 的一个极大无关组。
15. 维数的定义
    子空间 H 的任一组基所含向量个数称为 dim H。dim{0}=0，dim Rⁿ=n。维数 = 子空间的秩 = 生成集的秩。
16. 重要定理
    定理1：dim H = r，则 (1) H 中任意 r 个线性无关的向量构成基；(2) 任意 r 个向量若能生成 H 则也是基。
    秩定理：rank(A) + dim(Nul A) = n。
17. 坐标
    在基 B={b₁,…,bₚ} 下，x = x₁b₁+…+xₚbₚ，系数向量称为坐标。
    联系与意义——基是子空间的"坐标架"：
    基的概念将 4.3（极大无关组）、4.4（秩）、4.5（子空间）全面统一：
    •	子空间的基 = 子空间的极大无关组（来自 4.3）
    •	子空间的维数 = 极大无关组所含向量个数 = 秩（来自 4.3/4.4）
    •	列空间 Col A 的基 = 主元列对应的原矩阵列（来自 4.4 求秩）
    •	零空间 Nul A 的基 = 基础解系（4.7 详讲）
    基的求法：
    •	Col A 的基：对 A 行变换到阶梯形，主元列对应的原矩阵列。
    •	Nul A 的基：解 Ax=0，自由变量分别取 1 和 0 得到基向量。
    •	Row A 的基：对 A 行变换到阶梯形，非零行即是基。
    •	注意：Col A 的基回原矩阵取列；Row A 的基直接用变换后的非零行。
    联系 4.5：
    子空间是抽象的集合，基提供了具体的刻画工具。一旦选定基，子空间中向量就有了坐标，运算转化为坐标向量的运算。维数 dim H 是子空间的唯一不变量——这正是线性代数"用不变量刻画结构"思想的体现。
    六、§4.7 线性方程组有解的条件及解的结构
    （一）齐次线性方程组 Ax=0
18. 有非零解的条件
    Ax=0 有非零解 ⇔ R\(A\) < n ⇔ α₁\,…\,αₙ 线性相关。A 为方阵时 ⇔ \|A\|=0。
19. 解的性质
    解的线性组合仍是解。解集合 = Nul A，是 Rⁿ 的子空间。
20. 基础解系
    定义：解空间（Nul A）的一组基称为基础解系。
    定理：R(A)=r<n 时，存在基础解系，含 t=n-r 个解向量。这 t 正是 dim(Nul A)。
21. 通解：x = k₁X₁ + … + kₜXₜ
22. 求基础解系步骤：
    •	对 A 做行变换到行最简形，确定自由变量
    •	依次令一个自由变量=1，其余=0，得 n-r 个解向量
    •	这组解向量即是基础解系
    （二）非齐次线性方程组 Ax=β
23. 有解的条件
    有解 ⇔ β 可由列向量组线性表示 ⇔ R(A)=R(Ã)。
24. 解的分类：无解 R(A)≠R(Ã)；唯一解 R(A)=R(Ã)=n；无穷多解 R(A)=R(Ã)=r<n。
25. 解的结构（核心定理）：通解 = 特解 + 导出组通解。w = p + k₁X₁ + … + kₜXₜ。
26. 几何解释：解集是 Nul A 平移特解 p 后的仿射空间，不过原点，不构成子空间。
    联系与意义——全章概念的大汇合：
    4.7 节是全部概念的综合应用，推理链条如下：
    •	Ax=0 的解集 Nul A 是一个子空间（4.5 子空间）。
    •	Nul A 的维数 = n-R(A)（4.4 矩阵的秩 + 秩定理）。
    •	Nul A 的基 = 基础解系（4.6 基与维数，4.3 极大无关组）。
    •	基础解系含 t=n-r 个向量（4.6 维数计算）。
    •	非齐次通解 = 特解 + 齐次通解 = 子空间的平移（4.5 的几何）。
    •	有解条件 R(A)=R(Ã) 本质是 β 是否在 Col A 中（4.5 列空间）。
    各概念的对应关系总结：
    •	线性相关 ⇔ 齐次有非零解 ⇔ R(A)<n
    •	线性表示 ⇔ 非齐次有解 ⇔ R(A)=R(Ã)
    •	极大无关组 ⇔ 基（子空间的）
    •	向量组秩 ⇔ 矩阵秩 ⇔ 子空间维数
    •	n-R(A) = 自由变量数 = dim(Nul A) = 基础解系含向量个数
    •	通解 = 特解 + 基础解系的线性组合 = 仿射空间
    做题技巧：
    •	解齐次：对系数矩阵行变换→行最简形→参数通解→自由变量赋值得基础解系。
    •	解非齐次：对增广矩阵行变换→看秩是否相等→不等则无解→相等则令自由变量=0得特解→再求基础解系→合并。
    •	含参数方程组：讨论使行列式为0的参数值，对增广矩阵行变换分类讨论。这是考试高频题型。
    结 语
    第四章以"向量空间"为主线，各节层层递进：
    •	4.1&4.2（线性相关性）——起点，提出"向量之间有什么关系"。
    •	4.3（极大无关组与秩）——用极大无关组抓独立核心，用秩定量刻画。
    •	4.4（矩阵的秩）——行秩=列秩=矩阵的秩，从向量到矩阵统一。
    •	4.5（子空间）——提升到空间层面，提出列空间、零空间、行空间。
    •	4.6（基与维数）——为子空间提供精细刻画工具，维数是唯一不变量。
    •	4.7（解的结构）——理论大汇合，应用于线性方程组这一核心问题。
    从方法论看，本章体现了现代数学的思维方式：用代数结构（向量空间）统一描述看似不同的问题（向量、矩阵、方程组），用不变量（秩、维数）刻画结构本质，用基（坐标架）实现抽象空间与具体计算的转换。理解这一脉络，就真正掌握了第四章的精髓。
