# Visual System: wouldkeep 全面改版

## Direction

视觉系统服务于“个人档案馆 × 公共知识网络”。它把三种设计倾向组合成一个明确方向：功能主义提供秩序和克制，编辑设计建立长文层级，斯堪的纳维亚式自然色与柔和细节保留人的温度。

页面应像一个仍在生长、但经过认真编目的私人档案馆；关系图、修订状态和引用又让它成为公共知识网络。视觉表达不依赖复古纸纹、emoji 或大量卡片，而依赖排版、细线、编号、元数据和稳定的空间节奏。

实现令牌位于 `quartz/styles/tokens.scss`。

## Core Rules

1. **正文优先**：阅读页以排版和留白建立层级；工具降低视觉重量，只有在交互时增强。
2. **结构可见**：使用细线、目录编号、版本与引用标记表达关系；阴影只用于浮层和真正的层级变化。
3. **颜色有含义**：绿表示主要行动与稳定生长，陶土色表示档案/萌芽，蓝色表示链接与信息；状态同时配合文字和图标。
4. **圆角克制**：输入、按钮和轻量容器允许 4–12px 圆角；文章、目录和档案索引不形成满屏圆角卡片。
5. **动效解释状态**：只动画展开、聚焦、反馈和空间关系；不使用弹跳、循环漂浮或大面积滚动入场。

## Color System

### Light

- 画布是降低黄度的暖灰 `#f4f1e9`，正文纸面 `#fbf9f4`，避免旧主题偏黄和仿古。
- 主文字为暖墨色 `#25261f`，次级信息 `#5d5f56`。
- 主行动与“稳定生长”使用常青绿 `#2f6752`。
- 引用、链接和网络关系使用知识蓝 `#1f6070`。
- 档案、萌芽和第二强调使用陶土色 `#9a5d3f`。

### Dark

- 画布使用暖炭黑 `#171914`，表面用 `#1e211b` 和 `#262922` 分层，不做简单反相。
- 正文使用柔和米白 `#e8e6de`，减少长时间阅读的眩光。
- 绿、蓝、陶土色分别提升亮度，保持角色不变。

### Contrast Intent

- 正文、次级文字、链接和主要按钮文本以 WCAG AA 为最低目标。
- `--color-border-primary` 用于控件和重要边界；低对比的 `--color-border-subtle` 只用于装饰分隔。
- 成熟度与状态不得只用颜色表示，必须包含文字标签或可访问图标。

## Typography

- **Display**：Noto Serif SC，仅用于品牌字标、首页主标题、文章 H1 和少量引用性标题。
- **Body / UI**：Noto Sans SC，用于正文、导航、按钮、元数据和数据界面。
- **Mono**：JetBrains Mono，用于代码、版本号、日期索引和短小的档案编号。
- 正文默认至少 16px，中文长文行高约 1.65–1.82；阅读宽度控制在约 46rem。
- 全大写只限短英文标签；中文标签通过字号、字重和间距区分，不人为增加大段字距。
- 首页可以使用流体大标题；文章页不追求海报式字号，以标题、摘要、状态和正文形成清晰递进。

## Spacing and Layout

- 采用 4px 基础单位，并在长文区使用 24/32/48/64px 的编辑节奏。
- 手机从 375px 单列开始；现有 800px、1200px 断点继续作为 Quartz 行为边界。
- 宽屏中正文、目录和侧栏各自遵循独立宽度，不用拉宽正文填满空间。
- 区块间距大于卡片内距；主题分组通过留白和规则线形成，不依赖额外背景框。

## Shape and Depth

- 小控件 4px，中型容器 8px，突出浮层最多 12–16px 圆角。
- 默认结构由 1px 边界完成；2px 用于选中和强调。
- `shadow-sm` 只用于轻微脱离页面的控件，`shadow-md/lg` 只用于搜索、抽屉、弹窗和地图详情层。
- 焦点使用 3px 高对比外环，并与边界保留 2px 偏移。

## Motion

- 交互反馈以 140–220ms 为主，抽屉和大型状态转换最多 360ms。
- 颜色、透明度和小幅位移应分别声明属性，不使用 `transition: all`。
- 知识地图允许聚焦与邻接关系过渡，但停止后必须稳定，不持续漂浮。
- `prefers-reduced-motion: reduce` 将所有令牌时长压缩为 1ms、位移归零；实现阶段还需关闭平滑滚动和图谱持续运动。

## Component Character

- **Masthead**：衬线品牌名与无衬线实例名并置；细线和版本式小字表现“双品牌”，不使用大 Logo 图形填充空间。
- **Search**：像索引检索器而不是聊天框；结果强调主题、成熟度与匹配上下文。
- **Directory**：像分类目录，重视层级、数量和当前位置；避免文件管理器式密集图标。
- **Article Header**：标题下方以编目行展示成熟度、更新时间、主题和阅读信息。
- **Cards**：只在学习路径、地图详情和可操作集合中使用；普通文章列表采用规则线与行式布局。
- **Knowledge Map**：节点颜色表示主题而非热度，节点大小不暗示价值排名；必须提供等价列表视图。
- **Feedback**：成功、错误和空状态用清楚文案、统一图标和语义背景，不用 emoji 作为主要图标。

## Legacy Token Migration

Quartz 当前的 `--light`、`--lightgray`、`--gray`、`--darkgray`、`--dark`、`--secondary`、`--tertiary` 继续保留，避免令牌阶段改变现有页面。实施时按语义迁移：

| Legacy usage | Target role |
| --- | --- |
| 页面背景 `--light` | `--color-bg-canvas` 或 `--color-bg-surface` |
| 弱边界 `--lightgray` | `--color-border-secondary` / `--color-border-subtle` |
| 次级字与边界 `--gray` | 分拆为 `--color-text-tertiary` / `--color-border-primary` |
| 正文字 `--darkgray` | `--color-text-secondary` 或 `--color-text-primary` |
| 标题 `--dark` | `--color-text-primary` |
| 链接 `--secondary` | `--color-text-link` |
| 行动色 `--tertiary` | `--color-accent-primary` |

不要通过全局别名把一个旧变量机械映射到多个语义。应在组件改造时逐处替换，并用视觉回归验证。

## Implementation Guardrails

- 新组件不得硬编码颜色、间距、圆角、阴影、动效时长或 z-index。
- 原生 Quartz 组件优先扩展，不引入第二套 UI 框架。
- 图标统一使用同一套线性 SVG 语言，并保证按钮名称在按钮元素上。
- 对比度、键盘焦点、44px 触控目标、深色模式和 reduced motion 是令牌系统的验收条件，不是后期补丁。
- 完整页面实现前，先用 Masthead、文章头部、搜索结果和知识地图详情验证令牌的覆盖度。
